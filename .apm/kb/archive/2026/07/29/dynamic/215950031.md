﻿## 背景
用户发现两类 bug：(1) VFS 文件夹重命名后老目录残留（目录A和目录B同时存在）；(2) 移动端 Markdown 预览对 FrontMatter 处理异常——FM 不闭合时正文完全不渲染（只显示劝补全提示），FM 闭合+空正文时 FM 被渲染两次。已 brainstorm 确认根因。

## 目的
打包成一个 iteration（vfs-move-and-frontmatter-bugfix），产出 PRD/SPEC 并实现修复。用户已拍板：FM 修复取向 A 最干净版（改底层 splitMarkdownFrontMatter 语义，不闭合当无 FM 处理，清理 mobile 提示 UI，旧 mobile-bugfix spec 归档不构成约束）。

## 现状
brainstorm 探索完成，根因明确：
- VFS move（vfs-move.ts L178-181）：hadOldDirRow 判断恒 false 源目录不删 + 子目录行漏删 + 空目录 rename 抛 NOT_FOUND。
- FM：front-matter.ts 不闭合返回 closed:false；FileMarkdownPreview 用 closed 门控吞正文；L511 plain 兜底 || content 致双重渲染。
- 调用方影响：mobile FileMarkdownPreview（整套提示 UI 要清）、core workplace-display（header 档语义变更，测试要更新）。
PRD 已落盘 .apm/kb/docs/Iterations/vfs-move-and-frontmatter-bugfix/prd.md，待用户确认。
