# Mobile 表单底部主按钮命中区修复 PRD

> **类型**：缺陷修复（bugfix）  
> **平台**：Android Mobile（本迭代验收范围）  
> **关联**：`mobile-ui-vfs-defaults`（紧凑按钮回归）、表单底部 `StickyFormFooter` 主 CTA

## 背景

用户在「我的 → 添加服务商」页看到底部有一条很长的主操作条，但点击条带左右空白区域**无反应**；只有点到中间文案「创建」附近才会触发创建。视觉上像整条可点的长按钮，实际可点热区只覆盖文字级紧凑区域，造成「点了没反应 / 服务商创建不了」的错觉。

该底部主按钮由共享组件 `StickyFormFooter` 承载，不仅用于服务商创建，还用于服务商编辑「保存」、Agent 编辑、云同步保存、正则/压缩/事件等表单主 CTA。紧凑按钮回归（`mobile-ui-vfs-defaults`）去掉了 `minHeight: 44` 且未落地 `hitSlop`，在 footer 未把主按钮拉满宽时，热区与底栏视觉宽度不对齐的问题会被放大。

## 目标（含成功指标）

| 目标 | 成功指标 |
|------|----------|
| 视觉与热区对齐 | 表单底部主 CTA 的可点击区域与主色按钮可视区域一致（满宽或与 footer 内容区同宽），点左右空白可触发 |
| 创建服务商可用 | 「添加服务商」页在字段合法时可在按钮任意主色区域完成创建，不再依赖「只点到创建两字」 |
| 同类表单一并修好 | 所有走 `StickyFormFooter` 的底部主按钮（创建/保存）行为一致 |
| 不扩功能面 | 不改创建/保存业务语义、校验规则、文案与导航；不恢复全局大按钮视觉 |

## 用户与场景

| 用户 | 场景 |
|------|------|
| 配置服务商的用户 | 在「添加服务商」填完 ID / Base URL / API Key 后，点击底部主按钮完成创建 |
| 编辑各类设置的用户 | 在 Agent、云同步、正则、压缩条件等表单底部点「保存」，期望整颗主色按钮可点 |

## 范围

### 包含范围

1. 修复 Mobile 表单底部主 CTA：视觉满宽（或与 footer 内容区同宽）与触摸命中区一致。
2. 覆盖所有使用 `StickyFormFooter` 的表单主按钮（至少含：服务商创建/编辑、以及其它 StickyFormFooter 消费方）。
3. Android 真机或官方模拟器手工验收：点按钮左右空白可触发；合法字段下创建服务商成功。

### 不包含范围

- iOS / Desktop / CLI / `examples/mobile` 原型同步（本期未报告）。
- 恢复全局 `PrimaryButton` 的 `minHeight: 44` 大按钮视觉（仍遵循 `mobile-ui-vfs-defaults` 紧凑约定）。
- 改服务商创建校验规则、SKSP 写密钥语义、成功后导航/Toast 文案。
- 无关 UI 重构或抽新一套按钮组件体系。

## 核心需求

1. **热区对齐**：底部主按钮可点击区域不得明显小于主色可视块；用户点主色块内任意位置（含文字两侧空白）均应触发 `onPress`（在未 disabled 时）。
2. **创建主路径**：在「添加服务商」且可保存条件下，点主按钮任意有效区域可完成创建，行为与点中「创建」文字时一致。
3. **共享一致性**：凡经 `StickyFormFooter` 渲染的主 CTA，创建与保存文案场景行为一致，避免只修服务商一页。
4. **disabled 语义保留**：字段不合法导致按钮 disabled 时，整颗按钮仍不可点（与现网一致），不得因扩大热区而绕过校验。
5. **最小改动**：以对齐命中区为目标，避免无关样式或业务逻辑变更。

## 验收标准

### 添加服务商（主路径）

- **Given** 用户在 Android 上打开「添加服务商」，并填入合法的服务商 ID、Base URL、API Key  
- **When** 用户点击底部主色按钮的**左侧空白**或**右侧空白**（非「创建」文字正中）  
- **Then** 触发创建流程；成功后出现既有成功反馈，服务商出现在列表中

- **Given** 同上页面，必填项未齐导致按钮不可用  
- **When** 用户点击主色按钮任意位置  
- **Then** 不创建；行为与修复前 disabled 一致

### StickyFormFooter 回归

- **Given** 用户打开任一使用底部 StickyFormFooter 主按钮的表单（如服务商编辑「保存」、Agent 编辑「保存」）  
- **When** 在可保存状态下点击主色按钮左右空白  
- **Then** 与点击按钮文字中心效果相同，均触发保存/提交

### 负向（修复前现象不得复现）

- **When** 用户在可保存的「添加服务商」页点击底部条带上主色按钮区域（非仅文字中心）  
- **Then** 不得出现：仅点「创建」两字才响应、点左右空白完全无反应（修复前缺陷）
