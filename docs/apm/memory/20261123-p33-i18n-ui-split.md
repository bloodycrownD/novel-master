# p33 ui.yaml 拆 ui/{locale}/ 分片子目录（2026-11-23）

用户发起：ui.yaml 拆域后 2636 行还是太长，建子目录拆分；中途追加「ui 下再拆一次，en/zh 子目录」。

## 终态结构
`resources/i18n/ui/{zh-CN,en-US}/{transcript,agent,model,workspace,vfs,stats}.yaml`——域层由 ui/ 目录承载、locale 由子目录承载、语义族分片（最大 314 行）。24 个顶层键 → 6 分片：transcript(transcript/chat/common/session)、agent(agent/skills/prompt)、model(provider/sampling/chat_config/smart_sort)、workspace(nav/project/update/about/runtime/notification/menu/storage)、vfs(vfs/cloud_sync/rich_document/mermaid)、stats(stats)。

## 三处装载点同步（生成器 + 两个测试 helper）
- `gen-i18n-catalog.mjs`：DOMAIN_FILES（单文件域）+ DOMAIN_DIRS（子目录域）双轨；子目录域按 locale 子目录装载、分片合并、同段键互斥防静默覆盖。
- `test/helpers/core-i18n.ts` 的 loadCatalog、`test/i18n/catalog.test.ts` 的 loadUiMerged 同步同款逻辑——**catalog 消费点有三处独立实现**，改结构时三处一起改（本轮第一次只改生成器导致 35 测试红）。

## 大坑：yaml 库往返毁标量键
pyyaml 把 `"true"` 标量键 dump 成裸 `true:`，parse 回来变 boolean——`ui.common.true` 键静默丢失，keys.ts 的键清单与 generated 失配（TS2353）。**i18n yaml 拆分必须文本切片**（按顶层键行号切块拼文件），零库往返才保真。
