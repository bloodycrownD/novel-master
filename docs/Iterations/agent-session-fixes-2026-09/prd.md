# agent-session-fixes-2026-09 迭代 PRD

## 背景

2026-09-19 用户上报：删除智能体后，会话中的智能体直接锁定，无法切换。探索确认根因为「删除不级联 + UI 有意锁卡」叠加成死锁。

## 范围

| 敏捷项 | 类型 | 说明 |
|--------|------|------|
| `bugs/session-agent-locked-after-delete/` | bug | 智能体被删后，会话智能体卡从「锁死」放开为「待重选」——双端 |

## 明确不做（用户拍板）

- 删除时级联回退（批量把引用被删智能体的会话改绑到工作区默认智能体）——否决理由：背着用户换智能体不诚实，且为边角场景（copy 会话/子会话/坏 JSON 行/空 registry 回退目标）引入大量复杂度。残留代价：被删智能体的会话在用户手动重选前发不出消息，解锁后这是显式可见的「待重选」状态。
- 切换服务端 agentId 存在性校验、删除后广播刷新——均超出本 bug 最小修复范围。
