# 输入抖动 / 项目工作区返回 / 提示词长文本编辑 UX 修复 PRD

## 背景

本 PRD 覆盖一批来自真实使用的体验问题，共三则：

1. **Android 输入框抖动**：聊天输入框里引用了文件/技能（生成着色 tag）后，当文字较多时继续输入，输入框内容会出现上下抖动，影响连续输入体验。经排查，tag 本身没有动画特效（是静态着色胶囊），抖动与文本量较大时的重排相关，仅 mobile 端存在（desktop 端输入框是另一套实现，无此问题）。
2. **项目工作区返回不符合预期**：会话列表的「项目工作区」面板里进入子目录后，Android 返回（返回键/边缘滑动）在任何目录层级都直接跳回会话列表，丢失目录位置；而聊天页内的「聊天工作区」已经是「先逐级返回上级目录、根目录才退回面板」的行为，两处不一致。
3. **agent 配置页提示词输入框无长度约束**：双端 agent 配置页有多处提示词输入（系统提示词、技能索引前缀语、工作区助手确认语、常驻块内容、自定义附加信息、动态块内容），长文本会把表单撑得极长，浏览和填写体验差。

## 目标（含成功指标）

- Android 上，输入框存在引用 tag 且文本较多时，连续输入/删除不再出现可感知的内容上下抖动，同时保留 tag 的着色胶囊视觉。
- 「项目工作区」的返回行为与「聊天工作区」完全一致：先逐级返回上级目录，根目录才退回会话列表。
- agent 配置页表单在存在超长提示词时保持紧凑可浏览；超长提示词可通过全屏页面舒适编辑，未超长时保持原地直接编辑。

成功指标：真机回归上述三个场景全部通过；agent 配置页表单高度不再随超长提示词无限增长。

## 用户与场景

- mobile（Android）用户在聊天中通过 `@路径` / `$技能` 引用文件或技能后，继续连续输入较长文本。
- mobile（Android）用户在「项目工作区」多级目录中浏览文件，随后使用系统返回手势退出。
- 双端用户在配置 agent 时填写/查看较长的系统提示词或提示词块（典型：从别处复制粘贴大段提示词）。

## 范围

### 包含范围

- mobile 聊天输入框引用 tag 场景的输入稳定性（Android）。
- mobile「项目工作区」面板的 Android 返回手势逐级退目录。
- 双端 agent 配置页提示词输入框的超长折叠展示 + 全屏编辑，覆盖 6 类输入点：系统提示词、技能索引前缀语、工作区助手确认语、常驻块内容、自定义附加信息、动态块内容。

### 不包含范围

- iOS 边缘滑动返回上级目录（现有页面结构不支持，本次不做；iOS 返回行为维持现状）。
- desktop 聊天输入框（无此问题）。
- agent 描述字段（非提示词，维持现状）。
- 提示词长度的数据层/校验限制（本次纯展示与编辑体验，不改数据约束）。
- 提示词语法、宏能力的变更。

## 核心需求（3-7 条）

1. **输入稳定**：Android 输入框内存在引用 tag 且文本较多时，连续输入/删除不得出现内容上下抖动；tag 的着色胶囊视觉保留，不因修复而牺牲辨识度。
2. **项目工作区逐级返回**：Android 返回手势在「项目工作区」子目录中先返回上级目录，根目录时才切回会话列表——行为与「聊天工作区」一致。
3. **超长提示词折叠**：提示词超过阈值（默认 600 字符）时，折叠为最多 3 行并以省略号结尾的只读预览，表单保持紧凑；折叠区可点击。
4. **全屏编辑**：点击折叠区进入类似文件编辑页的全屏编辑（双端形态可按平台习惯：全屏页面或全屏弹层），支持自由滚动与编辑；保存后回填原字段，取消则不改动。
5. **短文本原地编辑**：未超阈值的提示词保持现有内联编辑方式，不强制进入全屏。
6. **编辑连续性**：内联输入过程中超过阈值时不立即折叠抢焦点，待失焦后才转为折叠态；全屏编辑保存后若长度已低于阈值，自动回到内联编辑态。
7. **宏能力保留**：内联编辑态保留现有宏着色与宏 chips 交互；全屏编辑态宏以纯文本呈现，内容不丢失、回填后宏继续生效。

## 验收标准

**R1 输入稳定（Android）**
- Given 输入框中已存在文件/skill 引用 tag 且文本较多（多行），When 连续输入与删除字符，Then 输入框内容不出现上下抖动，tag 胶囊着色正常。
- Given 输入框无引用 tag，When 连续输入，Then 行为与现状一致（无回归）。

**R2 项目工作区返回**
- Given 用户在「项目工作区」的二级及以下目录，When 按返回键/边缘滑动，Then 返回上一级目录（不切回会话列表）。
- Given 用户在「项目工作区」根目录，When 按返回键/边缘滑动，Then 切回会话列表。
- Given 用户在「聊天工作区」，When 返回，Then 行为与现状一致（无回归）。

**R3 超长折叠与全屏编辑（双端）**
- Given 某提示词字段内容超过阈值，When 打开/浏览 agent 配置页，Then 该字段以最多 3 行 + 省略号的折叠态呈现。
- Given 折叠态字段，When 点击，Then 进入全屏编辑，内容完整可编辑；When 保存，Then 返回表单且该字段更新；When 取消，Then 内容不变。
- Given 某提示词字段内容未超阈值，When 编辑，Then 仍可在表单内原地直接编辑。
- Given 用户正在内联输入且长度超过阈值，When 未失焦，Then 保持内联编辑不被折叠打断；When 失焦，Then 转为折叠态。
- Given 全屏编辑后内容已低于阈值，When 保存返回，Then 字段回到内联编辑态。
- Given 内联态含宏的提示词，When 查看与编辑，Then 宏着色与 chips 交互与现状一致；经全屏编辑保存后宏仍生效。

## 风险与待确认项

- **抖动根因深度**：若最终确认抖动来自输入渲染的底层重建机制，最小样式修复可能不足以完全消除，验收以真机回归为准；如需「高亮层与输入分离」的方案重构，超出本 PRD 范围，需另行评估。
- **阈值默认值**：600 字符 / 3 行折叠为默认值，待最终拍板（可做成常量便于调整）。
- **mobile 全屏编辑形态**：复用现有代码编辑器内核或纯文本大输入框由实现阶段决定，本 PRD 只约束体验要求（全屏、自由编辑、可保存/取消）。
