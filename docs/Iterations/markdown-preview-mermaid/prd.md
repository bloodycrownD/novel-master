# Markdown Mermaid 图表渲染（预览与聊天消息）PRD

## 背景

markdown 渲染场景（desktop 预览面板、mobile 工作区 `.md` 预览、双端聊天消息富文本）目前均按普通代码块渲染 ` ```mermaid ` 内容，用户只能看到裸源码文本。项目自身的迭代文档（`docs/Iterations/` 下大量 spec）广泛使用 mermaid 画流程图、时序图，助手回复中也常以 mermaid 表达结构；用户在应用内无法看到图表，体验断裂。

各端渲染管线不同（desktop 为浏览器内核直接渲染、mobile 预览与聊天消息为两条 WebView 渲染管线），本期要求所有 markdown 富文本场景都能把 mermaid 代码块渲染成图表。

## 目标（含成功指标）

在 markdown 富文本场景（文件预览 + 聊天消息）下，` ```mermaid ` 围栏代码块被渲染为对应图表（流程图、时序图、状态图等常用类型），而非源码文本。

成功指标：

- 打开含 mermaid 图表的 `.md` 文件或聊天消息，双端均直接呈现图表，无需切换到外部工具。
- 含图文档/消息的界面可正常滚动浏览，图表不遮挡、不破坏正文排版。
- 非法 / 不支持的 mermaid 源码不导致渲染崩溃。
- 流式输出场景下图表不闪烁（流式期间允许先显示源码/占位，结束后呈现图表）。

## 用户与场景

- 作者在应用内查阅项目 spec / 世界观文档（大量内置 mermaid 图），需要直接看懂流程与结构。
- 用户在手机上回顾自己写的剧情大纲（用 mermaid 表达人物关系或时间线）。

## 范围

### 包含范围

- desktop 文件预览面板的 markdown 模式：mermaid 代码块渲染为图表。
- mobile 工作区 `.md` / `.markdown` 预览（默认 WebView 引擎）：mermaid 代码块渲染为图表。
- 双端聊天消息富文本：历史消息与流式输出完成后的消息，mermaid 代码块渲染为图表（流式进行中允许显示源码或占位样式）。
- 渲染失败（语法错误、不支持的图类型）时的降级：回退为显示源码文本，并给用户可感知的失败提示（不静默空白）。
- 图表随正文滚动正常展示，宽度适配显示区域。

### 不包含范围

- 图表交互能力（点击节点、缩放拖拽等）。
- mermaid 主题深度定制（仅要求与预览的明暗主题基本协调）。
- mobile 的 `rn` 回退引擎与超长文本回退路径（维持现状：显示源码）。
- CLI 端。

## 核心需求（3-7 条）

1. **图表渲染**：markdown 正文中的 ` ```mermaid ` 围栏代码块渲染为图表；其余代码块行为不变。
2. **流式策略**：聊天流式输出期间允许以源码或占位样式呈现，流式完成后呈现图表，过程无明显闪烁。
3. **失败降级**：mermaid 源码无法解析时回退显示原源码，并带可见的失败标识；不影响其余部分的渲染。
4. **主题协调**：图表配色与当前明暗主题基本协调，不出现深色主题下白底刺眼的情况。
5. **版式适配**：图表宽度适配显示区域，超宽图表可横向查看（滚动或缩放，形态由实现定），不破坏正文排版。
6. **全场景覆盖**：desktop 与 mobile 的文件预览与聊天消息均支持；各场景对常用图类型的覆盖保持一致。

## 验收标准

| # | Given / When / Then |
|---|---|
| 1 | Given 含 ` ```mermaid flowchart ` 代码块的 `.md` 文件；When 在 desktop 打开预览；Then 该代码块位置呈现流程图而非源码。 |
| 2 | Given 同一文件；When 在 mobile 打开预览；Then 同样呈现流程图。 |
| 3 | Given 含语法错误的 mermaid 代码块；When 预览；Then 该块显示源码与失败标识，文档其余部分正常渲染，应用不崩溃。 |
| 4 | Given 含 ` ```ts ` 等普通代码块的文档；When 预览；Then 普通代码块渲染行为与现状完全一致。 |
| 5 | Given 系统切换到深色主题；When 预览含图文档；Then 图表配色与深色主题协调，无大面积白色底块。 |
| 6 | Given 含宽度超出屏幕的时序图文档；When 预览并滚动；Then 图表完整可查看，不遮挡正文、不破坏页面滚动。 |
| 7 | Given 同一文档在明 / 暗主题间切换；When 重新预览；Then 图表按当前主题正确呈现。 |
| 8 | Given 助手回复包含 mermaid 代码块；When 流式输出进行中；Then 该块显示源码或占位（不崩溃、不闪烁、不出现失败标识）。 |
| 9 | Given 流式输出完成；When 消息定稿；Then desktop 与 mobile 聊天气泡内均呈现图表。 |
| 10 | Given 历史消息（重新打开会话）包含 mermaid；When 查看消息列表；Then 图表直接呈现，无需等待交互。 |

## 风险与待确认项

- mermaid 常用图类型清单（flowchart / sequence / state / class / gantt 等）以主流稳定版支持为准，验收时取代表性 3-4 类验证即可。
- mobile 端两个 WebView 内渲染会带来包体增长（运行时体积约 1-2MB 级），属可接受范围，但发布说明中应提及。
- 预览的划词批注坐标以渲染后正文文本为基准，图表替代代码块文本后需回归批注功能（约束，非需求）。
