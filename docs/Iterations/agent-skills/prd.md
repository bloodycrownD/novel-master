# Agent Skills（技能能力）PRD

## 背景

novel-master 目前的 AI 协作缺少「可复用操作知识」的承载。用户在多个项目、多个会话里反复沉淀的写作规范、世界观校验清单、叙事风格约束，只能散落在各会话的工作区文件或 agent 配置的提示词文本里——换一个会话就带不走，AI 也无法稳定发现和复用。

类 AI IDE 的 SKILL.md 机制是成熟参照：技能是一个带入口文件的目录（`SKILL.md` + `references/` 等辅助文件），AI 依据索引中的描述自行决定是否读取并遵循使用。

直接套用该机制与现状有两处冲突：

1. **会话隔离**。session 工作区是 project 树的一次性拷贝，且会被模板同步整树重置。技能若存放在 session 域，换会话即失效、被同步即冲掉。因此技能必须独立于 session 生命周期，存放在 global / project 两域，并且不进入两条复制链（project→session 的会话工作区初始化、global→project 的模板同步）。
2. **AI 无跨域通道**。现有 AI 文件工具（read/write/edit/fs/glob/grep）全部绑定 session VFS，天然读写不到 global/project 域。需要为技能提供专用的跨域读写能力。

交互原型已在 `feat/skill-ui-prototype` 分支的 `examples/mobile/` 完成并通过验证，本 PRD 以其为交互基准。

## 目标（含成功指标）

让用户和 AI 都能把「操作知识」沉淀为跨会话、跨项目可复用的技能，且管理成本低于复用收益。

成功指标：

1. 用户在一个项目创建的技能，该项目新建会话立即可用，无需重新粘贴；
2. 全局技能对所有项目生效；同名项目技能覆盖全局版，且不影响其他项目继续使用全局版；
3. AI 能在对话中自主创建、更新技能，用户能从聊天工具卡片直达查看与编辑；
4. 技能索引常驻提示词的体积可控：只含名称、描述、来源域，正文由模型按需读取；
5. 无效技能（如缺少描述）不进入索引，但在所有管理界面可见、可修复，不静默丢失；
6. `$` 引用与 `@` 引用体验一致：手动输入与按钮双入口，首个引用附技能全文，可见历史内重复引用不重复加载。

## 用户与场景

| 用户 | 场景 |
|------|------|
| 作者 | 把某本书的叙事口癖规范沉淀为项目技能，让 AI 每次生成自动遵守 |
| 作者 | 把通用的世界观一致性检查清单提升为全局技能，所有项目共用 |
| 作者 | 发现 AI 这轮用了不对的规范，在会话技能面板临时关闭该技能（不影响其他项目） |
| 作者 | 在设置的技能管理页统一整理：跨项目复制、提升全局、批量清理废弃技能 |
| AI（技能使用者） | 依据索引描述判断需要某技能，拉取正文并遵循执行 |
| AI（技能生产者） | 用户说「把这个规范记成技能」时，创建或更新技能文件，并以工具卡片回报 |

## 范围

### 包含范围

- **存储**：VFS global + project 两域的 `meta/skills/{name}/` 目录，`SKILL.md` 为入口文件，支持 `references/` 等辅助文件与子目录。
- **隔离豁免**：技能目录不进入 session 工作区初始化与模板同步两条复制链，两域技能为长存数据。
- **AI 能力**：技能专用工具（列表 / 读取 / 写入），对 global 与 project 两域技能文件均可读写，无额外限制。
- **提示词注入**：生效技能的索引块（名称 + 描述 + 来源域）常驻注入；同名项目副本覆盖全局版后，索引中只出现项目版。
- **提示词配置与预览的体现**：技能索引块在智能体提示词配置 UI 中以固定占位卡片呈现（不可配置、不可移动，位置与实际注入一致），并在「查看提示词」预览中作为独立分段出现，保证所见即所得。
- **启停管理**：负清单式启用/关闭，默认全部启用；禁用记录按项目域落库。
- **技能引用（$ 引用）**：输入框手动输入 `$` 或工具栏按钮触发，选中后以 `$技能名` token 附入消息；首个引用附 `SKILL.md` 全文，可见历史内重复引用只留短标记，去重语义与 `@` 引用一致。触发符号定 `$` 而非 `/`：`/` 与 `@/路径` token 的路径前缀天然冲突，`$` 无历史包袱。
- **双端管理 UI（mobile + desktop）**：会话技能面板、设置·技能管理页、技能详情与编辑、聊天工具卡片。

### 不包含范围

- 技能市场、分享、订阅等社会化能力。
- 技能版本历史与回滚的专门 UI（VFS 版本链若天然覆盖则不额外承诺界面）。
- 技能间依赖、组合编排。
- 修改 session 隔离模型本身。
- front matter 除 name / description 之外的扩展控制字段（如禁用模型自动调用等）。

## 核心需求

### 1. 存储与两域模型

- 技能是目录而非单文件：`meta/skills/{name}/SKILL.md` 为必选入口，辅助文件（如 `references/timeline.md`）放在同目录任意子路径下，随技能整体复制、删除。
- 两域存放：全局域技能对所有项目生效；项目域技能仅所属项目生效。
- 合并规则：当前项目可见的技能 = 全局技能 ∪ 当前项目技能；同名时项目副本覆盖全局版（展示为覆盖态，全局原件保留、其他项目不受影响）。
- 有效性：`SKILL.md` 的 front matter 需含 name 与 description；缺失或不可解析的技能标记为无效——不进入索引与启用统计，但在管理界面正常展示并提示原因，可修复。

### 2. AI 技能能力

- 提示词常驻注入技能索引：每条为「名称 + 描述 + 来源域」，模型据此自主决定是否取用。
- 注入位置固定：索引块注入在**系统区之后、常驻工作区之前**；无生效技能时不产生该块。
- **智能体提示词配置 UI 体现**（双端）：以「会话区」同款占位卡片模式展示技能索引块——固定位置、无开关无输入框、不可移动不可删除，附说明文案（运行时自动注入当前生效技能的索引）。
- **预览体现**：「查看提示词」（desktop 会话页提示词 tab / mobile 查看提示词 / CLI）中技能索引为独立分段，位置与配置 UI 展示一致；无生效技能时不出现。
- 技能能力以**单一通用工具** `skill_opt(action, params)` 提供，按动作分发，参数为扁平显式字段（action / name / domain / path / content 等，不使用不透明 params 包）：
  - `read`：读取技能内文件，默认 `SKILL.md`，可指定相对路径（含 `references/` 等辅助文件）；缺省按生效副本解析（同名项目副本优先），可显式指定域；
  - `write`：创建或整文件覆盖技能文件（新建技能即向新目录写 `SKILL.md`），须指定目标域；
  - `edit`：按既有文件 edit 工具的匹配语义对技能文件做局部修改；
  - `list`：列出技能及其文件清单，用于重名核对与辅助文件发现（常驻索引只有名称与描述，不含文件清单）；
  - `path` 参数限定在技能目录内（禁 `..`）。
- AI 可创建新技能、更新既有技能（含辅助文件），读写范围覆盖 global 与 project 两域，与用户权限一致；删除技能仅限用户 UI 操作，不提供 AI 删除动作。
- AI 写入产生聊天工具卡片（见核心需求 7），用户可核对与追改。
- **工具可配置**：`skill_opt` 与其他内置工具一致，可在智能体配置的工具策略（allow / deny）中控制，双端工具策略选择器中出现；某智能体禁用 `skill_opt` 后，其会话不再注入技能索引（工具与索引同进退，避免模型看得见技能却用不了），`$` 引用不受影响（显式引用注入的是技能全文，不依赖工具）。

### 3. 启用 / 关闭

- 默认全部启用；关闭为负清单记录，不改动技能文件本身。
- 会话技能面板中的开关写**当前项目**的禁用记录：关闭仅对当前项目生效，不影响其他项目，也不影响全局原件。
- 禁用状态在面板列表中有明确视觉反馈（如划线弱化）。
- 会话操作抽屉展示汇总：「技能 n/m 启用」，n 剔除无效技能。

### 4. 会话技能面板

- 入口：会话操作抽屉新增「技能」项。
- 视角为**当前项目的合并视图**：全局 + 当前项目技能合并展示，同名只显示项目副本并标覆盖徽标。
- 列表每行：技能名 + 域徽标（全局 / 项目 / 项目 · 覆盖全局）+ 无效标签（含原因）+ 描述 + 启用开关；关闭态行弱化。
- 点行（开关区域外）进入技能详情页。
- 头部动作：「整理」跳转设置·技能管理页；「新建」打开新建弹窗并默认项目域。
- 空态有引导文案与新建入口。

### 5. 设置 · 技能管理页

- 入口：「我的」页新增「技能管理」，入口处展示计数（项目 X · 全局 Y）。
- **双 tab：全局技能（默认）在前，项目技能在后**。
- 全局 tab：平铺全部全局技能；被项目副本覆盖的技能标注灰标签「被项目副本覆盖」——任意项目存在同名副本即标注（SPEC D5，与项目 tab 展示所有项目的全局语境一致），tooltip 注明该全局版仅对无副本的项目生效。
- 项目 tab：**按所有项目分组展示全部项目技能**（管理页是全局语境，无法也不应只看当前项目），分组头展示项目名。
- tab 标题带计数；hint 文案随 tab 切换，说明当前域的生效范围与覆盖语义。
- 行操作（⋮ 菜单）：
  - 通用：编辑、删除（危险，需确认；确认文案区分「影响所有项目」与「仅该项目生效」）；
  - 全局域：复制到项目（项目选择弹层）；
  - 项目域：复制到其他项目（弹层排除源项目）、提升为全局（目标存在同名时需覆盖确认）。
- 复制 / 提升为**整目录操作**（含全部辅助文件）；目标同名则整包覆盖；若目标技能正被详情页或编辑器打开，同步刷新视图。
- 删除后同步清理对应禁用记录；正被打开的详情/编辑器安全踢回管理页。
- 批量管理：复用通用批量框架，进入选择模式（复选框 + 已选计数 + 删除按钮）；项目、全局 tab 各自独立列表；切换 tab 自动退出批量模式；技能列表允许全部删除。
- 新建按钮两个 tab 各自提供，并预选对应域。

### 6. 新建、详情与编辑

**新建技能弹窗**：

- 字段：技能名（即目录名，创建后不可改）、描述（进入索引，模型据此决定是否使用，必填）、存储域分段（全局 / 项目）、所属项目下拉（选项目域时出现，默认当前项目）。
- 校验：名称必填且不含空格与斜杠、不以 `.` 开头（保留名 `SKILL.md` 亦不可用作技能名），目标域内不重名、描述必填。
- 创建即生成仅含 `SKILL.md` 的技能目录，front matter 自动填 name / description，正文带辅助文件引导说明。
- 按钮为「创建并编辑」，成功后直达技能详情页。

**技能详情页**：

- 复用文件浏览器组件（技能详情视图），技能 `files` 动态构建目录树。
- 排序：`SKILL.md` 永远置顶，其次目录，再按文件名。
- 文件行状态区分「入口文件」与「技能辅助文件」；子目录可进入、可返回上级。
- 菜单裁剪：文件仅「打开 / 删除」，目录仅「进入」；顶部更多菜单仅「新建文件」。不提供纳入方式、目录规则、重命名等通用浏览器能力。
- `SKILL.md` 为保留入口：不可删除、不可新建同名文件。
- 新建辅助文件：输入相对路径（支持子目录如 `references/x.md`），校验必填、禁 `..`、域内查重；创建后直接进入编辑器。
- 删除辅助文件需确认；被删文件正被编辑时，关闭编辑器并回到详情页。
- 页面标题带技能名、域徽标；项目域附项目名。

**技能编辑器**（复用文件编辑器）：

- 顶栏标题「技能 · {名称}」；工具栏展示路径 chip（`meta/skills/{name}/{相对路径}`）与域徽标（「全局域 · 所有项目生效」/「项目域 · {项目名}」）。
- 未保存更改离开时拦截确认；保存写回技能文件。

### 7. 聊天工具卡片

- AI 的技能写入操作展示为专用工具卡片，形态对齐现有工具卡片模式（工具名 + 状态 + 摘要）。
- 支持创建与更新两类展示；摘要包含技能名、目标域与存储路径。
- 卡片可点击，直达对应技能详情页，便于用户核对 AI 刚写的内容。

### 8. 技能引用（$ 引用）

输入框新增 `$` 引用，交互形态与既有 `@` 引用完全一致，双入口：

- **手动输入**：光标前输入 `$`（须位于行首/空格/制表符边界，补尾空格后关闭）拉起技能 typeahead，按名称与描述模糊匹配、最多展示 5 条；点选后以完整 `$技能名` token 替换半截查询并补尾空格。
- **按钮入口**：工具栏新增 `$` 按钮（对应 `@` 的「引用文件」按钮位），打开技能选择器。选择器直接展示技能列表，不套用文件浏览器的层级 UI：平铺当前项目的合并视图（全局 ∪ 当前项目，同名只显示项目副本并标覆盖），无效技能不进入选择器；已关闭的技能可选中但标注关闭态（显式引用是用户明示意图，优先于负清单，引用照常注入）。
- **token 呈现与落库**：`$技能名` token 保留在正文中（mobile 以 mention 标签着色、退格整段删除；desktop 高亮层着色），发送时转为消息附件落库，不剥离正文。
- **注入与去重**：与 `@` 引用同机制——可见历史中某技能首次被 `$` 引用时，提示词附 `SKILL.md` 全文（仅入口文件，辅助文件由模型经技能工具按需读取）；同技能后续引用只留 `alreadyReferenced` 语义的短标记，不重复加载；置位/压缩后随可见窗口重置，再次引用重新附全文。
- **与常驻索引的关系**：常驻索引块只含名称+描述，不计入「已出现」判定——被索引的技能首次 `$` 引用仍附全文；反过来 `$` 引用附件也不影响索引块的构成。

## 验收标准

### 存储与合并

- [ ] Given 全局域与当前项目各存在技能 `foo`，When 会话技能面板加载，Then 只显示一条 `foo` 且标「项目 · 覆盖全局」，其他项目的会话仍显示全局版。
- [ ] Given 技能 `bar` 仅存在于全局域，When 任意项目会话加载，Then `bar` 可见可用。
- [ ] Given 技能 `broken` 缺少 description，When 任一管理界面加载，Then 该技能展示「无效 · 原因」标签，不计入「n/m 启用」的 n 与 m，修复 description 后自动恢复。

### AI 能力与注入

- [ ] Given 当前项目有 2 个生效技能（含 1 个覆盖全局的项目副本），When 提示词拼装，Then 索引块只含 2 条（覆盖后的项目版），每条为名称 + 描述 + 来源域，不含正文。
- [ ] Given 用户在对话中要求「把这段规范存成技能」，When AI 执行技能写入，Then global 或 project 对应域出现完整技能目录，且聊天中出现可点击的技能工具卡片。
- [ ] Given 技能被关闭（禁用），When 下一轮提示词拼装，Then 该技能不出现在索引中。
- [ ] Given 技能已存在，When AI 调用 `skill_opt(read)`，Then 返回 `SKILL.md` 或指定相对路径文件的内容，缺省解析到生效副本；When 调用 `skill_opt(edit)`，Then 仅匹配片段被更新，无需整文件重写。
- [ ] Given `skill_opt` 调用的 `path` 参数含 `..` 或越出技能目录，或 `write` 动作未指定目标域，When 执行工具，Then 报错拒绝并说明原因。
- [ ] Given 智能体 A 的工具策略禁用 `skill_opt`，When A 的会话拼装提示词，Then 无技能索引段且工具列表无 `skill_opt`；When 用户在同一会话 `$` 引用技能，Then `SKILL.md` 全文照常注入。
- [ ] Given 智能体 B 的工具策略未配置或允许 `skill_opt`，When B 的会话拼装提示词，Then 技能索引与工具均正常可用，双端工具策略选择器中 `skill_opt` 可勾选。

### 提示词配置与预览

- [ ] Given 智能体提示词配置页打开，Then 分区序列中出现技能索引占位卡片，位于系统区之后、常驻工作区之前，无开关无输入框、不可移动不可删除，mobile 与 desktop 呈现一致。
- [ ] Given 当前项目有生效技能，When 任一端「查看提示词」，Then 技能索引作为独立分段出现，位置与配置 UI 展示一致；Given 无生效技能，Then 该分段不出现。
- [ ] When 分区顺序调整或核对，Then 配置 UI 展示顺序、实际组装顺序、分区顺序文案三者一致（含技能索引块）。

### 启停

- [ ] Given 技能 `foo` 为全局技能，When 用户在项目 A 的会话面板关闭它，Then 项目 A 后续会话不再注入 `foo`；项目 B 的会话不受影响；`foo` 文件本身未被改动。

### 管理页

- [ ] When 进入设置·技能管理页，Then 默认停在「全局技能」tab，项目 tab 按所有项目分组展示（不限于当前项目），两 tab 标题带计数。
- [ ] Given 全局技能 `foo` 被项目 A 覆盖，When 在全局 tab 查看，Then `foo` 行带「被项目副本覆盖」标签。
- [ ] When 对项目域技能执行「提升为全局」且全局已有同名，Then 弹出覆盖确认；确认后全局版被整目录替换（含辅助文件）。
- [ ] When 跨项目复制技能，Then 项目选择弹层不包含源项目；复制为整目录；目标已有同名时整包覆盖。
- [ ] When 删除技能，Then 有确认且文案说明影响范围；对应禁用记录被清理；若该技能正被详情/编辑器打开，视图安全返回管理页。
- [ ] When 在批量模式切换 tab，Then 自动退出批量模式；批量模式中行点击为勾选而非打开；未选中时删除按钮不可用。

### 新建 / 详情 / 编辑

- [ ] When 新建技能时名称含空格、斜杠或以 `.` 开头、或目标域内重名、或描述为空，Then 逐项报错不创建。
- [ ] When 新建成功，Then 生成仅含 `SKILL.md` 的技能目录（front matter 含 name / description），并自动进入详情页。
- [ ] Given 详情页打开技能，When 尝试删除 `SKILL.md` 或新建名为 `SKILL.md` 的文件，Then 被拒绝并提示其为保留入口。
- [ ] When 在详情页新建辅助文件 `references/x.md`，Then 自动创建中间目录，成功后直接进入编辑器。
- [ ] When 新建辅助文件路径含 `..` 或与既有文件重名，Then 报错不创建。
- [ ] Given 编辑器打开技能文件且有未保存更改，When 返回，Then 弹出离开确认；保存后更改写回技能文件。
- [ ] When 编辑器打开技能文件，Then 标题为「技能 · {名称}」，路径 chip 显示 `meta/skills/...`，域徽标显示域与生效范围。

### 聊天卡片

- [ ] Given AI 成功创建/更新技能，When 消息流渲染，Then 出现对应技能工具卡片（含状态、技能名、域、路径），点击直达该技能详情页。

### $ 引用

- [ ] Given 输入框光标位于行首或空格后，When 手动输入 `$`，Then 拉起技能 typeahead（≤5 条，按名称/描述模糊匹配）；点选后插入 `$技能名` token 并补尾空格。
- [ ] When 点击工具栏 `$` 按钮，Then 打开技能选择器：平铺技能列表、合并视图、同名标覆盖、无效技能不出现；确认后 token 插入正文。
- [ ] Given 已关闭的技能在选择器中被选中并引用，When 提示词拼装，Then 该技能全文照常注入（显式引用优先于负清单）。
- [ ] Given 发送含 `$技能名` 的消息，Then 正文 token 保留，且消息附件中出现对应技能引用；纯 `$技能` 无其他正文时可发送。
- [ ] Given 输入含不存在技能名的 `$` token（如技能已删除），When 发送，Then 消息可正常发送、附件照常落库，且提示词中出现一行「技能不存在或已删除」提示而非全文。
- [ ] Given 可见历史中该技能首次被 `$` 引用，When 提示词拼装，Then 含 `SKILL.md` 全文；同技能第二次引用只留短标记；置位/压缩后再次引用重新附全文。
- [ ] When 在 mobile 输入框退格删除 `$技能名` 标签，Then 整段原子删除；When 在 desktop 输入框输入 `$技能名`，Then 高亮层着色。

### 隔离豁免

- [ ] Given 项目与全局域存在技能，When 执行会话工作区初始化或模板同步，Then 技能目录不被复制、不被删除、不被重置。
- [ ] Given 上一会话创建的项目技能，When 同项目新建会话，Then 该技能立即可用。

## 风险与待确认项

| 风险 / 待确认 | 说明 |
|------|------|
| 全局 tab「被项目副本覆盖」标签的判定范围 | 已拍板（SPEC D5）：按「任意项目存在同名副本」判定，与项目 tab 展示所有项目的全局语境一致；tooltip 注明该全局版仅对无副本的项目生效。 |
| 全局域禁用的 UI 写入路径 | 会话面板开关固定写当前项目的禁用记录，「仅对某个项目禁用全局技能」有通路；「全局层面禁用（所有项目）」目前无 UI 入口，是否在管理页全局 tab 补开关待定。 |
| desktop 项目/会话视图内全局树不可见 | 既有缺口：desktop 进入项目或会话视图后看不到 global 域文件树。技能管理页若独立成页则不受影响，但与文件浏览器的联动体验受此约束，是否顺手修复待定。 |
| 索引体积随技能数增长 | 索引常驻注入，技能数量多时提示词体积线性增长；短期靠描述长度约束，长期可能需要分组/检索式注入，暂不纳入本期。 |
