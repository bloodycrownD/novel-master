# 功能优化批次 2026-09 PRD（迭代总纲）

## 背景

2026-09-06 头脑风暴对四个优化点做了全链路只读探索（记录见 `docs/apm/memory/20260906-optimization-brainstorm.md`），用户逐项拍板后立项本迭代：

1. **聊天工作区与项目工作区目前只有单向同步**：新建会话自动从项目工作区初始化，手动「从上级同步」也只会用母本覆盖聊天工作区；会话中产出满意内容后没有固化回母本的通道。用户要求补一个反向「推送」按钮，行为与拉取对称。
2. **正则系统（v1.4.21 上线的消息正文替换系统）确认整体移除**：使用价值不足、历史上曾引发流式渲染 bug；用户已拍板接受失去「用户配置正文清洗」这一唯一出口。
3. **移动端统计图表缺标准能力**：条形图无纵坐标刻度、饼图无常驻百分比，用户拍板移动端重做；desktop 本批不动。
4. **mermaid 引擎经 11.16.1/11.17.2 双版本对照实测无语法缺失**（opt/loop/par 均支持，失败源于图源码写法）——结论：不做任何 mermaid 相关变更（用户拍板，曾立项的「语法指南并入 agent 配置指南」已撤销）。

## 目标（含成功指标）

三个功能改动一次交付：推送按钮补全双向同步、正则系统全量移除、移动端统计图表重做为标准形态。成功 = 各 feature 验收标准全绿，双端与 CLI 行为符合预期。

## 用户与场景

单一用户（小说作者本人）；场景分别是：把会话成果固化为项目模板、精简不用的功能面、在手机上快速读统计图表、让写作 agent 生成可靠的 mermaid 图。

## 范围

### 包含范围

- `features/workspace-push/prd.md` — 聊天工作区「推送到项目工作区」
- `features/regex-removal/prd.md` — 正则系统全量移除
- `features/mobile-charts-redo/prd.md` — 移动端统计图表重做

### 不包含范围

- mermaid 相关的一切变更：引擎升级（实测无必要，11.17.2 行为与 11.16.1 一字不差）与提示词/技能/文档改动均不做（用户已否决）
- desktop 统计图表改造（已有两档刻度，本批接受双端不对称）
- 正则系统的任何替代方案

## 验收标准（迭代级）

- 三个 feature 各自 PRD 的验收标准全部满足。
- CHANGELOG Unreleased 含对应条目（新增推送、移除正则、图表改进）。
