# 移动端统计图表重做 PRD

## 背景

移动端数据统计页（v1.5.11 上线的三页签：汇总/图表/流水）图表为纯自绘极简形态：条形图只有 1/3、2/3 两条参考线加右上角一个最大值标签，没有纵坐标刻度；饼图不常驻显示百分比，占比只在点选扇区/图例后的详情行里出现（当初 spec 拍板的点选式交互）。desktop 同类图表已有 max+mid 两档刻度与 hover 提示。用户反馈「这难道不是标准能力吗」，拍板移动端图表重做补齐标准可读性；desktop 本批不动。

## 目标（含成功指标）

移动端统计图表具备标准可读性：条形图有带刻度值的纵坐标参考系，饼图占比百分比常驻可见。成功指标：不点选、不悬停，仅看图即可读出各切片相对占比与柱高量级。

## 用户与场景

小说作者在手机上查看 token 用量统计：汇总页看各服务商×模型的用量分布（饼图），图表页看按天/按小时趋势（条形图），需要快速读出「谁占大头」「哪天用得多」，而不必逐个点选。

## 范围

### 包含范围

- 汇总页饼图：占比百分比常驻呈现
- 图表页按天条形图与 24 小时条形图：纵坐标刻度（轴线/网格 + 刻度值）
- 重做后与统计页现有视觉风格（卡片、色板）保持一致
- 既有交互保留：点选扇区/图例出详情行、长按检视、按天钻取 24 小时

### 不包含范围

- desktop 统计图表（本批接受双端不对称，后续单独处理）
- 新增图表类型或新增统计维度
- 数据层聚合逻辑变更（数据与筛选口径不动）
- 流水页签（表格形态，非图表）

## 核心需求

1. 条形图具备纵坐标：网格参考线 + 均匀刻度值（含 0 与当前最大值，中间至少一档），刻度值用压缩格式（如 1.5K）。
2. 饼图占比常驻可见：每个切片的百分比无需交互即可读到（图例行或切片标注，具体形态 spec 定）；点选详情行交互保留。
3. 重做组件与现有页面风格一致，不引入破坏现有布局的视觉变化。
4. 既有测试契约（网格线、详情行、色板）同步更新，覆盖不回退。

## 验收标准

- Given 图表页任意时间窗口有数据，When 查看按天条形图，Then 图上可见纵坐标刻度（至少 3 档：0、中间档、最大值）。
- 同场景查看 24 小时条形图，纵坐标刻度同样满足。
- Given 汇总页饼图有多个切片，When 直接查看，Then 无需点选即可看到每片占比百分比。
- 点选切片/图例仍出详情行（label · 用量 · 次数 · 占比），长按检视与钻取不受影响。
- mobile 测试全绿（含更新后的图表契约断言）。

## 风险与待确认项

- 百分比呈现形态（图例行追加 vs 切片直标及小切片处理）与是否引入图表库（现为自绘无依赖）属 spec 决策。
- 刻度档数与压缩格式的具体视觉规格在 spec/实现阶段定稿。
