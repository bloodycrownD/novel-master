# 连接模型与服务商

Novel Master 通过「服务商」连接大模型。一个服务商保存一组接口信息：服务商名称、协议、Base URL 和 API Key；模型挂在服务商下面，每个模型还可以单独设置采样参数。把某个已保存的模型选为当前模型之后，对话才会真正调用它。

下面按「添加服务商 → 添加模型 → 选择当前模型」的顺序，说明连接 API、管理模型和调整参数的完整操作。入口与界面文案以 Android 手机端为准。

::: tip
第一次配置时，先添加服务商并填好 API Key，再在它的「模型管理」页签里添加至少一个模型，最后到「我的 → 当前大模型」把当前模型切过去。
:::

## 服务商、模型与当前模型

| 概念 | 含义 |
|---|---|
| 服务商 | 一组模型接口的连接配置：服务商名称、协议、Base URL、API Key；在「高级」里还可以追加请求头和请求体参数。 |
| 模型 | 挂在某个服务商下的可调用模型，保存「厂商模型 ID」与显示名，可以单独配置采样参数。 |
| 当前模型 | 对话实际使用的模型。工作区有一份全局选择，单个会话可以单独覆盖。 |

服务商与模型是一对多的关系：同一个服务商下可以保存多个模型，模型选择器会把所有服务商的已保存模型放在一起供选择。

## 入口速查

| 操作 | 入口 |
|---|---|
| 添加服务商 | 我的 → 服务商配置 → 添加 |
| 修改服务商信息或更换 API Key | 我的 → 服务商配置 → 点某个服务商行 |
| 添加模型 | 我的 → 服务商配置 → 某服务商 → 「模型管理」页签 |
| 配置某个模型的采样参数 | 我的 → 服务商配置 → 某服务商 → 「模型管理」页签 → 点某个模型 |
| 切换工作区当前模型 | 我的 → 当前大模型 |
| 切换当前会话的模型 | 对话 tab → 顶栏 ☰（对话态）→ 会话详情页 → 当前大模型卡 |
| 就地切换当前会话的模型 | 对话 tab → 对话页 meta 条 → 点模型名 |
| 删除服务商 | 我的 → 服务商配置 → 某行「⋮」→ 删除 |

## 我的页：配置总目录

**入口：底部 tab 第 2 个「我的」**

「我的」是绝大多数配置页的统一入口，页面分三段：

| 分组 | 菜单项 |
|---|---|
| 「工作区」 | 「当前大模型」「当前智能体」「文件浏览器」 |
| 「配置」 | 「智能体配置」「服务商配置」「搜索配置」「技能管理」「聊天配置」「存储配置」「数据统计」「智能排序」 |
| 「应用」 | 「关于 Novel Master」 |

只有「工作区」里的「当前大模型」和「当前智能体」两行右侧会显示当前取值，其余菜单行只有名称。与本文相关的是「当前大模型」这一行，以及「配置」里的「服务商配置」。

## 添加服务商

**入口：我的 → 服务商配置 → 添加**

进入「服务商配置」后，列表里每一行显示服务商名、已保存的模型数量和 API Key 状态标签（「已连接」或「未连接」）。列表顶部右侧是「添加」。

1. 点「添加」，进入「添加服务商」页。
2. 在「连接」段填写三项：
   - **「服务商名称」**：自定义一个容易辨认的名称，例如 `智谱`。
   - **「协议」**：在 `openai`、`anthropic`、`gemini` 三个选项中选择一个。
   - **「Base URL」**：填写接口地址，例如 `https://api.example.com/v1`。
3. 在「认证」段填写 **「API Key」**。这一项必填，会写入系统安全密钥存储。
4. 在「高级」段按需填写可选项：
   - **「Headers JSON」**：必须是 JSON 对象，例如 `{"X-Custom":"value"}`；留空表示不设置。
   - **「自定义参数」**：JSON 对象，会原样合并进请求体顶层，可以覆盖标准字段，例如 `{"tool_stream": true}`；清空后保存即移除。
5. 点页面底部的「创建」。

创建成功后会进入这个服务商的详情页。切到「模型管理」页签，就可以继续添加模型。

::: tip
「Headers JSON」和「自定义参数」都必须是 JSON 对象。格式不合法时保存会被拦下，先检查引号和括号。
:::

### 中转站与自建端点

协议选 `openai`，绝大多数中转站和自建网关都兼容 OpenAI 协议；Base URL 填中转地址。地址末尾的 `/v1` 要与服务商文档保持一致，不要自己添加或删除。如果中转站需要额外的鉴权头或额外参数，用「高级」里的「Headers JSON」和「自定义参数」补上。

## 修改服务商信息或更换 API Key

**入口：我的 → 服务商配置 → 点某个服务商行**

点某个服务商行进入详情页。页内有「服务商配置」和「模型管理」两个页签，连接信息在「服务商配置」页签里修改。

1. 在「认证」段查看「当前状态」，它会显示 API Key 是「已连接」还是「未连接」。
2. 修改需要变更的字段。
3. 「API Key」留空表示不修改，只有填入新值才会覆盖旧值。
4. 点页面底部的「保存」。

::: warning
只改服务商名称或 Base URL 时，不要把「API Key」清空。留空就是保持原样，填入新值才会替换；这样不会因为改名把原来的 Key 抹掉。
:::

## 添加模型

**入口：我的 → 服务商配置 → 某服务商 → 「模型管理」页签**

「模型管理」页签里是已保存模型的列表，顶部有「管理」「远程」「添加」三个按钮：「管理」进入批量模式，「远程」和「添加」分别对应两种添加方式。

### 从服务商远程拉取

1. 点「远程」，应用会向厂商拉取一份可用模型清单。
2. 在顶部的输入框「过滤模型…」里输入关键字，筛选清单。
3. 勾选需要添加的模型，点「添加」把它们保存到列表。

::: tip
有些中转站不支持列模型的接口，这时「远程」可能拉不到任何模型。改用下面的手动添加，直接填「厂商模型 ID」即可。
:::

### 手动添加

1. 点「添加」，打开「添加模型」。
2. 填写两个字段：
   - **「厂商模型 ID」**：真正发给服务商的模型标识，必填。
   - **「模型名称（可选）」**：给自己看的显示名，可以不填。
3. 确认后模型加入列表。

### 模型行的操作

- 点整行，进入这个模型的「采样配置」。
- 点行尾的「⋮」，打开菜单，可以选择「重命名」或「删除」。
- 点列表上方的「管理」进入批量模式，勾选多个模型后可以一次删除；批量模式下点行不会进入采样配置。

## 采样配置

**入口：我的 → 服务商配置 → 某服务商 → 「模型管理」页签 → 点某个模型**

页面分「模型」「内部预算」「生成参数」三段。

### 模型

- **「模型名称」**：修改这里的名字会同步修改显示名。
- **「厂商 ID：…」**：冒号后面是实际发给服务商的模型标识，随模型不同而变化，界面上不可修改。

### 内部预算

- **「上下文上限 (tokens)」**：必须是正整数，填写有误时保存会被拦下。
- **「计数方式」**：默认按模型名自动匹配分词器族，也可以手动指定。

这一段的两个字段用于应用内部的上下文预算计算，不直接映射成发给服务商的 HTTP 生成请求参数。

### 生成参数

字段按服务商协议分开显示：

| 协议 | 可调字段 |
|---|---|
| `openai` | 「温度」「Top P」「输出最大长度」 |
| `anthropic` | 「温度」「Top P」「Top K」「输出最大长度」 |
| `gemini` | 「温度」「Top P」「Top K」「输出最大长度」 |

这一段还有「思考强度」，按需调整。区头右侧的「恢复默认」会把「上下文上限」和采样参数一起恢复成默认值。

点页面底部的「保存」写回。生成参数会随请求发送给服务商，影响模型实际生成时的采样行为。

::: tip
「生成参数」区标注「展示协议推荐默认值；保存后以本页为准」：没有填写的字段会先显示协议推荐的默认值，保存后以本页填写的值为准。
:::

## 选择当前模型

选择当前模型有三个入口，效果都是切换模型，但作用域不同。

### 工作区级

**入口：我的 → 当前大模型**

点一下弹出模型选择器，切换的是工作区级的当前模型，全局生效。

### 会话级

**入口：对话 tab → 顶栏 ☰（对话态）→ 会话详情页 → 当前大模型卡**

**入口：对话 tab → 对话页 meta 条 → 点模型名**

这两个入口都会带上当前会话，只改这一个会话使用的模型，不会回退到工作区设置，也不会污染工作区的默认值。meta 条是更快的一条路，点一下就地弹出选择器。

### 模型卡被锁定

智能体配置了专属模型（pin）时，模型卡会锁住：右侧显示 🔒 而不是 ›，整张卡降低透明度，点击会弹出提示，不允许切换。想自由切换模型，需要到「智能体配置」里打开该智能体，把「专属模型」改回「默认(跟随)」，具体操作见[「智能体」](/docs/guide/agents)。

::: tip
模型选择器为空时，页面会提示「暂无已保存模型。请先在「服务商」页添加模型。」按提示先到服务商下添加模型。
:::

## 切换服务商

服务商本身没有「当前」这个概念。工作区有一份全局的当前模型，单个会话还可以单独覆盖，所以换服务商的实际操作是：把新服务商的模型添加进来，再用「选择当前模型」里的入口把当前模型切到新服务商名下的模型。

## 删除服务商

**入口：我的 → 服务商配置 → 某行「⋮」→ 删除**

删除会二次确认。也可以点列表上方的「管理」进入批量模式，勾选多个服务商后一次删除。列表支持下拉刷新。

::: warning
删除服务商会连同它名下所有已保存的模型与采样配置一起移除，确认前先看清范围。
:::

## 常见问题

### Base URL 末尾的 `/v1` 怎么写

与服务商文档保持一致。有的服务商需要 `/v1`，有的不需要，不要自己猜，也不要随手增删。

### 改了服务商名称，API Key 好像没了

API Key 留空表示不修改，把这一栏清空不会覆盖已保存的 Key，只有填入新值才会替换。如果「当前状态」显示「未连接」，说明这个服务商还没有保存过 Key，补填一次即可。

### 模型卡点不动

多半是这个智能体配置了专属模型。到「智能体配置」里打开该智能体，把「专属模型」改回「默认(跟随)」，模型卡就会解锁。

### 远程拉取拉不到模型

有些中转站不支持列模型的接口。改用手动添加，直接填「厂商模型 ID」即可。

### 找不到已保存的模型列表

点某个服务商行进入详情页，页面上方有「服务商配置」和「模型管理」两个页签，切到「模型管理」才能看到已保存模型。

### 保存采样配置时被拦下

检查「上下文上限 (tokens)」是否为正整数。填写负数、小数或留空都无法保存。
