# 数据管理

Novel Master 的设置入口集中在底部「我的」tab。除了写作相关的智能体、服务商与技能配置，还有一组页面负责数据本身：搜索用哪个引擎、数据库怎么备份和同步、用量怎么看、文件列表怎么排序，以及版本更新与消息通知。本文按页面说明这些功能的入口和操作。

## 搜索引擎

Agent 需要查资料时会调用搜索工具。搜索请求按配置页里的引擎顺序依次尝试，失败会自动降级到下一个已配置的引擎。

**入口：我的 → 搜索配置**

列表按优先级从上到下排列：

| 引擎 | 副标题 |
|---|---|
| Bocha | 按量计费 · 中文检索 |
| Tavily | 按量计费 · 国际 |
| Brave | 按量计费 · 国际 |
| SearXNG | 自托管 · 免费 |
| DuckDuckGo | 内置 |

每行右侧显示配置状态标签；DuckDuckGo 一行固定显示「内置」。

### 调整优先级

**入口：我的 → 搜索配置 → 行「⋮」→ 上移 / 下移**

排在第一位的引擎是默认引擎。列表首行的「上移」和末行的「下移」不可用。

### 配置密钥

**入口：我的 → 搜索配置 → 点某一行**

进入后页面标题会变成引擎名。不同类型的引擎填写方式不同：

- **Bocha / Tavily / Brave**：填写「API Key」。留空保存不会修改已保存的密钥；已保存过密钥时，可以点「清除已存密钥」清除。
- **SearXNG**：填写「实例地址 Base URL」。留空保存即清除。
- **DuckDuckGo**：内置引擎，无需配置。

填完点底部的「保存配置」。页面只显示是否已配置，不会回显明文。SearXNG 的地址会做校验，带 userinfo（用户名@密码）的写法会被拒绝。

### 使用说明

**入口：我的 → 搜索配置 → 标题栏「?」**

弹窗「使用说明」分三段：

- **引擎优先级**：列表顺序即搜索时尝试引擎的顺序，第一位为默认引擎；未配置任何引擎时由内置 DuckDuckGo 免费兜底（无需密钥）。
- **自动降级**：请求失败（如密钥失效、超时）时自动尝试下一个已配置引擎，直到成功。
- **密钥安全**：API key 仅存本机安全密钥库，不进入会话记录，不随云同步上传。

::: tip
一个 key 都不配置也能搜索，此时会走内置的 DuckDuckGo。
:::

## 存储配置与备份

**入口：我的 → 存储配置**

页面包含「存储空间」卡、「云端配置」、「数据清理」、「导出数据库」和「导入数据库」等项。

### 存储空间与数据清理

「存储空间」卡显示「库体积」和「可回收」两个指标，单位按 KB / MB / GB 自动换算。

「数据清理」行的右侧显示「清理数据库空间」。Agent 运行中，这一行会变成「Agent 运行中」，不能点击。开始清理前会提示预计耗时，清理期间不要关闭应用。

### 导出数据库

**入口：我的 → 存储配置 → 导出数据库**

导出会生成一份数据库备份文件，可用于换机、留档或导入回本机。

::: warning
备份文件包含聊天记录明文，请妥善保管，不要随意分享。
:::

### 导入数据库

**入口：我的 → 存储配置 → 导入数据库**

导入是**完全替换**：所选备份会覆盖当前的应用数据（项目、会话、消息等），操作前有二次确认，确认后不可撤销。

本机的服务商与 API Key 会保留；备份文件里带的服务商配置不会导入。

::: warning
导入前建议先执行一次「导出数据库」，为当前数据留一份备份。
:::

## 云同步

云同步把本机数据库快照推送到 S3 兼容存储，或从云端拉回本机。

**入口：我的 → 存储配置 → 云端配置**

### 同步状态与手动同步

页面顶部是「同步状态」卡，显示「本机 rev」「云端 rev」以及两者是否对齐；「从云端拉取」和「推送到云端」两行的右侧显示上次操作的结果与时间。

- 「云存储配置」：进入 S3 存储配置页。
- 「从云端拉取」：弹出二次确认，确认后开始拉取。拉取会用云端快照替换本机数据，本机服务商与 API Key 会保留。
- 「推送到云端」：不弹确认，直接开始推送。如果云端已被其他设备推进，会提示先拉取，避免覆盖较新的云端数据。

Agent 运行中，同步控件是禁用的，页面会提示「Agent 运行中，同步操作已禁用。」先等这一轮跑完再操作。

### 同步进度页

点「从云端拉取」或「推送到云端」后，会进入「云同步」进度页。进页即开始执行并显示进度，完成后自动返回。这个页面禁用了侧滑返回，也没有返回按钮，必须等它跑完。

### 配置 S3 兼容存储

**入口：我的 → 存储配置 → 云端配置 → 云存储配置**

页面分「S3 兼容存储」和「凭据」两段。

「S3 兼容存储」：

- 「Endpoint」：提示「含 https://」，占位 `https://s3.example.com`。
- 「Bucket」。
- 「Region」：提示「MinIO 可留空」。
- 「路径前缀」。
- 「Path style」：开关。

「凭据」：

- 「Access Key ID」。
- 「Secret Access Key」：已存过密钥时，占位显示「留空保留已存密钥」。
- 「设备名称（可选）」：占位「便于识别本机」。

填完点「测试连接」验证；确认无误后点底部的「保存配置」。

自建 MinIO 这类对象存储，Endpoint 填自己的地址，Region 留空，Path style 一般要打开。

## 数据统计

**入口：我的 → 数据统计**

<ShotStrip :items="[['/screenshots/stats.png', '数据统计：图表 / 汇总 / 流水']]" />

数据统计页按时间、服务商和模型汇总本机的 token 用量与缓存命中率，并保留每次请求的明细。

### 筛选

顶部是筛选栏：

- 时间范围：「今天」「近 7 天」「近 30 天」「自定义」。选「自定义」会弹起止月份选择面板。
- 模型与服务商：可以筛到某个服务商下的具体模型。

筛选条件跨页签保留，切换页签不会重新查询。

### 三个页签

| 页签 | 内容 |
|---|---|
| 「汇总」 | 七个指标卡：总 token、调用次数、平均速率、平均首字延迟、输入、输出、命中率；下方是「服务商 × 模型」饼图。 |
| 「图表」 | 按天的堆叠柱状图，柱子上可以钻取到 24 小时。 |
| 「流水」 | 请求级明细分页列表，逐条可查。 |

### 空态

空态会区分两种情况：

- 整个库还没有数据：显示冷启动引导，说明统计从什么时候开始积累。
- 选定范围内没有数据：提示「该区间无数据」。

两种提示不一样，不是故障。

## 智能排序

**入口：我的 → 智能排序**

智能排序规则决定文件列表怎么自动排序。比如内置规则能识别章节号，让「第 3 章」排在「第 10 章」前面。

### 规则列表

**入口：我的 → 智能排序**

页面按优先级列出规则，每行有一个启用开关。点某一行进入规则详情。

**入口：我的 → 智能排序 → 行「⋮」**

菜单包含「编辑」「置顶」「上移」「下移」「置底」「删除」。内置规则不能删除，这一项不会出现。

**入口：我的 → 智能排序 → 顶栏「更多」**

菜单包含「导入 YAML」「导出 YAML」「恢复默认」。

**入口：我的 → 智能排序 → 顶栏「管理」**

进入批量模式，批量条提供「启用」和「禁用」；内置规则不可删除。

::: warning
「导入 YAML」会替换全部现有规则，包括内置规则的启停状态。导入前建议先「导出 YAML」留档。
:::

### 规则详情

三个入口都能打开规则表单：

- **入口：我的 → 智能排序 → 「新建」**
- **入口：我的 → 智能排序 → 点某一行**
- **入口：我的 → 智能排序 → 行「⋮」→「编辑」**

表单字段：

| 字段 | 说明 |
|---|---|
| 「启用规则」 | 开关，控制这条规则是否参与排序。 |
| 「名称」 | 规则名，占位「如 中文序号章节」。 |
| 「正则表达式」 | 支持 `/pattern/flags` 字面量写法，占位 `如 /第([0-9〇零一二两三四五六七八九十百千]+)章/i`。 |
| 「捕获数字」 | 三档：「智能数字」「固定最大」「固定最小」。 |
| 「描述」 | 占位「描述这条规则匹配什么，如 匹配 第X章 形式的标题」。 |

### 捕获数字三档

- 「智能数字」：从正则的捕获组里提取序号，中文数字和阿拉伯数字都能识别，比如「第十二章」和「第 12 章」都会得到 12。有多个捕获组时组成复合序号，比如「第 X 卷第 Y 章」得到 `[X, Y]`。这一档要求正则里至少有一个捕获组。
- 「固定最小」：命中即排在所有序号之前，适合序章、楔子一类。
- 「固定最大」：命中即排在所有序号之后，适合终章、番外一类。固定档不需要捕获组。

### 正则匹配测试器

1. 在「测试文本」里粘贴一段样例，比如几行章节标题。
2. 点「测试」。
3. 「结果」里会高亮所有匹配段，并列出每处提取到的元组和匹配计数。

改动「测试文本」、正则表达式或「捕获数字」中的任何一项，都会清空上一次的结果；改完重新点「测试」。

### 规则说明

标题栏的「?」打开「使用说明」，分「规则与优先级」「智能数字」「固定最大/最小」「正则格式」四段，补充说明规则的匹配顺序和正则写法。

## 关于与更新

**入口：我的 → 关于 Novel Master**

页面顶部显示应用图标、名称「Novel Master」和版本号。

### 更新

「更新」段有两项：

- 「自动检查更新」：开关，控制启动时是否自动检查新版本。
- 「检查更新」：点一下立即检查，行右侧显示上次检查结果。

**入口：我的 → 关于 Novel Master → 「检查更新」**

App 里没有自动更新安装包。检查到新版本会弹窗「发现新版本」，显示版本号和更新摘要；点「前往下载」会用浏览器打开 GitHub 发行页，下载和安装都要在浏览器里完成。不想被打扰可以点「稍后」，或者关掉「自动检查更新」。

开启「自动检查更新」时，启动后还会有一个应用级的「版本检查」弹窗，用于提示自动检查的结果：

- 已是最新：显示「当前已是最新版本」。
- 检查失败：显示「无法检查更新，请检查网络」。

弹窗可以点「关闭」，也可以点「今日不再提醒」，当天不再弹。

### 项目链接

「项目链接」段有三项，点开都会用浏览器打开：

- 「GitHub 仓库」
- 「发行版」
- 「许可证」

## 消息通知与聊天配置

**入口：我的 → 聊天配置**

页内主要是开关，切换后即时保存。

| 开关 | 说明 |
|---|---|
| 「父会话流式」 | 开启后主对话回复边生成边显示（推荐）；关闭则回复完成后一次性显示。 |
| 「子会话流式」 | 开启后子智能体回复边生成边显示；关闭则完成后一次性显示。 |
| 「思考提示词」 | 开启后模型的思考内容进入后续提示词，关闭则不进入。 |
| 「富文本消息」 | 开启后消息解析 Markdown/HTML，关闭显示纯文本。 |
| 「消息通知」 | 开启后进入应用即常驻状态栏保活，生成中显示状态，结束后台提醒。 |

### 通知权限

这一行只在 Android 上出现，值显示「已授权」「未授权」或「申请中…」。点它手动申请系统通知权限。

没授权时「消息通知」照样可以打开，只是系统不会真的弹出提醒，所以建议先授权再开。

关掉「消息通知」就是没有常驻通知、没有提醒，但不影响生成行为。

如果写库失败，开关会自动弹回原值，并提示「保存失败」，不会停留在假状态。

## 常见问题

### 一个 API Key 都没配，搜索还能用吗

能。未配置任何引擎时，搜索由内置的 DuckDuckGo 免费兜底，只是走的不是你自己配置的引擎。

### 导入数据库会把 API Key 弄丢吗

不会。导入会完全替换项目、会话、消息等数据，但本机的服务商与 API Key 会保留；备份文件里的服务商配置不会导入。

### 为什么清理和同步按钮点不了

Agent 正在运行。存储配置里的「数据清理」会显示「Agent 运行中」，云同步控件也会被禁用。等这一轮生成结束再操作。

### App 能直接更新吗

不能。App 只负责检查版本，查到新版本会引导到浏览器打开 GitHub 发行页，下载和安装要自己完成。

### 客户端有内容过滤吗

Novel Master 本身不内置内容过滤，能生成什么取决于所选模型和服务商的策略。需要调整时，可以从两个方向入手：

- 接入策略更宽松的服务商或模型。**入口：我的 → 服务商配置 → 添加**
- 在智能体的系统提示词里写明写作风格与尺度。**入口：我的 → 智能体配置 → 点某个智能体 →「提示词模版」→「系统区」**

这两个方向只调整你自己的配置，本文不提供具体的提示词内容。
