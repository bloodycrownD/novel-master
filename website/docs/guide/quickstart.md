# 快速上手

<ShotStrip :items="[['/screenshots/workspace.png', '会话工作区：卷纲 / 设定 / 章节 三层文件树']]" />

Novel Master 是专注长篇小说创作的 AI Agent 工作台。安卓端把世界观、人设、卷纲、章节统统放进一棵虚拟文件树，Agent 直接读写这些文件，你和它在同一个空间里对话改稿。底部只有两个 tab——「对话」和「我的」，绝大多数设置页都从「我的」进。

本页面向第一次使用的新用户，从下载安装开始，依次走完配置模型、新建项目、新建会话、放入设定、写出第一稿、查看工具卡、改稿和长对话收敛的完整流程。走完一遍，日常使用的主干路径就都熟悉了。

本页只讲 Android 手机端。桌面端的界面布局与手机端不同，不在本页范围内。

## 安装应用

### 从 GitHub Releases 下载 APK

1. 在手机浏览器中打开 [GitHub Releases](https://github.com/bloodycrownD/novel-master/releases)。
2. 找到最新的 Release。页面里有「下载 · Android」表格，列出本次发布提供的各个 APK 文件。
3. 多数手机下载通用包，文件名形如 `NovelMaster-<版本号>-universal.apk`。发布说明里的安装提示是：「多数手机请下载 universal；按 ABI 分包体积更小。」如果清楚自己设备的 ABI，也可以选对应的分包，文件名里会带 `arm64-v8a`、`armeabi-v7a`、`x86` 或 `x86_64`。

### 安装并打开

1. 下载完成后，在浏览器的下载列表或系统的文件管理器里点开 APK。
2. 系统可能会拦截一次未知来源安装，按提示允许当前浏览器或文件管理器安装应用。
3. 安装完成后打开 Novel Master，默认落在「对话」tab。

## 最短路径

如果只想尽快写出第一稿，记住四件事就够了：

1. 新建项目（第 1 步）。
2. 新建会话（第 2 步）。
3. 放入设定文件（第 3 步）。
4. 写第一稿（第 4 步）。

每一步的详细操作在后面的分步小节里。

::: tip
设定文件要写进「聊天工作区」，而聊天工作区属于具体的会话。所以顺序是先新建会话，再往会话工作区里放设定；「项目工作区」是只读的，不能直接写入文件。
:::

## 第 0 步：接入模型

没有可用的模型，后面的步骤都无法开始，所以先把服务商和模型配好。

配置顺序是：先添加服务商并给它添加模型，再选择当前模型。

**第一步：添加服务商。入口：我的 → 服务商配置 → 添加**

1. 点底部「我的」tab，再点「服务商配置」。
2. 点「添加」新建一个服务商，填写名称、协议、Base URL、API Key。

**第二步：选择当前模型。入口：我的 → 当前大模型**

1. 回到「我的」页，点「当前大模型」这一行，弹出模型选择器。
2. 选一个模型作为当前模型。

::: tip
新建的服务商下如果还没有模型，先到「模型管理」里添加模型，模型选择器里才会出现可选项。入口：我的 → 服务商配置 → 某个服务商 → 「模型管理」tab。
:::

服务商配置、模型管理、采样参数和中转站的填写方式，见[连接模型与服务商](/docs/guide/providers)。

## 第 1 步：新建项目

**入口：对话 tab → 顶栏 ☰ → 新建**

1. 打开 App，默认落在「对话」tab，顶栏显示当前项目名。
2. 点顶栏左上角的「☰」，弹出项目抽屉，抽屉标题是「项目」。
3. 点抽屉右上角的「新建」，弹出输入框，填写项目名（例如「科幻小说创作」），确定。

### 项目抽屉里的其他操作

- **切换项目**：点某个项目卡即可切换到该项目。卡片右下角有「当前」角标，标出你正在使用的项目。
- **重命名或删除**：点项目卡右边的「⋮」，菜单里有「重命名」和「删除」。删除会二次确认，并提示「将同时移除其下所有会话」，操作前需要确认清楚。
- **批量删除**：点抽屉顶栏的「管理」进入批量模式，勾选多个项目后一次删除。

## 第 2 步：新建会话

**入口：对话 tab → 列表头「新建会话」**

1. 保持在「对话」tab 的列表视图，顶部分段条默认停在「会话 / 项目工作区」的第一项。
2. 列表头顶部有「新建会话」按钮，点它。
3. 新会话创建后会自动进入对话视图。工作区是从项目模板复制过来的，在这个会话里怎么改都不会影响别的会话。

### 会话列表和聊天是同一个页面的两个视图

这是使用中必须知道的结构：会话列表和聊天对话其实是同一个页面里的两个视图，不是两个页面。列表视图的顶部分段条是「会话 / 项目工作区」；进入对话后，顶部分段条换成「聊天 / 聊天工作区」。

因此「返回」不是回到另一个页面，而是在这个页面里切回另一个视图。返回键逐层消费：先关弹层，再逐级退出工作区目录；从对话态返回会回到会话列表，再按一次就进入退出应用的流程。

### 会话行的操作

- **进入对话**：点一行。
- **行菜单**：点「⋮」打开菜单。运行中的会话会多一项「停止生成」；此外还有「重命名」「复制」「删除」。
- **批量操作**：长按一行进入批量模式，顶部出现「取消 / 已选 N 项 / 删除」。

## 第 3 步：放入设定文件

设定不应该塞在对话消息里，应该放成文件，让 Agent 按文件读取。

### 先看项目工作区

**入口：对话 tab → 项目工作区**

1. 在列表视图，点顶部分段条的「项目工作区」。
2. 这是项目域的文件树，只能浏览，不能修改。可以用它确认整个项目的默认文件结构长什么样。
3. 想真正动手改文件，需要切到会话工作区。

### 在聊天工作区里建文件

**入口：对话 tab → 进任意会话 → 顶部分段条「聊天工作区」**

1. 进入一个会话，把顶部分段条切到「聊天工作区」。
2. 这是会话域的文件树，可以读写，Agent 也主要在这里读写。
3. 顶栏的「⋯」更多菜单里有：「新建目录」「新建文件」「导入」「导出」「目录规则」。
4. 点「导入」会再弹一层形式菜单，三选一：「单文件」「ZIP 包」「角色卡」。
5. 点某个文件进入文件编辑器，点「保存」写回。

建议的目录结构如下，在「聊天工作区」里新建目录建出来：

```
/设定/世界观.md
/设定/人设.md
/卷纲/第一卷.md
/正文/01.md
```

::: tip
第一次使用时，最省事的做法是在「聊天工作区」里直接对 Agent 说：「帮我建一个 /设定 目录，里面放世界观.md 和人设.md 的空模板」，让它用文件工具替你创建，比逐项手点更快。
:::

工作区的三层结构、文件树操作和目录规则，见[工作区与文件](/docs/guide/workspace)。

## 第 4 步：写第一稿

<ShotStrip :items="[['/screenshots/chat.png', '对话：聊天面板与输入框']]" />

**入口：进会话 → 底部输入框**

1. 点底部输入框，输入内容并发送。
2. 回复以流式方式输出，边生成边显示。这个行为可以在「我的 → 聊天配置 → 父会话流式」关掉。
3. 生成过程中，发送按钮变成「终止」，想中途停止就点它。

### 输入框工具条

输入框工具条上有四个按钮，从左到右依次是：

- **⛶**：全屏编辑，适合写长段的写作要求。退出时内容自动回填到输入框，不单独保存。
- **@**：引用文件。点击后弹出文件选择器，可以层级浏览、多选，选中的文件会生成 `@路径` 标签。
- **$**：引用技能。点击后弹出技能列表，选中的技能会生成 `$技能名$` 标签。
- **发送 / 终止**：发送消息，或中断当前生成。

不想点按钮时，直接手打 `@` 或 `$` 也会弹出候选列表。

### 对话页的 meta 条

对话页顶部的 meta 条显示当前智能体名和当前大模型名。点智能体名会弹出智能体选择器，点模型名会弹出模型选择器。被智能体锁定的时候，点击会弹出提示，不允许切换。

## 第 5 步：查看工具卡

Agent 干活时会在对话里留下工具卡片，这是理解它行为的关键。不同卡片点开后去向不同：

- **task 工具卡**：代表主 Agent 派了一个子代理去干活。点这张卡进入「子会话」页，可以看到子 Agent 的完整消息历史（只读）。子会话里的 task 卡还能继续往下点，一层层下钻。
- **skill 工具卡**：点开进入技能详情页。
- **工具结果卡**：search、curl、grep 之类的工具结果。点开进入「轮详情」页，把这条结果整段铺开查看，可以长按复制。
- **文件工具卡**：点开会自动切到「聊天工作区」，并直接进入文件编辑器。

对话页还有一条指标条，显示本轮 token 用量。点它会弹出「用量详情」面板，里面有模型、输入、输出、缓存读取、缓存写入、缓存命中率、可见消息数、工具调用次数、上下文占用这些信息。

## 第 6 步：改稿

改稿有两条路：改文件里的内容，或者改对话里的消息。

### 路 A：划词批注定点改

<ShotStrip :items="[['/screenshots/annotate.png', '划词批注：选中正文写意见']]" />

这是最精准的改稿方式——指着文件里的某一段说明要怎么改。

**入口：对话 tab → 聊天工作区 → 点文件 → 右上切到「预览」→ Markdown 档 → 划词**

1. 进入会话，切到「聊天工作区」。
2. 点开要改的文件，进入文件编辑器。
3. 点右上角的「编辑/预览」切到预览态。
4. 预览态下面有「Markdown / 文本」两档，批注只在 Markdown 档可用。
5. 在正文里划一段词，弹出选择菜单，点「批注」，写批注说明，添加。
6. 同一处文字上有好几条批注时，会先弹「选择批注」，让你挑一条。
7. 点已有的批注下划线，可以查看、修改或删除。
8. 回到对话发送消息，批注会跟着一起发给 Agent，它按批注定点改。

::: warning
批注只在三个条件同时满足时可用：文件处于预览态、文件属于会话工作区、预览切在「Markdown」档。编辑态没有批注；项目工作区、全局文件浏览器、技能文件里的文件也没有。
:::

### 路 B：修改消息本身

**入口：对话 → 点消息气泡右上角的「⋯」**

菜单里有：编辑、复制、置位、分叉、回滚。其中「置位」只对用户消息出现，从工具卡里点开的菜单也没有这一项。

- **编辑**：修改这条消息的内容，然后重新发出去。注意内容不能为空。
- **复制**：复制这条消息的正文。

置位、回滚、分叉属于长上下文管理手段，见[上下文管理](/docs/guide/context)。

## 第 7 步：长对话收敛

<ShotStrip :items="[['/screenshots/context.png', '消息操作菜单：编辑 / 复制 / 置位 / 分叉 / 回滚']]" />

写长篇很容易聊着聊着上下文就撑爆了。常用的做法有三种。

### 置位

在某条用户消息上点「⋯ → 置位」，把那条消息定为可见起点，它之前的旧消息不再进入上下文。聊到一个新阶段时置一次位，效果很好。

### 压缩

上下文快满的时候压一下。

**入口：对话 tab → 顶栏 ☰（对话态）→ 会话详情页 → 压缩上下文**

也可以打开自动压缩，让它按 token 比例自己触发，配置方式见上下文管理页。

### 回滚

改砸了想退回去，在某条消息上点「⋯ → 回滚」。这是危险操作，菜单里标红，这条消息之后的消息会全部丢失。

详细的压缩配置、置位与回滚的差别、分叉怎么用，见[上下文管理](/docs/guide/context)。

## 常见坑

### 以为会话列表和聊天是两个页面

它们是同一个页面里的两个视图，进出会话就是在这一个页面里切换。返回键逐层消费：先关弹层，再逐级退出工作区目录；从对话态返回会回到会话列表，再按一次就进入退出应用的流程。

### 长按消息气泡想打开菜单

这个交互已经废弃，现在只有消息气泡右上角的「⋯」能打开消息菜单。

### 划词批注在别的场景找不到

批注只在「预览态 + 会话工作区文件 + Markdown 档」三个条件同时满足时才有。编辑态没有；项目工作区、全局文件浏览器、技能文件里的文件也没有。

### 在项目工作区里想改文件却发现改不了

项目工作区是只读的。要写文件，请切到会话工作区。

### 顶栏「☰」的行为不一致

在列表态，它弹出项目抽屉；在对话态，它直接跳转会话详情页。两个场景下不是同一个东西。
