# 技能

![技能](/screenshots/skills.png)

技能是一份遵循 SKILL.md 标准的说明文档。它不执行代码，而是进入提示词里的技能清单，由模型按「描述」判断当前任务要不要使用它。同一份技能可以在不同项目、不同会话里反复引用；社区现成的技能打包成 ZIP 就能导入。

## 三个概念

| 概念 | 含义 |
|---|---|
| 全局技能 | 所有项目都能用，存在全局域 |
| 项目技能 | 只在某一个项目里用，存在项目域 |
| 会话技能面板 | 当前项目的合并视图：全局 ∪ 项目，同名时项目那份覆盖全局那份 |

同名冲突时，项目副本优先。对于存在同名副本的项目，全局那份不生效；没有副本的项目仍然使用全局版。

## 技能管理

**入口：我的 → 技能管理**

页内有两个页签：

- 「全局技能」：跨项目共用的技能。
- 「项目技能」：只在所属项目生效，列表按项目分组展示。

全局页签下方会给出提示：「全局技能对所有项目生效。若任意项目存在同名副本，该项目优先使用副本——该全局版仅对无副本的项目生效。」

项目页签的提示是：「项目技能仅所属项目生效，同名时覆盖全局版。按所有项目分组展示全部项目技能。」

### 行的操作

- 点整行，进入「技能详情」。
- 点行尾的「⋮」，打开操作菜单：
  - 「编辑信息」
  - 「导出 ZIP」
  - 「删除」

全局页签里，如果某个技能在任意项目下有同名副本，这一行会带灰色标签「被项目副本覆盖」。

### 无效技能

SKILL.md 的 front matter 缺失、YAML 解析失败，或者字段不合法时，这个技能会被判为无效。行上会标出「无效 · 原因」，例如「无效 · front matter 不合法」。

无效技能仍然会出现在管理页，但：

- 「编辑信息」置灰，改不了名称和描述。
- 需要先进入「技能详情」，把 SKILL.md 本体修好。

### 批量删除

1. 点页面顶部的「管理」进入批量模式。
2. 勾选要删除的行。
3. 点「删除」。

批量模式下顶部会显示当前已选数量，点「取消」退出。切换页签也会自动退出批量模式。

删除范围会写在确认框里：全局技能提示「全局技能删除后影响所有项目」，项目技能则会说明只影响所属项目，并把项目名带出来。确认框还会提醒「删除会清理整目录与对应禁用记录」。

::: warning
删除是破坏性操作，确认前先看清影响范围。全局技能删掉后，所有依赖它的项目都会失去这个技能。
:::

## 新建技能

**入口：我的 → 技能管理 → 「新建」**

列表为空时，页面中间的「新建技能」按钮也能打开同一个弹窗。

弹窗标题是「新建技能」，有两条创建路径。

### 手动创建

1. 填「技能名（即目录名，可在管理页重命名）」，占位提示是「如 worldbuilding-checker」。
2. 填「描述」，占位提示是「进入技能索引，模型据此决定是否使用」。
3. 从「项目技能」页签新建时，还要确认「所属项目」。这里默认选中第一个项目，可以点开修改。
4. 点「创建」。

「描述」不能为空。它是模型判断要不要使用这个技能的唯一依据，写清楚技能解决什么问题、什么场景该用。

技能名有几条限制：不能包含空白字符和「/」，不能以「.」开头，也不能使用保留名「SKILL.md」。

创建成功后，会直接进入「技能详情」。

### 从 ZIP 导入

1. 在弹窗里点「从 ZIP 导入…」，选一个 zip 文件。
2. 预检通过后，弹窗显示「已导入 ZIP · N 个文件（创建后全部带入）」，同时从 SKILL.md 的 front matter 里读出「技能名」和「描述」并预填。
3. 预填的值可以修改。只要改过，创建时会用表单里的值重写 SKILL.md 的 front matter，正文保留不动。
4. 点「创建」，zip 里的全部文件会落入新技能的目录，创建完直接进入「技能详情」。

导入后如果不想用这个 zip 了，点这一行右侧的「移除」，回到手动填写。

ZIP 的格式要求是 **zip 根目录就是技能目录**，也就是打开 zip 第一层要能看到 SKILL.md，而不是再套一层文件夹。

导入失败时常见两种提示：

- 「ZIP 根目录缺少 SKILL.md（导出格式：zip 根即技能目录）」
- 「目标域已存在同名技能「xxx」」

第二种表示目标域里已经有同名技能，新建不会覆盖，得改名或者先删掉旧的。

::: tip
front matter 只接受 `name` 与 `description` 两个字段，多写字段会被判为无效。从别处拿到的 SKILL.md 如果带了额外元数据，导入后可能显示「无效」。
:::

## 编辑技能信息

**入口：我的 → 技能管理 → 某行「⋮」→「编辑信息」**

弹窗里可以改两样：

- 「技能名」：技能目录名，改名会同步迁移目录和 SKILL.md 的 front matter。
- 「描述」：进入技能索引的说明，模型据此判断是否使用。

改完点「保存」。只改描述也可以单独保存。

::: tip
全局域的内置技能不能改名，技能名输入框是只读的，只能改描述。
:::

无效技能的「编辑信息」是灰的，先按上一节修好 SKILL.md。

## 导出 ZIP

**入口：我的 → 技能管理 → 某行「⋮」→「导出 ZIP」**

导出格式同样是 zip 根即技能目录。导出的 zip 可以直接发给别人，用「从 ZIP 导入…」重新导入。保存成功会提示「ZIP 已保存到所选位置」。

## 技能详情

三个入口都能进：

- **入口：我的 → 技能管理 → 点某一行**
- **入口：对话 tab → 顶栏 ☰（对话态）→ 会话详情页 → 技能卡 → 点某一行**
- **入口：对话 tab → 进会话 → 点对话里的 skill 工具卡片**

详情页就是技能内部的文件浏览器：

- 主文件是 SKILL.md，旁边可以有辅助文件。
- 点任意文件进入编辑器，改完可以保存。
- 可以新建、删除辅助文件。SKILL.md 是技能入口文件，不能删除或重命名。
- 如果技能在别处被并发删除，页面会提示「技能不存在或已被删除」并退回上一页。

## 会话技能面板

**入口：对话 tab → 顶栏 ☰（对话态）→ 会话详情页 → 技能卡**

这个面板显示当前项目的合并视图：全局技能 ∪ 项目技能，同名时项目那份覆盖全局那份。行上的徽标会标出「全局」「项目」或「项目 · 覆盖全局」。

每行右侧有一个开关，它写的是 **当前项目的负清单**：

- 关掉一个全局技能，只是把它加进当前项目的禁用名单，其他项目照旧能用。
- 关掉一个项目技能，同样只影响当前项目。
- 关闭的行会整体变淡。
- 无效技能的开关是禁用的，行上会给出原因标签。

面板列表为空时，会显示「新建技能」按钮，建出来的技能固定属于项目域，创建完直接进「技能详情」。

::: tip
这里管的是「当前项目默认用不用这个技能」。想删除技能、修改技能信息，或者让改动对所有项目生效，要回「我的 → 技能管理」。
:::

## 在对话里使用技能

### 从输入区引用

**入口：对话 tab → 进会话 → 输入区工具条的「$」按钮**

点开后弹出「引用技能」选择器，当前项目的可用技能平铺单选。已被当前项目关闭的技能也会列出来，带「已关闭」标注。

选中后，技能会以 `$技能名$` 标签的形式插入输入框，跟这条消息一起发出去。

也可以直接在输入框里手打 `$技能名$`，发送时同样按技能引用处理。

::: tip
显式引用优先于项目负清单。标着「已关闭」的技能，用 `$` 显式引用后依然会在这一轮生效。

无效技能不会出现在「引用技能」选择器里，因为它没有可读的 SKILL.md。
:::

### 技能索引区

**入口：我的 → 智能体配置 → 某个智能体 → 「提示词模版」→「技能索引区」**

这一区不是插入引用的入口，而是控制技能清单怎么呈现给模型：

- 「技能索引区」里的清单由运行时自动注入，只读。
- 「索引前缀语」可以编辑，它决定模型看到的技能清单前那段说明怎么写。

## 安装从别处拿到的技能

1. 先检查 zip：根目录直接是技能目录，里面是 SKILL.md 和辅助文件，不要多套一层文件夹。
2. **入口：我的 → 技能管理 → 「新建」**
3. 点「从 ZIP 导入…」，选中这个 zip。
4. 检查预填的「技能名」和「描述」。描述要能说明这个技能什么时候用，模型才判断得准。
5. 点「创建」，完成后进入「技能详情」，可以继续查看或修改文件。
6. 想让它在某个项目里默认生效：进入那个项目的会话 → 对话 tab → 顶栏 ☰（对话态）→ 会话详情页 → 技能卡 → 打开对应技能的开关。

装好后，在对话里通过输入区的「$」按钮或手打 `$技能名$` 就能引用它。

## 常见问题

### ZIP 导入提示根目录缺少 SKILL.md

打包时多套了一层目录。zip 打开后第一层应该直接是 SKILL.md 所在的技能文件夹，不是它的父目录。

### 「创建」按钮点不了

描述为空。描述是必填项，也是模型判断是否使用这个技能的唯一依据。

### 提示目标域已存在同名技能

新建不覆盖同名技能。换一个技能名，或者先删掉目标域里的旧技能。

### 在会话面板关了技能，会影响别的项目吗

不会。面板里的开关写的是当前项目的负清单，只影响这一个项目。要全局处理，去「我的 → 技能管理」。

### 技能显示「无效」

SKILL.md 的 front matter 不合法：可能是缺失、YAML 写错，或者字段不符合要求。这时「编辑信息」是灰的，进「技能详情」打开 SKILL.md 修改本体。

### 对话里选不到某个技能

先看它在「我的 → 技能管理」里是不是无效状态。「引用技能」选择器只列出有效技能，无效技能要先修好 SKILL.md。已经关闭的技能仍然会出现，只是标着「已关闭」。

另外确认它是当前项目的项目技能——别的项目的项目技能不会出现在这个项目的合并视图里。
