# 智能体

![智能体](/screenshots/agents.png)

智能体是一套角色预设：它决定一次对话里 AI 的名称、系统提示词、能调用哪些工具，以及是否固定使用某个模型。应用内置了一个 `general`，是一个通用的全能角色，多数写作场景直接使用它就够了；需要细分角色时，比如只读分析员、资料整理员，可以自己新建。

智能体分为两类：

- **主智能体**：可以直接选用，作为对话主体。
- **子智能体**：由主智能体在任务中委派调用。

::: tip
调整完记得在编辑页点「保存」，再回到会话里验证效果。
:::

## 智能体列表

**入口：我的 → 智能体配置**

页面顶部有「新建」按钮，页内用两个页签分开管理：

- 「主智能体」
- 「子智能体」

「子智能体」页签的第一行固定是内置的 `general`，只读。点进去后，所有控件都会灰显，页面没有保存栏，顶部横幅显示「内置智能体，不可编辑」。

行的操作：

- 点行进入该智能体的编辑页。
- 点「⋮」打开菜单，可以「重命名」「复制」「删除」。
- 列表顶部的「管理」按钮进入批量模式，勾选多行后可以一次删除。
- 内置的 `general` 不提供「⋮」菜单，不能重命名、复制或删除。删除其他智能体时，建议至少保留一个可用的智能体。

## 新建与编辑智能体

**入口：我的 → 智能体配置 → 「新建」**

**入口：我的 → 智能体配置 → 点某一行**

编辑页从上到下分为「基本信息」「模型」「运行时」「工具策略」「提示词模版」几个区块。

### 基本信息

这一区包含以下字段：

- 「名称」
- 「作用域」（mode）
- 「描述」

这一段还有「导入 YAML」和「导出 YAML」。导入会覆盖当前配置，并弹出二次确认。

### 模型

可以给这个智能体指定「专属模型」。

::: warning
指定之后，这个智能体运行的所有会话都会锁死使用这个模型，会话详情页的模型卡也会跟着锁定。想让会话自由换模型，就不要指定专属模型。
:::

### 运行时

「最大步数」（maxSteps）：限制单轮任务中模型与工具的往返次数。

### 工具策略

「模式」有三档：默认、白名单、黑名单，具体选项在「工具名单模式」里选。

- 选白名单时，显示「白名单工具」选择器。
- 选黑名单时，显示「黑名单工具」选择器。
- 保持默认时，下方提示：未配置时使用全部内置工具（11 个）。

11 个内置工具的职责如下：

| 工具 | 作用 |
|---|---|
| `read` | 读工作区单个文件的文本（只读，大文件可分段续读） |
| `write` | 写入或整文件覆盖（不存在的文件会创建） |
| `edit` | 文件内精确文本替换，适合小范围修改 |
| `fs` | 文件系统命令：列目录、删除、移动、复制、新建目录等 |
| `glob` | 按 glob 模式找文件路径（如 `**/*.md`） |
| `grep` | 在文件内容里搜索关键词或正则，返回路径、行号与摘录 |
| `skill` | 装载与查看技能（读取技能的 SKILL.md 后开始工作） |
| `agent` | 在对话里管理智能体定义（列出 / 查看 / 新建 / 更新） |
| `curl` | 发送 HTTP 请求，抓取网页、接口文档与 API 内容 |
| `search` | 联网搜索（走「搜索配置」里的引擎链；没配付费引擎也有内置 DuckDuckGo 兜底） |
| `task` | 派一个子代理执行子任务，完成后带回结果 |

**用工具策略做角色分工：**

- 只读分析员：白名单只勾 `read`、`glob`、`grep`、`search`，不给 `write` 和 `edit`，它就无法修改稿件。
- 全权写作：白名单，把文件工具都加入白名单。
- 也可以反过来使用黑名单，禁用危险工具。

### 提示词模版

这一段是编辑智能体的核心，把提示词拆成六个区：

| 区 | 作用 |
|---|---|
| 系统区 | 这个智能体的系统提示词，定义人设和总规矩 |
| 技能索引区 | 运行时自动注入的技能清单，只读；能改「索引前缀语」 |
| 常驻工作区 | 每次都带进上下文的工作区文件前缀；开启后可以编辑「助手确认语」 |
| 持久区 | 长期固定的提示词块，可以加多条，能上下移、能删 |
| 会话区 | 用户聊天历史，开启后可给每次输入附加额外内容（支持 `$time`、`$week_cn`、`$filetree…` 这些动态宏） |
| 动态区 | 按条件动态注入的提示词块，可以加多条，能上下移、能删 |

系统区、技能索引区、常驻工作区、持久区、动态区都可以单独关闭。会话区的开关控制的是「附加信息内容」，聊天历史本身始终在上下文里，不受这个开关影响。

每个提示词字段都能点进「编辑提示词」全屏页。全屏页支持「Markdown」与「文本」两种预览，改完点「保存」；有未保存改动时直接返回会弹确认，确认离开后改动丢弃。

### 保存

有未保存改动时，页面顶部会显示红色的「有未保存的更改」，返回时会弹确认。改完一定要点编辑页底部的「保存」，没有保存直接返回，确认后内容会被丢弃。

## 切换会话的智能体

正在对话时，可以就地切换这个会话使用的智能体。两个会话级入口效果相同：

- **入口：对话 tab → 对话页 meta 条 → 点智能体名** —— 最快的一条路，就地弹选择器。
- **入口：对话 tab → 顶栏 ☰（对话态）→ 会话详情页 → 当前智能体卡** —— 点卡片弹选择器。

这两个入口都会带上当前会话，选择只对这一个会话生效，不会污染工作区的默认值。

还有一个工作区级入口：

- **入口：我的 → 当前智能体**

它切换的是没有单独指定智能体时使用的默认智能体。

### 锁定与待重选

- 会话的智能体信息还在加载时，卡片右侧显示 🔒，整张卡降低透明度，点击会弹出提示，这是防止误点。
- 如果会话绑定的智能体被删除了，智能体卡会放开为待重选状态，卡上提示「智能体已删除 · 点击重选」。点进去重新选择一个智能体，写入新的 id 后锁定自然解除。模型卡在重选前一直保持锁定。

## 子会话

主智能体可以把任务派给子代理。子代理有自己独立的消息历史，和父会话共享同一个工作区。

**入口：对话 tab → 进会话 → 点对话里的 task 工具卡片**

进入「子会话」页后，可以只读浏览子代理的完整消息历史。页面和主会话使用同一套渲染，流式输出、富文本、工具卡都在。

- 空态显示「子会话暂无消息」。
- 子代理还在运行时，页面顶部有「停止」按钮，可以中断。
- 子会话里的 task 卡还能继续点进去查看孙会话，可以逐层向下查看。
- 子会话里的文件卡按父会话工作区的 scope 打开，因为子会话共享父会话的工作区。
- 页面也有指标条，点开是「用量详情」，数据按子会话自己统计。子会话不显示 meta chip，所以「上下文占用」那行会显示「—」。

::: tip
子会话是空的，通常是子代理还没跑完，或者已经跑完但没有产出消息。可以先等一会儿，或者从 task 卡确认它是不是被中断了。
:::

## 查看实际发送的提示词

**入口：对话 tab → 顶栏 ☰（对话态）→ 会话详情页 → 查看提示词**

这一页按「轮摘要卡 → 区块卡流」组织，点叶子卡进入「轮详情」，可以整段查看这一轮实际发送给模型的内容。配置改完不确定是否生效时，这是最直接的验证方式。

## 常见问题

### 改完提示词没有生效

编辑页底部的「保存」必须点。没有保存就直接返回，确认后改动会丢弃。

### 模型卡点不动

被这个智能体的专属模型 pin 锁住了。到编辑页的「模型」区把「专属模型」改回「默认(跟随)」。

### 想删内置的 general

删不掉。内置 general 只读，列表里也不提供行操作。如果要删除的是其他智能体，注意至少保留一个。

### 找不到「子智能体」页签

它在「智能体配置」页里，和「主智能体」页签并排。

### 子会话是空的

可能是子代理还没跑完，或者已经跑完但没有产出消息。先等一会儿，或者从 task 卡确认它是不是被中断了。
