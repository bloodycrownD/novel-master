# 工作区与文件

![聊天工作区](/screenshots/workspace.png)

Novel Master 把世界观、人设、卷纲、正文都放进一棵虚拟文件树里，Agent 和你在同一个空间里读写这些文件。所有文件在逻辑上都以 `/` 为根，比如 `/设定/世界观.md`、`/正文/01.md`；路径在三层工作区里形状一致，方便备份和迁移。

这一页讲三层工作区怎么分工、文件树怎么操作、目录规则怎么配、文件编辑器怎么用，以及怎么划词批注。

## 三层工作区

| 层 | 用途 | 在手机上的对应 |
|---|---|---|
| 全局模板 | 跨项目共用的种子内容 | 我的 → 文件浏览器 |
| 项目模板 | 某一作品默认自带的目录与文件 | 对话 tab → 项目工作区（列表态） |
| 会话工作区 | 当前会话正在编辑的文件树，Agent 主要在这里读写 | 对话 tab → 聊天工作区（对话态） |

新建会话时会从项目模板复制一份工作区，之后你在会话里怎么改都不影响别的会话。想把改动沉淀回模板，用工作区里的「下推模板」按钮。

::: tip
会话工作区是当前会话的私有副本。要让这次的整理成果成为项目模板的一部分，用「下推模板」推回项目工作区；反过来，想把模板里的更新拉进当前会话，用「上拉模板」。
:::

## 文件树操作

文件浏览器、项目工作区、聊天工作区、技能详情这四个地方用的是同一套文件树组件，基础浏览交互一致；读写能力和菜单项会随场景有些差别，后面「四处浏览器的差异」会逐项对照。

### 顶栏

聊天工作区的顶栏从左到右依次是：

上级目录按钮 → 当前路径（中间省略）→ 上拉模板按钮 → 下推模板按钮 → 「⋯」更多

「上拉模板」和「下推模板」只在聊天工作区出现，其余文件树场景的顶栏只有上级目录按钮、当前路径和「⋯」更多。路径过长时中间会省略，点上级目录按钮逐级向上。

### 「⋯」更多菜单

点顶栏的「⋯」会打开更多菜单：

- 「新建目录」
- 「新建文件」
- 「导入」
- 「导出」
- 「目录规则」

技能目录里没有工作区，后三项「导入」「导出」「目录规则」不会出现。技能的导入导出在技能管理页做。

### 行「⋯」菜单

每一行右侧也有「⋯」，菜单项按行类型区分：

- 目录行：「导出」「导入」「状态变更」「重命名」「删除」。
- 文件行：「导出」「状态变更」「重命名」「删除」。

「删除」是危险项，会弹原生确认框。

### 导入

点「导入」会再弹一层形式菜单，三选一：

- 「单文件」
- 「ZIP 包」
- 「角色卡」

### 状态变更

「状态变更」用来切换文件或目录的纳入状态。默认文件不一定参与 Agent 上下文，纳入之后才会进。这个开关走的是工作区目录规则。

### 目录规则

**入口：文件树顶栏 → ⋯ → 目录规则**

这个面板控制「哪些文件参与列表、怎么排序、怎么拼进 Agent 上下文」，不改文件内容。面板里的字段有：

- 「排序方式」：「智能排序」「文件名称」「创建时间」「更新时间」。点开是单选弹层，当前值那一行写「当前」。
- 「排序方向」：「升序」「降序」。
- 「头部数量 (0–1000)」：排在最前面的几条按完整内容带进上下文。
- 「尾部数量 (0–1000)」：排在最后的几条也带进来。
- 「其余文件填充」：「文件名」「头信息」「不展示」。

点底部「保存」写回。

这套规则的价值是维持稳定的前缀：不动的设定常驻、改动的章节置顶，靠规则就能长期保持一个稳定的前缀，服务商的缓存命中率会明显变好。

### 批量操作

长按任意一行进入批量模式，顶部会出现批量条，里面有「移动」。移动会弹目录选择器，可以把一批文件或目录搬到别处。删除有原生确认框。

### 返回键

返回键逐级退出目录。文件浏览器在根目录允许侧滑退出，子目录会关掉侧滑，防止误退。

## 四处浏览器的差异

| 场景 | 入口 | 可写 | 特殊 |
|---|---|---|---|
| 全局文件浏览器 | 入口：我的 → 文件浏览器 | 否 | 全库物理树拼接视图（全局模板 + 技能 + 各项目会话），顶部有只读横幅 |
| 项目工作区 | 入口：对话 tab → 列表态 → 顶部分段条「项目工作区」 | 否 | 整棵项目域文件树 |
| 聊天工作区 | 入口：对话 tab → 对话态 → 顶部分段条「聊天工作区」 | 是 | 有上拉 / 下推模板按钮 |
| 技能详情 | 入口：技能管理 / 技能面板 → 点技能行 | 是 | 没有工作区，无导入、导出和目录规则 |

「上拉模板」和「下推模板」这两个按钮只在聊天工作区出现：

- **上拉模板**（弹窗标题「从上级同步」）：从项目模板往上覆盖，把模板里更新的内容拉进当前会话工作区。
- **下推模板**（弹窗标题「推送到项目工作区」）：把会话工作区整棵树推回项目工作区，成为模板母本。

::: warning
「上拉模板」会从项目模板覆盖当前会话工作区，本地修改会丢失。动手前先确认重要改动已经下推或者备份过。
:::

## 文件编辑器

**入口：文件浏览器 / 项目工作区 / 聊天工作区 / 技能详情 / 子会话的文件卡 / 工具卡里的文件 → 点开任意文件**

任何一个文件点开都进这里。页面结构如下：

- 左上「保存」。
- 中间标题就是文件名；有未保存改动时标题变红，显示「未保存」。
- 右上「编辑 / 预览」切换。
- 顶部一行统计：「更新于 … · N 字」；编辑中有未保存内容时，末尾加「· 编辑中未保存」。

预览态下面还有「Markdown / 文本」两档，可以切渲染方式。

编辑态是代码编辑器，CodeMirror 内核。保存成功会回调刷新列表。

有未保存改动时返回会弹确认。

::: warning
在文件浏览器里打开文件时，保存是禁用的。全局文件浏览器是只读视图，文件只能看；要改文件，请到对应的工作区里打开。
:::

## 划词批注

批注是定点改稿的核心功能：在文件预览上划一段词写意见，跟着消息发给 Agent，它照着批注改对应的地方。

![划词批注](/screenshots/annotate.png)

**入口：对话 tab → 进会话 → 顶部分段条「聊天工作区」→ 点开文件 → 右上切到「预览」→ Markdown 档**

三个条件必须同时满足才能用：

1. 文件在**预览态**，不是编辑态。
2. 文件属于**会话工作区**，也就是从聊天工作区打开的文件。项目工作区和全局文件浏览器里都没有批注。
3. 预览在 **「Markdown」** 档，文本档没有批注。

操作步骤：

1. 在正文里划一段词。
2. 弹出选区菜单，里面有「复制」和「批注」，点「批注」。
3. 弹「批注」框，里面显示你划的原文（超过 80 字会截断加省略号），输入框占位是「批注说明」，点「添加」。
4. 已有批注在下划线标出，点它能看详情，也能改（弹「编辑批注」，确认按钮是「保存」）或删。
5. 同一处文字有多条批注时，点下划线会先弹「选择批注」让你挑一条。
6. 回到对话发送消息，批注会跟着一起发出去。

::: tip
写批注的黄金时间是读改稿之前——你读到哪不满意就划一条，比回头翻聊天记录精确得多。
:::

## 常见问题

### 在项目工作区里找不到新建按钮

项目工作区是只读的，切到会话工作区才能写。

### 批注划不出来

九成是三个条件没同时满足：忘了切到预览态、在文本档，或者文件根本不是会话工作区的——项目工作区和全局文件浏览器里都没有批注。

### 文件树里找不到「目录规则」

技能目录里没有工作区，这项不显示，这是设计如此。

### 文件浏览器里保存是灰的

它是只读的物理树，本来就是给你检视用的，要改去对应的工作区。

### 上拉模板误覆盖了改稿

上拉会从项目模板覆盖当前工作区，动手前先确认重要改动已经下推或者备份过。

### 返回键一下退太多

文件树里返回键是逐级退目录的，在深层目录里要点好几次才回到根。
