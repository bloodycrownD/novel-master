# 服务商、API 连接与模型管理

这一篇回答两类问题：「我怎么设置服务商」「我怎么连接 API」，顺带管模型列表、采样参数和当前模型的选择。

## 我的页：所有配置的总目录

**入口：底部 tab 第 2 个「我的」**

这一页是绝大多数配置页的唯一入口，分三段：

**工作区**

- 当前大模型（点一下弹模型选择器）
- 当前智能体（点一下弹智能体选择器）
- 文件浏览器

**配置**

- 智能体配置
- 服务商配置
- 搜索配置
- 技能管理
- 聊天配置
- 存储配置
- 数据统计
- 智能排序

**应用**

- 关于 Novel Master

每个菜单行右边会显示当前取值。下面的内容都从这里进。

---

## 一、添加服务商

**入口：我的 → 服务商配置 → 添加**

服务商列表页标题是「服务商」，每行显示服务商名、已保存的模型数量、API Key 配置态标签。顶栏右边有「添加」。

1. 点「添加」进「添加服务商」页。
2. 「连接」这一段填三样：
   - **服务商名称**：随便起个好认的名字，比如「智谱」。
   - **协议**：三个选项 chip——`openai` / `anthropic` / `gemini`。
   - **Base URL**：填接口地址，比如 `https://api.example.com/v1`。
3. 「认证」这一段填 **API Key**。必填，会写进系统安全密钥存储。
4. 「高级」这一段可选：
   - **Headers JSON**：必须是 JSON 对象，比如 `{"X-Custom":"value"}`。留空表示不设置。
   - **自定义参数**：JSON 对象，会原样合并进请求体顶层（可以覆盖标准字段）。比如 `{"tool_stream": true}`。清空保存即移除。
5. 点底部「创建」。

保存成功后会自动跳到这个服务商的「模型管理」页，可以接着加模型。

**中转站 / 自建端点怎么填**：协议选 `openai`（绝大多数中转站和自建网关都兼容 OpenAI 协议），Base URL 填中转地址。地址末尾的 `/v1` 要跟服务商文档一致，不要自己加减。如果中转站需要额外的鉴权头或者额外参数，用「高级」里的 Headers JSON 和自定义参数填。

## 二、改服务商信息或换 Key

**入口：我的 → 服务商配置 → 点某个服务商行**

进的页面标题是「模型管理」，但页内有双 tab：「服务商配置」和「模型管理」。

1. 切到「服务商配置」tab 改信息。
2. 这一页会显示「当前状态」：Key 是已配置还是未配置。
3. **API Key 留空表示不修改**，只有填了新值才会覆盖。这是为了防止你只是改个名字却把 Key 抹掉。
4. 点底部「保存」。

## 三、加模型

**入口：我的 → 服务商配置 → 某服务商 → 「模型管理」tab**

有两种加法：

### 路 A：远程拉取

1. 点「远程」，弹「远程模型拉取」面板，会向厂商拉一份模型清单。
2. 顶部可以「过滤模型…」，输入关键字筛。
3. 从清单里选。

### 路 B：手填

1. 点「添加」，弹「添加模型」框。
2. 填 **厂商模型 ID**（这是真正发给服务商的模型标识，必填）和 **模型名称（可选）**（给你自己看的显示名）。
3. 确定。

模型行的操作：点行 → 进「采样配置」；点「⋮」→ 「重命名」或「删除」。长按可以批量删除。

## 四、采样配置

**入口：我的 → 服务商配置 → 某服务商 → 模型管理 → 点某个模型**

页面分三段：

**模型**

- 模型名称。改这个名字会同步改显示名。
- 下面有一行「厂商 ID：xxx」，告诉你实际发给服务商的 ID，别乱动。

**内部预算**

- **上下文上限 (tokens)**：必须是正整数。填错保存会被拦。
- **计数方式**：自动按模型名匹配分词器族，也可以手动指定。

**生成参数**

表单按协议分开显示：

- `openai` 协议：温度、Top P、输出最大长度。
- `anthropic` 协议：温度、Top P、Top K、输出最大长度。
- `gemini` 协议：温度、Top P、Top K、输出最大长度。

另外还有「思考强度」这一档可调。

- 点区头右边的「恢复默认」会把上下文上限和采样参数一起恢复成协议推荐默认值。
- 点底部「保存」写回。

模型副标题里那句「展示协议推荐默认值；保存后以本页为准」的意思是：这些字段是 novel master 自己算预算用的，不直接映射成 HTTP 请求体，所以改了它不会改变服务端行为。

## 五、选当前模型

模型选择有三个入口，效果都是切模型，但作用域不同：

- **入口：我的 → 当前大模型** —— 切工作区级的当前模型，全局生效。
- **入口：对话 tab → 顶栏 ☰（对话态）→ 会话详情页 → 当前大模型卡** —— 切这个会话的模型。传了 sessionId 的选择器不会回退到工作区设置。
- **入口：对话 tab → 对话页 meta 条 → 点模型名** —— 就地弹选择器，最快的一条路。

选择器打开时如果传了 sessionId，走会话级，不会污染工作区默认值。

**锁定的情况**：智能体配了专属模型（pin）时，模型卡会锁住，右边显示 🔒 而不是 ›，整张卡降透明，点它弹提示不给切。想要自由切模型，就得去那个智能体的配置里把专属模型关掉（见 `agents.md`）。

## 六、切换服务商

provider 本身没有「当前」这个概念——当前模型是全局的。你想换服务商，实际操作是：把新服务商的模型加进来，然后在上头的入口里把当前模型切过去。

删除服务商：**入口：我的 → 服务商配置 → 某行「⋮」→ 删除**，会二次确认。长按可以批量删。列表页支持下拉刷新。

## 常见坑

- **Base URL 末尾的 `/v1` 写错。**这个跟服务商文档保持一致就行，有的要有的不要，别自己猜。
- **改名字把 Key 抹了。**编辑页 API Key 留空就是不改，别手滑清空。
- **「模型管理」页标题和第一个 tab 对不上。**页头标题写「模型管理」，进去第一个 tab 却是「服务商配置」。这是现状，按 tab 认就行。
- **模型卡点不动。**多半是被智能体的专属模型锁了，去智能体配置里关掉 pin。
- **远程拉取拉不到模型。**有些中转站不支持列模型接口，改用手填「厂商模型 ID」就行。
