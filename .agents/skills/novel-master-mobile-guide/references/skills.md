# 技能管理

技能是一份遵循 SKILL.md 标准的说明文档。它不执行代码，而是进入提示词的技能索引，模型按描述判断要不要用。社区现成的 skill 打包成 ZIP 导入即用。

## 三个概念先分清

| 概念 | 含义 |
|---|---|
| 全局技能 | 所有项目都能用，存在全局域 |
| 项目技能 | 只在某一个项目里用，存在项目域 |
| 会话技能面板 | 当前项目的合并视图：全局 ∪ 项目，同名时项目那份覆盖全局那份 |

## 技能管理页

**入口：我的 → 技能管理**

页内双 tab：

- **全局技能**
- **项目技能**

项目 tab 按所有项目分组。

行的操作：

- 点行 → 进「技能详情」。
- 点「⋮」→ 编辑信息 / 导出 ZIP / 删除。

全局 tab 里被项目副本覆盖的技能会带一个灰标签「被项目副本覆盖」。

无效技能（SKILL.md 的 front matter 不合法）行的「编辑信息」是置灰的，得先把 SKILL.md 修好。

长按可以批量删除，批量删除的文案会区分影响范围（全局的会影响所有项目，项目的只影响那一个）。切 tab 会自动退出批量态。

## 新建技能

**入口：技能管理 → 新建**（在新建弹窗里）

弹窗里有两条路：

### 路 A：手进模板

1. 填「技能名（即目录名，可以在管理页重命名）」，占位提示是「如 worldbuilding-checker」。
2. 填「描述」，占位提示是「进入技能索引，模型据此判断是否使用」。**描述不能为空**——它是模型判断要不要用这个技能的唯一依据，写清楚点。
3. 选 tab 是全局 tab 就存全局，项目 tab 还要选「所属项目」。
4. 点「创建」。

### 路 B：从 ZIP 导入

1. 在弹窗里点「从 ZIP 导入…」，选一个 zip 文件。
2. 预检通过后显示「已导入 ZIP · N 个文件（创建后全部带入）」，同时自动预填技能名和描述（从 SKILL.md 的 front matter 读来的）。
3. 预填的值可以改。**改了的话创建时会用表单的值重写 SKILL.md 的 front matter，正文保留。**
4. 点「创建」，zip 里全部文件落入新技能目录，创建完直接进技能详情。

导入报错的情况：zip 根目录缺少 SKILL.md（导出格式要求 zip 根就是技能目录），会提示「ZIP 根目录缺少 SKILL.md（导出格式：zip 根即技能目录）」。另外如果目标域已经有同名技能，会报「目标域已存在同名技能「xxx」」，新建不会覆盖，得改名或者先删掉旧的。

## 导出 ZIP

**入口：我的 → 技能管理 → 某行「⋮」→ 导出 ZIP**

导出格式是 zip 根即技能目录，所以这个 zip 可以直接被另一个人的「从 ZIP 导入」吃进去。

## 技能详情

**入口**：三个地方都能进——技能管理点行、会话技能面板点行、对话里点 skill 工具卡片。

页面里是技能内部的文件浏览器，主文件是 SKILL.md，旁边可以有辅助文件。还能新建和删除辅助文件。

点任意文件 → 进文件编辑器（skill 域，可以保存）。

技能被别人并发删掉的话，页面会安全地把你踢回管理页。

## 会话技能面板（项目负清单）

**入口：对话 tab → 顶栏 ☰（对话态）→ 会话详情页 → 技能卡**

这个面板显示当前项目的合并视图：全局技能 ∪ 项目技能，同名时项目那份覆盖全局那份。每行右边有开关。

**这个开关写的是「当前项目的负清单」**——意思是：

- 关掉一个全局技能，只是把它加进当前项目的禁用名单，别的项目照旧能用。
- 反过来也一样，只影响这一个项目。
- 无效技能的开关是禁用的，旁边会给原因标签。

面板里也能「新建」，固定建在项目域，创建完直接进详情。

## 对话里用技能

三个入口，效果一样：

- **入口：对话 tab → 进会话 → 输入区工具条的「$」按钮** —— 弹技能选择器，平铺单选。已经关闭的技能会标「已关闭」。
- **入口：手打「$」** —— 弹 typeahead 候选列表，选中一样生成标签。
- **入口：智能体配置的「技能索引区」** —— 这里的「索引前缀语」决定模型看到技能清单时怎么描述它们。

选中的技能会变成一个标签跟着输入框里的内容一起发出去。

## 如何安装本指南 skill

本指南本身也是一个 skill，格式和上面说的完全一样，所以按 ZIP 导入装就行。

1. 把 `novel-master-mobile-guide` 目录打包成 ZIP，**zip 根目录直接是技能目录本身**（里面就是 SKILL.md 和 references/），不要多套一层文件夹。
2. **入口：我的 → 技能管理 → 新建**
3. 点弹窗里的「从 ZIP 导入…」，选这个 zip。
4. 预填的名称和描述可以改（描述改成「novel master 安卓端使用指南」之类，模型才好判断什么时候用）。
5. 点「创建」，创建完会直接进技能详情。
6. 装完想让它在某个项目生效，进那个项目的会话，打开「会话详情页 → 技能」面板，把开关打开。

装完就能在对话里用 `$novel-master-mobile-guide` 引用它了。

## 常见坑

- **ZIP 导入报「根目录缺少 SKILL.md」。**打包时多套了一层目录。zip 打开后第一层应该就是 SKILL.md 所在的那个技能文件夹，不是它的父目录。
- **描述不填不让创建。**描述是模型判断用不用这个技能的唯一依据，必填。
- **导入说同名已存在。**新建不覆盖，得改名或者先删旧的。
- **会话面板关了技能，别的项目也没了。**不会。那里写的是当前项目的负清单，只影响这一个项目。要全局生效得去技能管理里处理。
- **技能无效。**SKILL.md 的 front matter 不合法。这时候「编辑信息」是灰的，得进技能详情改 SKILL.md 本体。
- **对话里选不到某个技能。**它可能被当前项目关了，去会话技能面板看开关状态。
