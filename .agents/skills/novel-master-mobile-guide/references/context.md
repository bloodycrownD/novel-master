# 长上下文管理：压缩、置位、回滚、分叉

写长篇最容易崩的就是上下文。这一篇讲怎么把对话收敛住。

## 四个术语一句话

- **置位**：把某条用户消息定为可见历史的起点，它之前的消息不再进入模型上下文。
- **回滚**：把会话退回到某条消息的状态，它之后的消息全部丢弃。
- **压缩**：把最旧的一段可见消息隐藏掉——不再进入模型上下文，但数据还在（转录里降透明度显示）；可以自动触发，也可以手动点。
- **分叉**：从某条消息起在同一个项目里复制出一个新会话（自动起名），原来那条线完整保留，分叉后直接切过去。

## 消息菜单：四个动作的入口

**入口：对话 tab → 进会话 → 点消息气泡右上角的「⋯」**

菜单按消息类型给不同的项：

| 菜单项 | 出现在 | 干什么 |
|---|---|---|
| 编辑 | 有正文的消息 | 改内容重新发出去，内容不能为空 |
| 复制 | 所有消息 | 复制正文 |
| 置位 | 只有用户消息，且不是在工具卡里点的 | 把这条定为可见起点 |
| 分叉 | 所有消息 | 从这条起在同一项目里复制出一个新会话，并直接切过去 |
| 回滚 | 所有消息（标红，危险操作） | 退回这条，丢弃后面的 |

**置位和回滚的区别**，这是最容易混的一对：

- 置位只是改变「哪些历史可见」，旧消息还在数据里，随时可以再置回别的地方。适合聊完一个阶段、切换话题时用。
- 回滚是真的删掉后面的消息，不可逆。所以菜单里它是红的。

## 手动压缩上下文

**入口：对话 tab → 顶栏 ☰（对话态）→ 会话详情页 → 压缩上下文**

会话详情页长这样，从上到下：

1. 大字标题（点一下直接 inline 改名）。
2. 当前智能体卡。
3. 当前大模型卡。
4. 查看提示词卡。
5. 压缩上下文卡，副标题写「减少上下文占用」。
6. 技能卡，副标题写「查看与管理」。

点「压缩上下文」会弹确认框「将压缩上下文。是否继续？」，点「压缩」开始。压完 toast 提示「已压缩」，被隐藏的旧消息在转录里显示为降透明度。

**压缩期间 Agent 在跑的话不给压**，会弹「请稍候 / Agent 运行中无法压缩」。等这一轮跑完再压。

## 自动压缩配置

**入口：我的 → 聊天配置**

「压缩配置」这一段有三个设置：

- **隐藏起始深度**（数字输入，默认值 6）：从这个深度开始折叠，也就是保留最近多少层内容。这个对自动压缩和手动压缩都生效。
- **启用自动压缩**（开关，默认关）：打开后，满足 token 比例阈值时自动压缩。
- **Token 比例**（数字输入，默认 0.8）：只有打开自动压缩之后这个字段才出现。意思是上下文占用超过模型上限的这个比例就触发压缩。

**保存是即时的**，没有保存按钮：开关一切就落库，数字输入框编辑完收起键盘就落库。

填错会拦：「Token 比例需为数字」「隐藏起始深度需为数字」「启用时至少填写 token 比例」。写库失败的话开关会自动弹回原值并 toast「保存失败」，不会留一个假状态。

### 建议的配法

- 刚开始写，模型上下文大，先不开自动压缩，靠手动压更可控。
- 长时间挂着写、经常忘了压，打开自动压缩，比例设 0.7～0.8，隐藏起始深度保持默认 6 就行。压太狠会丢细节，压太松容易顶到上限。

## 会话详情页的隐藏入口

顺带说一遍，这个页面本身也是隐藏入口，很多人找不到：

**入口：对话 tab → 顶栏 ☰**——注意只有在**对话态**点 ☰ 才进会话详情页。在列表态点 ☰ 弹的是项目抽屉。

会话详情页还能改会话名、改当前智能体、换当前模型、查看提示词、进技能面板。智能体被删掉的时候，智能体卡会放开成「待重选」，点它重选一个就解开了；模型卡在重选前一直锁着，因为智能体没了它 pin 的模型也无从解析。

## 查看实际发了什么提示词

上下文出问题的时候，最该看的就是「到底给模型发了什么」。

**入口：对话 tab → 顶栏 ☰（对话态）→ 会话详情页 → 查看提示词**

页面三层结构：

1. 轮摘要卡，可以就地展开收起。
2. 区块卡流。
3. 点叶子卡进「轮详情」，把某一段提示词或某条工具结果整段铺开，可以长按复制。

空的时候显示「（空提示词）」。

这条链路跟工具结果卡（search、curl、grep 之类）点开也是同一个详情页。

## 常见坑

- **长按消息气泡出菜单。**这个已经移除了，现在只有气泡右上角的「⋯」。
- **在会话列表里找压缩。**列表里没有这个入口，必须先进对话态，再点顶栏 ☰ 进会话详情页。
- **压缩的时候 Agent 正在跑。**会被拒，等这一轮结束再压。
- **置位 / 分叉的时候 Agent 正在跑。**跟压缩一样会被拒（提示「Agent 运行中无法置位」「Agent 运行中无法分叉」），等这轮跑完再操作。
- **以为置位等于回滚。**置位不删数据，回滚删。想留后路就用置位。
- **改消息留空了。**编辑消息内容不能为空，空了保存不了。
- **自动压缩没反应。**检查「启用自动压缩」是不是开着——Token 比例那一栏只有开了才出现，没开就等于没有阈值。
