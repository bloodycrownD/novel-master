# 低频功能与常见问题

这一篇收的都是不天天用但迟早要碰的东西。

## 一、搜索引擎配置

**入口：我的 → 搜索配置**

Agent 需要查资料时会走搜索。列表按优先级从上到下排着这几个引擎：

| 引擎 | 副标题 |
|---|---|
| Bocha | 按量计费 · 中文检索 |
| Tavily | 按量计费 · 国际 |
| Brave | 按量计费 · 国际 |
| SearXNG | 自托管 · 免费 |
| DuckDuckGo | 内置 |

每行右边显示配置态标签，DuckDuckGo 那行显示「内置」。

### 调优先级

**入口：搜索配置列表 → 行「⋮」→ 上移 / 下移**

第一位是默认引擎。首位那行「上移」是禁用的，末位那行「下移」是禁用的。

### 配密钥

**入口：搜索配置 → 点某行**（标题变成引擎名）

- key 类引擎（Bocha / Tavily / Brave）：填 API Key。**留空即不改**，也可以清除。
- SearXNG：填自托管的 baseUrl，**空串即清除**。
- DuckDuckGo：内置的，不用配。

底部点「保存」。页面只显示配置态，不回显明文。URL 校验会禁掉带 userinfo（用户名@密码）的那种写法。

### 标题栏的「？」

点搜索配置页标题栏右边的「?」，弹「使用说明」三段：

- **引擎优先级**：列表顺序即搜索时尝试引擎的顺序，第一位为默认引擎。未配置任何引擎时由内置 DuckDuckGo 免费兜底（无需密钥）。
- **自动降级**：请求失败（密钥失效、超时等）时自动尝试下一个已配置引擎，直到成功。
- **密钥安全**：API key 仅存本机安全密钥库，不进入会话记录，不随云同步上传。

所以你一个 key 都不配也能搜，只是走 DuckDuckGo。

## 二、存储配置与备份

**入口：我的 → 存储配置**

页面从上到下：

- **存储空间卡**：显示「库体积」和「可回收」两个指标（KB / MB / GB 自动换算）。
- **存量数据迁移进度**：几行只读指标（消息正文明文化、版本内容去 base64、文件缓存去 base64、历史版本打包），页面聚焦时每 5 秒重采样一次，进度会自己走。
- **云端配置**：进云同步设置。
- **数据清理**：清理数据库空间。Agent 运行中这一项会显示「Agent 运行中」不给点，跑起来会有耗时提示。
- **导出数据库** / **导入数据库**。

**导入数据库的语义要看清楚**，有二次确认：导入是完全替换。但本机的服务商和 API Key 会保留，备份文件里带的服务商不会导入进来。所以放心导，密钥不会丢。

## 三、云同步

**入口：我的 → 存储配置 → 云端配置**

### 同步状态与拉取推送

**入口：存储配置 → 云端配置**

页面显示同步状态卡：本机 rev、云端 rev、是否对齐、上次拉取/推送的结果。下面是：

- **云存储配置**：进配置页。
- **从云端拉取**：会弹二次确认。
- **推送到云端**：直接开始。

**Agent 运行中同步控件是禁用的**，会提示。先等这一轮跑完。

点了拉取或推送之后会进「云同步」进度页，进页即开始执行并显示进度，完成后自动返回。这个页面**禁用了侧滑返回**，必须等它跑完。

如果云端还没有数据，它会提示你改走 push 方向。

### 配 S3 兼容存储

**入口：存储配置 → 云端配置 → 云存储配置**

「S3 兼容存储」这一段：

- **Endpoint**（提示「含 https://」，占位 `https://s3.example.com`）
- **Bucket**
- **Region**（提示「MinIO 可留空」）
- **路径前缀**
- **Path style**（开关）

「凭据」这一段：

- **Access Key ID**
- **Secret Access Key**（已存过密钥时占位显示「留空保留已存密钥」）
- **设备名称（可选）**（占位「便于识别本机」）

点「测试连接」验证，底部点「保存配置」。

MinIO 这类自建的对象存储，Endpoint 填自己的地址、Region 留空、Path style 一般要打开。

## 四、数据统计

**入口：我的 → 数据统计**

顶部筛选栏：时间范围（今天 / 近 7 天 / 近 30 天 / 自定义）+ 模型 + 服务商。选「自定义」会弹起止月份选择面板。

下面是三个页签：

- **汇总**：七个指标卡，加一张「服务商 × 模型」饼图。
- **图表**：按天的堆叠柱状图，柱子上还能钻取到 24 小时。
- **流水**：请求级明细分页列表，逐条可查。

筛选条件跨页签保留，切页签不会重新查数据。可以下拉刷新。

空态会区分两种：整个库是空的，和选定范围内没数据——这两种的提示不一样，别当成 bug。

## 五、智能排序规则

**入口：我的 → 智能排序**

这套规则决定文件列表怎么自动排序（比如「第 3 章」排在「第 10 章」前面）。

页面是规则列表，每行有启用开关。行的操作：

**入口：行「⋮」**

编辑 / 置顶 / 上移 / 下移 / 置底 / 删除。内置规则不能删（那一项不出现）。

**入口：顶栏「更多」菜单**

导入 YAML / 导出 YAML / 恢复默认。

长按进批量，批量条有「启用」和「禁用」。

### 规则详情

**入口：智能排序规则 → 新建 / 点行 / 编辑**

字段：

- **名称**（占位「如 中文序号章节」）
- **正则表达式**（占位 `如 /第([0-9〇零一二两三四五六七八九十百千]+)章/i`，支持 `/pattern/flags` 字面量写法）
- **捕获数字**：三档——智能数字 / 固定最大 / 固定最小
- **描述**（占位「描述这条规则匹配什么，如 匹配 第X章 形式的标题」）
- **启用规则**（开关）

**最有用的功能是正则匹配测试器**：

1. 在「测试文本」里粘一段样例（比如几行章节标题）。
2. 点「测试」。
3. 下面「结果」里会高亮所有匹配段，列出每处提取到的元组，还有匹配计数。

改任何一个输入都会清掉上次的测试结果，改完重新点「测试」。

「捕获数字」的三档怎么理解：文件名里匹配出来的数字，交给「智能数字」档能识别中文数字和阿拉伯数字的混合，自动定出最大最小值；用「固定最大 / 固定最小」则强制按你给的界算。

页面区头有个「?」讲「规则与优先级 / 智能数字 / 固定最大最小 / 正则格式」。

## 六、关于与更新

**入口：我的 → 关于 Novel Master**

页面内容：

- 顶部图标、名称「Novel Master」、版本号。
- **更新**段：「自动检查更新」开关 + 「检查更新」行。
- **项目链接**段：GitHub 仓库 / 发行版 / 许可证，点开用浏览器打开。

**App 里没有自动更新安装包。**查到新版本会弹窗「发现新版本」，告诉你版本号和更新摘要，按「前往下载」会打开浏览器到 GitHub 发行页，下载和安装得你自己在浏览器里走完。不想被打扰就按「稍后」，或者关掉「自动检查更新」。

首次启动或者检查完也会有一个应用级的「版本检查」弹窗，显示「已最新」或者「检查失败」，可以选「今日稍后」。

## 七、消息通知与聊天配置

**入口：我的 → 聊天配置**

页内全是开关，切一下即时保存：

| 开关 | 说明 |
|---|---|
| 父会话流式 | 主对话回复边生成边显示（推荐） |
| 子会话流式 | 子智能体回复边生成边显示 |
| 思考提示词 | 开启后模型的思考内容进入后续提示词，关闭则不进入 |
| 富文本消息 | 开启后消息解析 Markdown/HTML，关闭显示纯文本 |
| 消息通知 | 开启后进入应用即常驻状态栏保活，生成中显示状态，结束后台提醒 |

**Android 专属的「通知权限」行**：只有安卓渲染，值显示「已授权」/「未授权」/「申请中…」。点它手动申请系统通知权限。没授权的时候消息通知照样能开，只是系统不会真的弹提醒，所以先授权再开。

关掉消息通知就是无常驻通知、无提醒，**但不影响生成行为**。

写库失败的话开关会自动弹回原值并 toast「保存失败」，不会出现假状态。

这一页的「压缩配置」部分是自动压缩的设置，见 `context.md`。

## FAQ

### 我怎么越狱？

先说清楚前提：novel master 是个客户端，它自己**不内置任何内容过滤**，能生成什么完全取决于你选的模型和服务商的策略。所以不存在在 App 里「打开某个开关就能解封」这回事，能调的是下面两条：

**第一条，换更宽松的服务商或模型。**

**入口：我的 → 服务商配置 → 添加**

你可以接入任意一家策略更宽松的服务商，或者用「自定义 baseUrl」直接接自己的端点、中转站、本地部署的推理服务。协议选 `openai`，Base URL 填那个地址，API Key 填对应的。建好之后把模型加进来，再从「我的 → 当前大模型」切过去。

详细的填法见 `providers.md`。

**第二条，在智能体的提示词里定死写作风格与尺度。**

**入口：我的 → 智能体配置 → 点某个智能体 → 提示词布局 → 系统区**

系统区就是定义人设和总规矩的地方，你可以在里面明确写出想要的文风、尺度、题材边界。另外「会话区」里的附加信息会在每次输入时附上，适合放这次要写的具体要求。

改完点底部「保存」。

本指南不提供也不编写任何越狱提示词内容，上面只说清楚调整的方向。

### 会话列表和聊天是两个页面吗？

不是。它们是同一个页面里的两个视图，切换不换屏。列表态顶部分段条是「会话 / 项目工作区」，对话态换成了「聊天 / 聊天工作区」。

### 项目里的文件改不了了？

项目工作区是只读的。切到会话工作区才能写——那是从项目模板复制出来的你的私有副本。

### 删项目会把稿子一起删掉吗？

会。删除确认框明写「将同时移除其下所有会话」。重要项目建议先在文件里导出 ZIP 备份。

### 划词批注划不出来

三个条件必须同时满足：预览态、会话工作区文件、Markdown 档。详见 `workspace.md`。

### 压缩的时候点了没反应

Agent 正在跑的时候压缩会被拒，弹「请稍候 / Agent 运行中无法压缩」。等这一轮跑完再点。

### 怎么把改动沉淀回模板

**入口：对话 tab → 聊天工作区 → 顶栏下推模板按钮**，确认弹窗标题是「推送到项目工作区」。注意顺序：先下推再上拉，反过来会覆盖掉会话里的改稿。

### App 能直接更新吗

不能。App 里只有版本检查，查到新版本会引导你去浏览器打开 GitHub 发行页，下载安装自己走。
