# 智能体配置与子会话

智能体是一个角色预设：名字、系统提示词、能用哪些工具、可选的专属模型。内置了一个 general，写作用的全能角色，多数时候够用；想细分角色（比如只读分析员、资料整理员）就自己配。

## 智能体列表

**入口：我的 → 智能体配置**

页面顶部有 ManageHeader「新建」按钮。页内双 tab：

- **主智能体**
- **子智能体**

子智能体 tab 的第一行固定是内置的 general，只读，点进去所有控件灰显，没有保存栏，顶部横幅写「内置智能体，不可编辑」。

行的操作：

- 点行 → 进智能体编辑页。
- 点「⋮」→ 重命名 / 复制 / 删除。内置的 general 只有删除且是禁用的。
- 长按 → 批量模式，可全选、批量删除。删除至少要留一个 Agent，删最后一个会被拦并 toast「至少保留一个 Agent」。

## 编辑智能体

**入口：智能体配置列表 → 点行**，或点「新建」。

页面分几个区块，从上到下：

### 基本信息

名称、作用（mode）、描述。这一段还有「导入 YAML」和「导出 YAML」，导入会覆盖当前配置并二次确认。

### 模型

可以给这个智能体指定专属模型（pin）。指定之后，这个智能体跑起来的会话就锁死用这个模型，会话详情页的模型卡也会跟着锁住。想让会话自由换模型，就不要开这一项。

### 运行时

最大步数（maxSteps）。

### 工具策略

- **模式**：默认 / 白名单 / 黑名单（具体选项在「工具名单模式」里选）。
- 选白名单时显示「白名单工具」选择器，选黑名单时显示「黑名单工具」选择器。
- 保持默认时下面是一行提示：未配置时使用全部内置工具（11 个）。

11 个内置工具，各自干什么：

| 工具 | 干什么 |
|---|---|
| `read` | 读工作区单个文件的文本（只读，大文件可分段续读） |
| `write` | 写入或整文件覆盖（不存在的文件会创建） |
| `edit` | 文件内精确文本替换，适合小范围修改 |
| `fs` | 文件系统命令：列目录、删、移动、复制、建目录等 |
| `glob` | 按 glob 模式找文件路径（如 `**/*.md`） |
| `grep` | 在文件内容里搜关键词或正则，返回路径、行号与摘录 |
| `skill` | 装载与查看技能（读技能的 SKILL.md 开工） |
| `agent` | 在对话里管理智能体定义（列出 / 查看 / 新建 / 更新） |
| `curl` | 发 HTTP 请求，抓网页、接口文档、API 内容 |
| `search` | 联网搜索（走「搜索配置」里的引擎链；没配付费引擎也有内置 DuckDuckGo 兜底） |
| `task` | 派一个子代理去干子任务，跑完把结果带回来 |

**怎么用这个做角色分工**：

- 只读分析员 → 白名单，只勾 read、glob、grep、search，不给 write 和 edit，它就改不了你的稿子。
- 全权写作 → 白名单，把文件工具都给它。
- 或者反过来用黑名单，把危险工具禁掉。

### 提示词布局

这一段是核心，六个区，每区都能单独开关：

| 区 | 干什么 |
|---|---|
| 系统区 | 这个智能体的系统提示词，定义人设和总规矩 |
| 技能索引区 | 运行时自动注入的技能清单，只读；能改「索引前缀语」 |
| 常驻工作区 | 每次都带进上下文的工作区文件前缀，开关旁带一个「助手确认语」文本 |
| 持久化区 | 长期固定的提示词块，可加多条，能上下移、能删 |
| 会话区 | 用户聊天历史，开启后可给每次输入附加额外内容（文本框占位提示支持 `$time`、`$week_cn`、`$filetree…` 这些动态宏） |
| 动态区 | 按条件动态注入的提示词块，可加多条，能上下移、能删 |

每个提示词字段都能点进去开「编辑提示词」全屏编辑（CodeMirror 内核，可切 Markdown / 文本预览）。全屏编辑页底部有「保存」。

有未保存改动时页面顶部会显示红色「有未保存的更改」，返回时弹确认。改完要点底部「保存」。

## 切换会话的智能体

两个入口，效果一样：

- **入口：对话 tab → 对话页 meta 条 → 点智能体名** —— 最快的一条路，就地弹选择器。
- **入口：对话 tab → 顶栏 ☰（对话态）→ 会话详情页 → 当前智能体卡** —— 点卡片弹选择器。

这两个入口传了 sessionId，走会话级选择，只改这一个会话，不污染工作区默认值。

还有第三个是工作区级的：**入口：我的 → 当前智能体**，切的是没有单独指定智能体时的默认那个。

**锁定与待重选**：

- meta 还在加载时，卡片右侧显示 🔒 且整张卡降透明，点了会弹提示，这是防止误点。
- 如果会话绑定的智能体被删了，智能体卡会放开成「待重选」，可以点进去重选一个，写入新 id 后锁定自然解除。模型卡在重选前一直锁着。

## 子会话

主 Agent 可以派生子代理去干活，子代理有自己独立的消息历史，共享同一个工作区。

**入口：对话 tab → 进会话 → 点对话里的 task 工具卡片**

进「子会话」页，能只读浏览子 Agent 的完整消息历史。里面跟主会话用同一套渲染：流式输出、富文本、工具卡都在。

- 空态显示「子会话暂无消息」。
- Agent 还在跑的时候顶部有「停止」按钮，可以中断。
- **嵌套下钻**：子会话里的 task 卡还能继续点进去看孙会话，一层层往下钻。
- 子会话里的文件卡按**父会话工作区**的 scope 打开（因为子会话共享父会话的工作区）。
- 子会话页也有指标条，点开是「用量详情」，数据按子会话自己统计。它的 meta chip 不显示，所以「上下文占用」那行会出「—」。

## 顺带：查看实际发送的提示词

想确认智能体到底被喂了什么，**入口：对话 tab → 顶栏 ☰（对话态）→ 会话详情页 → 查看提示词**。

轮摘要卡 → 区块卡流 → 点叶子卡进「轮详情」整段看。配置改完拿不准有没有生效的时候，这页是最直接的验证方式。

## 常见坑

- **长按消息气泡出菜单。**已经废了，只有气泡右上角「⋯」。
- **改完提示词发现没生效。**编辑页底部「保存」要点，没保存直接返回会弹确认但内容丢弃。
- **模型卡点不动。**被这个智能体的专属模型 pin 锁了，去编辑页把「模型」那项关掉。
- **想删内置 general。**删不掉，它只有删除且禁用。要删的是别的 Agent 的话，注意至少留一个。
- **找不到「子智能体」tab。**它在「智能体配置」页内，跟「主智能体」并排。
- **子会话是空的。**可能是子 agent 还没跑完，或者已经跑完但没产出消息。等一下或者从 task 卡确认它是不是被中断了。
