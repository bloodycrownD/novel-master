# 快速上手：从零写出一章小说

这条路线把「新建项目 → 建会话 → 放设定 → 对话写稿 → 看工具卡 → 改稿 → 长对话收敛」串一遍。走完之后你就知道日常怎么用了。

## 第 0 步：先把模型接上

没模型什么都干不了，所以先把服务商配好。

**入口：我的 → 当前大模型**

1. 点「我的」tab，点「当前大模型」那一行。
2. 如果列表里还没有模型，去「我的 → 服务商配置 → 添加」建一个（填名称、协议、Base URL、API Key）。
3. 建好之后回到「我的 → 当前大模型」选一个。

详细的 provider 配置、模型管理、采样参数、中转站怎么填，见 `providers.md`。

---

## 第 1 步：新建项目

**入口：对话 tab → 顶栏 ☰ → 新建**

1. 打开 App，默认落在「对话」tab，顶栏显示当前项目名。
2. 点顶栏左上角的「☰」，弹出项目抽屉（标题是「项目」）。
3. 点抽屉右上角的「新建」，弹输入框，填项目名（比如「科幻小说创作」），确定。

抽屉里还能做的事：

- 点某个项目卡 → 切换到该项目，卡片右下角有「当前」角标标着你正在用的那个。
- 点项目卡右边的「⋮」→ 「重命名」或「删除」。删除会二次确认，并提示「将同时移除其下所有会话」，所以点之前想清楚。
- 长按项目卡 → 进批量模式，可以选多个一起删。

## 第 2 步：新建会话

**入口：对话 tab → 列表头「新建会话」**

1. 还在「对话」tab 的列表视图，顶部分段条默认在「会话 / 项目工作区」的第一项。
2. 列表头顶有个「新建会话」按钮，点它。
3. 新会话创建后会自动进对话视图，工作区是从项目模板复制过来的，你在这个会话里怎么改都不会影响别的会话。

**这里有个必须知道的结构**：会话列表和聊天对话其实是同一个页面里的两个视图，不是两页。列表视图顶部分段条是「会话 / 项目工作区」；进对话后顶部分段条换成「聊天 / 聊天工作区」。所以「返回」不是回到另一个页面，而是这个页面里切回了另一个视图。

会话列表里每行的操作：

- 点一行 → 进对话。
- 点「⋮」→ 菜单：运行中的会话多一项「停止生成」；另外有「重命名」「复制」「删除」。
- 长按一行 → 进批量模式，顶部出现「取消 / 已选 N 项 / 删除」。

## 第 3 步：把设定文件放进去

设定不该塞在对话里，应该放成文件。

**入口：对话 tab → 项目工作区**

1. 在列表视图，点顶部分段条的「项目工作区」。
2. 这是项目域的文件树，只读浏览——从这里能看到整个项目的默认文件结构长什么样。
3. 想真正动手改文件，切到会话工作区。

**入口：对话 tab → 进任意会话 → 顶部分段条「聊天工作区」**

1. 进一个会话，顶部分段条切到「聊天工作区」。
2. 这是会话域的文件树，可以写。Agent 也主要在这里读写。
3. 顶栏「⋯」更多菜单：「新建目录」「新建文件」「导入」「导出」「目录规则」。
4. 「导入」会再弹一层形式菜单：单文件 / ZIP 包 / 角色卡。
5. 点某个文件 → 进文件编辑器，「保存」写回。

建议的目录结构（在「聊天工作区」里新建目录建出来）：

```
/设定/世界观.md
/设定/人设.md
/卷纲/第一卷.md
/正文/01.md
```

第一次用的话，最省事的做法是在「聊天工作区」里直接跟 Agent 说：「帮我建一个 /设定 目录，里面放世界观.md 和人设.md 的空模板」，让 Agent 用文件工具替你建，比手点快。

## 第 4 步：对话写稿

**入口：进会话 → 底部输入框**

1. 点底部输入框输入内容，发送。
2. 回复是流式出来的，边生成边显示（这个可以在「我的 → 聊天配置 → 父会话流式」关掉）。
3. 生成过程中发送按钮变成「终止」，想中途停就点它。

输入框工具条上有四个按钮，从左到右：

- **⛶**：全屏编辑，适合写长段的写作要求。退出时内容自动回填到输入框，不单独保存。
- **@**：引用文件。会弹出文件选择器，层级浏览，可以多选，选中的生成 `@路径` 标签。
- **$**：引用技能。弹出技能列表，选中的生成 `$技能名` 标签。
- **发送 / 终止**：发出去 / 中断当前生成。

不想点按钮的话，直接手打 `@` 或 `$`，也会弹候选列表。

对话页顶部的 meta 条显示当前智能体名和当前大模型名，**点智能体名弹智能体选择器，点模型名弹模型选择器**，被智能体锁定的时候点了会弹提示不给切。

## 第 5 步：看工具卡，看 Agent 到底干了什么

Agent 干活时会在对话里留下工具卡片，这是理解它行为的关键。

- **task 工具卡**：代表主 Agent 派了个子代理去干活。点这张卡 → 进「子会话」页，能看到子 Agent 的完整消息历史（只读）。子会话里的 task 卡还能继续往下点，一层层下钻。
- **skill 工具卡**：点开 → 进技能详情页。
- **工具结果卡**（search、curl、grep 之类）：点开 → 进「轮详情」页，把这条结果整段铺开看，可以长按复制。
- **文件工具卡**：点开会自动切到「聊天工作区」并直接进文件编辑器。

对话页还有一条指标条显示本轮 token 用量，**点它弹出「用量详情」面板**，里面能看到模型、输入、输出、缓存读取、缓存写入、缓存命中率、可见消息数、工具调用次数、上下文占用。

## 第 6 步：改稿

有两条路：改对话里的消息，或者改文件。

### 路 A：划词批注定点改

这是最精准的方式——指着文件里某一段说要怎么改。

**入口：对话 tab → 聊天工作区 → 点文件 → 右上切到「预览」→ Markdown 档 → 划词**

1. 进会话，切到「聊天工作区」。
2. 点开要改的文件，进文件编辑器。
3. 右上角点「编辑/预览」切到**预览态**。
4. 预览态下面有「Markdown / 文本」两档，**批注只在 Markdown 档可用**。
5. 在正文里划一段词，弹出选择菜单点「批注」，写批注说明，添加。
6. 同一处文字上有好几条批注的时候，会先弹「选择批注」让你挑一条。
7. 点已有的批注下划线可以查看、改或删。
8. 回对话发送消息，批注会跟着一起发给 Agent，它按批注定点改。

### 路 B：改消息本身

**入口：对话 → 点消息气泡右上角的「⋯」**

菜单里有：编辑、复制、置位、分叉、回滚。

- **编辑**：改这条消息的内容，重新发出去。注意内容不能为空。
- **复制**：复制这条消息的正文。

置位、回滚、分叉是长上下文管理手段，见 `context.md`。

## 第 7 步：长对话收敛

写长篇很容易聊着聊着上下文就撑爆了。三招：

1. **置位**：在某条消息上点「⋯ → 置位」，把那条定为可见起点，之前的旧消息不再进上下文。聊到一个新阶段时置一次位，很有效。
2. **压缩**：上下文快满了就压一下。

   **入口：对话 tab → 顶栏 ☰（对话态）→ 会话详情页 → 压缩上下文**

   也可以打开自动压缩，让它按 token 比例自己触发——见 `context.md`。

3. **回滚**：改砸了想退回去，在某条消息上点「⋯ → 回滚」。这条是危险操作（菜单里标红），后面的消息会全丢。

详细的压缩配置、置位与回滚的差别、分叉怎么用，见 `context.md`。

## 常见坑

- **以为会话列表和聊天是两个页面。**它们是同一个页面里的两个视图，进出会话就是在这一个页面里切换。返回键也是逐层消费：先关弹层 → 退目录 → 回列表 → 退到上一个会话。
- **长按消息气泡出菜单。**这个已经废掉了，现在只有气泡右上角的「⋯」能开菜单。
- **划词批注在别的场景找不到。**批注只在「预览态 + 会话工作区文件 + Markdown 档」三个条件同时满足时才有。编辑态没有，项目工作区、全局文件浏览器、技能文件里的文件也没有。
- **在项目工作区里想改文件却发现改不了。**项目工作区是只读的，要写就切到会话工作区。
- **顶栏「☰」的作用会变。**在列表态它弹项目抽屉，在对话态它直接跳会话详情页，不是同一个东西。
