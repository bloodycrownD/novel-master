# novel master 安卓端使用指南

## 这是什么

novel master 是专注长篇小说创作的 AI Agent 工作台。安卓端把世界观、人设、卷纲、章节统统放进一棵虚拟文件树，Agent 直接读写这些文件，你跟它在同一个空间里对话改稿。底部只有两个 Tab——「对话」和「我的」，绝大多数设置页都从「我的」进。

本指南只讲 Android 手机端。桌面端的界面布局跟手机端不一样，遇到桌面端问题不要用这里的路径回答。

## 核心概念速览

| 概念 | 一句话 |
|---|---|
| 项目 | 一部作品或一个创作宇宙，装着项目模板（默认文件树、目录规则）。 |
| 会话 | 项目下的一条写作/对话线；新建会话时从项目模板复制一份工作区，之后各会话互不干扰。 |
| 三层工作区 | 全局模板（跨项目种子内容）、项目模板（某作品默认文件树）、会话工作区（当前正在编辑的文件树，Agent 主要在这里读写）。 |
| 智能体 | 一个角色预设：名称、系统提示词、可用工具的允许/拒绝名单、可选的专属模型。 |
| 技能 | 一份遵循 SKILL.md 标准的说明文档，进入提示词索引，模型按描述决定要不要用；分全局域和项目域。 |

## 四个术语

- **置位**：把某条用户消息定为可见历史的起点，它之前的旧消息不再进入模型上下文。
- **回滚**：把会话退回到某条消息的状态，之后的消息全部丢弃重来。
- **压缩**：把最旧的一段可见消息隐藏掉——不再进入模型上下文，但数据仍保留；可以按 token 阈值自动触发，也可以手动点。
- **分叉**：从某条消息起在同一个项目里复制出一个新会话（自动起名），原来那条线完整保留；分叉后直接切进新会话。

## 写法约定

回答用户时：

1. **先给入口路径，再给步骤。**每条路径写成「入口：我的 → 服务商配置」「入口：对话 tab → 顶栏 ☰」这种形式，让用户能照着点。
2. **引用界面文案用「」原样引用**，比如「压缩上下文」「聊天工作区」，不要改写、不要意译成别的说法。
3. **一个操作有多个入口就都列全。**比如换模型能从「我的」页、会话详情页、对话页的 meta 条进，三个都要写。
4. **只写文档里确证过的入口和交互**，不确定的不要编。
5. 素材里提到的遗留死路径（比如那个进不去的「会话操作」抽屉）绝对不能当成真实入口写给用户。
