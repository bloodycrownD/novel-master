# 三栏工作台与工作区

---

## 一、三层工作区：为什么中栏会自己变

这是整个界面最容易懵的地方，一句话因果先说清：

**中栏显示哪一层工作区，由右栏当前停在哪一级导航决定。** 你不是在手动切工作区，你是跟着右栏走。

| 右栏停在 | 中栏标题变成 | 这层是什么 | 能不能编辑 |
|----------|--------------|------------|--------------|
| **项目**列表页 | 文件浏览器 | 物理磁盘真实位置的只读树，把各处的真实文件路径跨域拼起来看 | 只读 |
| 某个项目的**会话列表** | 会话工作区 | 项目模板母本，新建会话从这里复制 | 可改 |
| 某个**具体会话**的聊天 | 聊天工作区 | 当前会话私有副本，Agent 主要在这儿读写 | 可改 |

`/子智能体会话只读页` 也算聊天工作区，但面板是只读的。

所以你在右栏点项目进出会话列表，中栏就换成母本；再点一个会话进去，中栏又换成那份私有副本。这不是刷新失败，是 scope 跟着导航自动切的结果。

物理文件浏览器那一层是特例：它不接拖入，也不响应右键（没有那三套菜单），只有只读预览——你是去「检视」真实布局，不是去改。

## 二、栏位显隐与拖宽

**入口：顶栏右上三个按钮 `◧` `▥` `◨`**，分别切换左栏 / 中栏 / 右栏；中间还有一个主题切换 `☀`/`☾` 和设置 `⚙`。

1. 嫌三栏挤，就把用不上的那一栏点掉藏起来。显隐状态会被记住，下次开还在。
2. 宽度：拖栏与栏之间的分隔条（splitter）。有最小宽度限制——预览栏 450px、工作区栏 300px、聊天栏 350px；窗口宽度 ≤900px 会被当成窄视口。
3. 打开设置时整个三栏会隐藏——设置是覆盖整页的，不是弹窗。

## 三、文件树操作：右键有三套菜单

**入口：中栏树的三个位置右键，出来的菜单不一样**

| 右键位置 | 菜单项 |
|----------|--------|
| **空白处** | 新建文件、新建文件夹、导入、导出 |
| **目录行** | 新建文件、新建文件夹、导入、导出、**规则配置**、重命名、删除文件夹 |
| **文件行** | **状态设置**、导出、重命名、删除文件 |

记这条规律：**目录行是超集**（等于空白处菜单 + 规则配置 + 重命名 + 删除文件夹），文件行是另一套（状态设置 + 导出 + 重命名 + 删除文件），没有新建、没有导入。

## 四、新建 / 导入 / 导出

### 新建

空白处或目录行右键 →「新建文件」/「新建文件夹」。目录行上新建是建在该目录里，空白处新建是建在当前展开的层级。

### 导入（三选一）

**入口：空白处或目录行右键 →「导入」→ 打开「导入形式」弹窗**

弹窗里三选一，选完再点底部「导入」主按钮才生效——光选不点不会导入：

| 形式 | 行为 |
|------|------|
| **ZIP 包** | 解压并覆盖目标目录的全部内容（有确认弹窗，会提醒覆盖） |
| **角色卡** | 解析后写入目标目录，覆盖同名文件（有确认弹窗） |
| **单文件** | 走系统选文件，批量 ingest 进工作区；遇到同名文件会再弹一次「覆盖确认」，确认期间按钮显示「处理中」不能重复点 |

### 导出

**入口：任意位置右键 →「导出」**，类型直达，不用再选：

- 在**文件行**上导出 → 导出这一个文件。
- 在**目录行或空白处**导出 → 导出成 ZIP 子树。

### 拖拽

还能从系统文件管理器直接把文件拖进树里批量 ingest，也能在树内拖拽移动文件到别的目录。

## 五、目录规则（决定送给 Agent 的上下文长什么样）

**入口：目录行右键 →「规则配置」**

这个弹窗不改任何文件内容，只控制「哪些文件参与列表、怎么排、按什么档位进 Agent 上下文」：

| 字段 | 选项 / 范围 |
|------|-------------|
| 排序方式 | 文件名称 / 创建时间 / 更新时间 / 智能排序 |
| 排序方向 | 升序 / 降序 |
| 头部数量 | 0–1000 |
| 尾部数量 | 0–1000 |
| 其余文件填充 | 文件名 / 头信息 / 不展示 |

这套规则作用于**逻辑工作区文件树**，也就是真正送给 Agent 的那棵——所以规则按会话缓存快照，一个回合内前缀稳定，服务商的缓存命中率才不会掉。

工作区根目录 `/` 的规则是强制启用的，关不掉。

「智能排序」这个排序方式会用 设置 → 高级 · 智能排序 里那份规则列表，按从上到下逐条尝试，首条命中的规则用它的捕获组提取序号。所以章节文件叫「第1章」「第 003 章」还是「Chapter_1」都能排对。

## 六、文件纳入状态（三态）

**入口：文件行右键 →「状态设置」**，单选三态：

| 状态 | 含义 |
|------|------|
| **展示** | 强制纳入 Agent 上下文，显示全内容 |
| **隐藏** | 强制不纳入 |
| **跟随** | 由父目录的纳入规则决定（默认） |

文件行上会显示当前纳入状态。保存后工作区会刷新。

配合目录规则用效果最好：不动的设定走目录规则（头部数量 + 「头信息」填充，永远只占前几条），写得频繁的章节正文走「展示」。

## 七、左栏文件预览

**入口有三条路**：中栏点文件行、点聊天里的工具卡、点聊天消息里的路径链接。

1. **多标签页**：VS Code 式开多个。删掉文件只把 tab 标成「已删除」，不会自动关掉；文件重命名时 tab 名会同步跟着变。
2. **预览 / 编辑分段切换**：Markdown 走渲染预览（支持 mermaid 图），其余文件走 `<pre>` 纯文本。切到「编辑」档是 CodeMirror 编辑器，底部有行数和「未保存 / 已保存」状态，**Ctrl+S 保存**。
3. **物理文件浏览器面板只有只读预览档**，没有编辑档——它是检视真实布局用的。
4. 保存冲突会走 lastKnownContent 校验，弹「保存失败：…」，不会静默覆盖你改过的内容。

路径 chip 会显示当前文件的完整路径，方便核对。

## 八、划词批注（定点改稿）

**入口：左栏预览态下鼠标划词 → 浮动条「添加批注」**

三个前置条件缺一不可：**在聊天工作区**（右栏停在具体会话）、**处于预览态不是编辑态**、**文件是 Markdown**；另外当前会话要有上下文。

流程：

1. 划词 → 点浮动条「添加批注」。
2. 弹窗里显示你选中的原文，下面填批注说明，保存。
3. 同一段文字上有多条批注时，会先经过「选择批注」弹窗让你挑。
4. 预览里已入库的批注是高亮的，点高亮直接进「批注详情」弹窗改或删。
5. 发消息时批注作为 `annotate` 附件注入，输入框顶部出现对应状态 chip（这个 chip 不能用叉删掉，是状态标记）。

Agent 收到的是「原文片段 + 这条批注」，所以定点改稿比在消息里描述「把第三章那段改一下」准得多。

## 九、初始化 / 推送到项目工作区

**入口：中栏标题右侧的 `⋯`**

这个按钮**只在聊天工作区、且不在子会话视图时**才有内容，其它情况下根本不渲染。它有两个动作，都会弹确认弹窗并且文案写明覆盖影响面：

### 初始化（pull）

「从项目工作区覆盖当前聊天工作区，本地修改将丢失」。

用途：你改了项目母本，想让当前会话重新拿到母本的内容。会话里这一轮写的东西会没，所以先想清楚。

### 推送到项目工作区（push）

「将用当前聊天工作区覆盖项目工作区」，这是危险操作（按钮是 danger 样式）。

关键影响面：项目工作区是**该项目所有会话的模板母本**，覆盖之后，这个项目之后新建的会话、以及其它会话的「初始化」都会拿到被覆盖后的内容。

用途：会话里打磨出一版满意的大纲/人设，想沉淀成这个项目的默认模板，就推送上去。

> 子会话视图下没有这个菜单——子智能体共享父会话的工作区，同步入口统一收敛到主会话做。

## 常见坑

1. **中栏的树突然变了。** 跟着右栏导航自动切的 scope，看右栏停在哪个页面就对了。
2. **在文件浏览器里右键没菜单。** 物理树只读，本来就不响应右键也不接拖入。
3. **在导入弹窗里选好了没反应。** 要再点底部「导入」主按钮才生效。
4. **导出得到的是整个 ZIP 而不是单个文件。** 导出类型是直达的：文件行导单文件，目录行和空白处导 ZIP 子树。想导单文件就去文件行上右键。
5. **导入撞到同名文件被拦。** ZIP 和角色卡会走确认弹窗，单文件走「覆盖确认」；确认期间按钮是「处理中」，别重复点。
6. **规则配了但 Agent 还是只看得到一点内容。** 目录规则里的「其余文件填充」选的是「不展示」或「头信息」时，被挤出头尾数量的文件就只有名字进上下文了。想全文就配到头尾数量里，或者给文件单独设「展示」。
7. **批注怎么划不出来。** 编辑态、非 Markdown、不在聊天工作区，三个都检查一遍。
8. **推送之后别的会话内容变了。** 那是设计如此——项目工作区就是所有人的母本，覆盖是全局的。
