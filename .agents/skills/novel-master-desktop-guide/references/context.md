# 长上下文管理：压缩、置位、回滚、分叉

---

## 四个术语一句话定义

- **置位**：把某条消息设成可见历史的起点，它前面的旧消息隐藏掉但仍然存在；常用来在章节之间开新话题时收敛上下文。
- **回滚**：把会话退回到某条消息的状态，砍掉它之后的对话和改动；不可逆，有二次确认。
- **压缩**：把最旧的一段可见消息隐藏掉——不再进入后续上下文（界面里降透明度显示，数据仍保留），用来降 token 占用；可按阈值自动触发，也可手动点一次。
- **分叉**：从某条消息起在同一项目里复制出一个新会话（自动起名）继续写，原会话原样保留，相当于存档后重开；分叉后直接切进新会话。

一句话总结分工：**压缩是「把旧内容移出上下文」，置位是「换个起点」，回滚是「往回退」，分叉是「岔一条路」**。

---

## 一、看占用

**入口：会话里点输入框工具栏最左的 `⋯` →「会话详情」抽屉**

抽屉里有一条「上下文占用」进度条，token 读数订阅流式事件实时刷新。显示上有个细节：估算档用家族记号加 `≈`（比如 `gpt ≈`），等 main 侧精确计数算出来会升级成精确档（`glm =`），数字会比刚生成时跳一下，这是正常的。

占用条下面还有「查看提示词」链接，跳到聊天页签的「提示词」页签，能按轮看真实送进模型的提示词原文——怀疑「为什么它不知道我前面说过的话」，来这里对。

---

## 二、自动压缩配置

**入口：顶栏 ⚙ 设置 → 工作区 · 常规**

「聊天偏好」这一组里有一张自动压缩卡片，三个字段：

1. **隐藏起始深度**：往前留多少条消息的原文。调大留得多、token 高；调小省得多但细节丢得快。
2. **启用自动压缩**：开关。
3. **Token 比例**：上下文占用到这个比例就触发自动压缩。

这三个字段改完有 600ms 防抖自动保存，弹一下「已保存」就生效了，不用手动点保存按钮。

同一组里的四个开关也顺便说一下，影响的是消息展示和请求行为：

| 开关 | 作用 |
|------|------|
| **父会话流式** | 主对话实时输出；关掉就是回复完成后一次性显示 |
| **子会话流式** | 子智能体会话实时输出，同上 |
| **思考提示词** | 模型的思考内容进不进后续提示词；关掉就不进 |
| **富文本消息** | assistant 正文按 Markdown 渲染（含 mermaid 支持）；关掉走纯文本 |

隐藏起始深度对自动压缩和手动压缩**都**生效，是两者共用的参数。

## 三、手动压缩

**入口：会话里点输入框工具栏 `⋯` →「会话详情」抽屉 → 底部「压缩上下文」**

1. 点下去弹确认，告诉你「将按照事件配置压缩上下文」，确认后执行。
2. 压缩成功会刷新消息列表并推 token 读数，抽屉里的占用条会立刻掉下来（之前估算档停在 `gpt ≈` 的情况也会被修正成精确档）。

自动压缩没配或者不想等阈值，就用这个手动点。

---

## 四、置位

**入口：右键（或点气泡上的 `⋯`）自己的 user 消息 →「置位」**

1. 只有 user 消息有置位项。
2. 会有二次确认。
3. 置位成功后，那条消息之前的旧消息在聊天里带「已隐藏」标签、降透明度显示——不是真删了，把置位点换到更早的消息就又能看到。
4. 生成过程中「置位」是禁用的，会被拒掉并弹提示，等这轮跑完再操作。

用途：写完第一章想开新话题时，先把「开始写第二章」那条置位，Agent 就不会老翻第一章的细节。

---

## 五、回滚

**入口：右键（或点气泡上的 `⋯`）任意消息 →「回滚」**

1. 回滚到这条消息的状态，它之后的对话和文件改动一起退掉。
2. 有二次确认，而且确认弹窗有三种形态：普通确认、快照丢失、工作区无法恢复。快照丢了或工作区回不去的时候文案更重，让你知道自己会丢东西。
3. 隐藏的消息不显示回滚项（它本来就不在可见历史里）。
4. 回滚成功后占用读数会同步刷新。

不可逆，动手前想清楚。

---

## 六、分叉

**入口：右键（或点气泡上的 `⋯`）任意消息 →「分叉」**

1. 在同一个项目里复制出一个新会话（自动起名），包含这条消息及之前的全部对话；原会话原样保留。
2. 分叉成功后直接切进新会话，接着从这条消息之后继续写。
3. Agent 正在跑的时候会被拒，提示「Agent 运行中无法分叉」，等这轮跑完再点。
4. 适合「这条走向我想留着，另开一条试试」的场景。

---

## 七、编辑消息

**入口：右键（或点气泡上的 `⋯`）消息 →「编辑」**

1. 只有纯文本消息能编辑（只有文本块的那些）。
2. 弹窗里是等宽多行文本域，**回车换行，Ctrl+Enter 保存**。
3. 保存只替换首个文本块，思考过程和工具调用的顺序原样保留。
4. 保存后不回填输入框，内容就在聊天里生效了。

菜单里还有「复制」，复制消息原文。隐藏的消息不显示这些项。

---

## 完整消息操作菜单

右键消息气泡，或者点气泡右上角的 `⋯`：

| 菜单项 | 可用条件 |
|--------|----------|
| 编辑 | 仅可编辑文本的消息 |
| 复制 | 都行 |
| 置位 | 仅 user 消息；生成中禁用 |
| 分叉 | 生成中禁用 |
| 回滚 | 隐藏消息不显示 |

## 常见坑

1. **「已隐藏」的消息是删了吗？** 没有，只是移出了可见历史。换个起点或者回滚就能再看到。
2. **自动压缩配了却没触发？** 检查「启用自动压缩」开关，以及 Token 比例是不是设得太高，压根没到线。
3. **置位 / 分叉点了说不行。** Agent 正在跑，等这轮结束再操作。
4. **改完发现走偏了怎么办？** 回滚，然后编辑那条 user 消息重新描述。注意回滚是退整条链，不是退单条。
5. **占用读数刚生成完突然变了？** 估算档升级成精确档导致的，以精确档为准。
6. **占用一直降不下来？** 除了压缩和置位，也可以在会话详情抽屉里把会话换到上下文更短的模型，或者换更省 token 的模型。
