# 低频功能与常见问题

这一篇收的都是「不是天天用、但迟早要用」的东西。

---

## 一、搜索配置

**入口：顶栏 ⚙ 设置 → AI · 搜索配置**

Agent 联网查资料时按这里配的搜索链顺序去找。

1. 列表按 `engineOrder` 排出所有搜索引擎，行上显示 API Key 状态；内置的 DuckDuckGo 标着「内置」。
2. 行 `⋯` 菜单有「上移」「下移」调搜索链优先级，第一个在最前。已经到顶的不能再上移，到底的不能再下移。
3. 排序在途的时候整个菜单会禁点，防止交错提交把顺序搞乱。
4. 页首的「?」打开使用说明弹窗，看完点「知道了」或点遮罩关。

**进单个引擎详情**：搜索配置列表点行。

| 引擎类型 | 详情页里能填什么 |
|----------|-----------------|
| 需要 key 的 | API Key（**留空 = 不修改**，不是清空）+「清除密钥」按钮 |
| SearXNG 型 | 实例 Base URL（留空 = 清除；保存前会校验必须是 http/https 且不含账号密码） |
| DuckDuckGo | 只读说明页，没有可填项 |

顶部有「配置状态」区。保存和清除是互斥的，不会交错的。

## 二、智能排序

**入口：设置 → 高级 · 智能排序**

只在工作区目录规则里把排序方式选了「智能排序」时才起作用。页面顶部写着规则怎么用：「目录选『智能排序』时按本列表从上到下逐条尝试，首条命中规则的捕获组提取序号」。

1. 列表按优先级排，**拖拽**可以排序，行菜单可以删除。
2. 顶部操作：导入 YAML、导出 YAML、恢复默认、新建规则。
3. 批量模式可以全选后启用 / 禁用 / 删除。
4. **内置规则只能禁用不能删**——它们不出现在删除项里，批量删除也会被拦下。

**规则编辑页**（列表点行或「新建规则」）：

- 基本信息：名称、正则（形如 `/第([0-9…]+)章/i`，支持 flags）、捕获数字类型（智能 / 固定最小 / 固定最大）、描述、启用规则。
- 测试区：贴一段测试文本 → 点「测试」→ 原文里高亮匹配段，下面列出每处匹配提取出来的元组，还有匹配计数。
- 正则非法会实时提示，别等保存。
- 保存或创建后自动返回列表。

典型用途：把「第1章」「第 003 章」「第十章」「Chapter_5」各种命名统一排出正确顺序，靠的是写几条正则。

## 三、备份与恢复

**入口：设置 → 数据 · 备份与恢复**

这一页有四块。

### 云同步

填 Endpoint、Bucket、Region、Path Prefix、AccessKey、Secret Key，还有路径风格和设备名。

- 点「测试连接」先验通不通。
- 「拉取」从云端拉下来，「推送」把本机传上去。
- 拉的时候如果发现云端数据更新，会弹确认，让你选「先拉取」还是「仍要覆盖云端」。

### 导出

把数据库导出成 `.nmbackup` 文件。换机器、留底都用它。

### 导入

导入一个 `.nmbackup`，**完全替换**本机数据。但**本机的服务商配置和 API Key 会保留**——所以换机之后不用重新配 key。

### 存量数据迁移 / 数据清理

- 存量数据迁移有三行进度条，把早期版本的数据搬过来。
- 数据清理跑 VACUUM，会报告清理前后的体积变化。库很大、删过很多东西之后跑一下能省空间。

### 同步期间

状态和库体积每 2 秒轮询一次。**同步进行中、Agent 运行中、正在维护**这三种情况下整页控件都禁用，别以为点了没反应。

## 四、数据统计

**入口：设置 → 数据 · 数据统计**

### 筛选

时间范围：今天 / 近 7 天 / 近 30 天 / 自定义起止日期。模型下拉：全部模型 / 具体模型 / 其他模型。

两种空态要分清：
- 「库里还没有任何用量数据」——一条对话都没发生过。
- 「当前筛选范围内暂无用量数据」——库里有，只是这段时间没有，换个范围看看。

### 三个页签

**① 汇总**（默认停在这一页）

- 总览卡片：总 token、输入、输出、缓存读、缓存写、缓存命中率、平均生成速率、平均首字延迟。
- 「服务商 × 模型」饼图，**点某个扇区**会在下面展开那一项的明细（用量 / 调用次数 / 占比）。

**② 图表**

- 时间范围选「今天」时，展示的是**当天按小时分布**（0–24 点的输入输出与调用量）。
- 选其他范围（近 7 天 / 近 30 天 / 自定义）时，展示的是**按天用量**。

两种形态下点某一天都能展开那天的明细。

**③ 流水**

逐请求表格：时间 / 模型 / 输入 / 输出 / 缓存读 / 首字延迟 / 总时间，按时间倒序，带上一页下一页分页。某次调用花了多少、慢在哪一段，翻这页最直接。

## 五、关于与更新

**入口：设置 → 应用 · 关于**

1. 页面上是应用图标、名称、版本号。
2. **更新区**：自动检查更新开关 + 「检查更新」按钮 + 上次检查的状态行。
3. **项目链接**：GitHub 仓库 / 发行版 / 许可证，点开用外部浏览器。

**重要：本产品没有应用内自动更新。** 检查到新版本时只会：

- 启动约 2 秒后在后台悄悄检查，命中新版本弹一条 toast，带「查看」按钮。
- 或者你手动点「检查更新」，就地弹一个「发现新版本」弹窗，显示新版本号 + 发行说明摘要，三个按钮：「取消」「稍后」「前往下载」。
- 「稍后」会记住这个版本号（dismissedVersion），同一个版本不再提示；「前往下载」是用**外部浏览器**打开 GitHub 发行页，下载和安装得你自己来。
- 如果检查结果是「当前已是最新版本」或「无法检查更新，请检查网络」，弹窗只有「关闭」和「今日不再提醒」（24 小时不再提）。

> Windows / Linux 上原生菜单栏是隐藏的，所以「帮助 → 关于 Novel Master」那个原生对话框你基本看不到。**看版本号、更新、链接，一律走 设置 → 应用 → 关于。**

## 六、快捷键与栏位

### 快捷键汇总

| 快捷键 | 在哪 | 干什么 |
|--------|------|--------|
| **Ctrl / Cmd + Enter** | 聊天输入框、多行文本域 | 发送提交（Enter 是换行；输入法组字期间不会误触发） |
| **Ctrl + S** | 左栏文件编辑器、技能详情编辑器、编辑消息弹窗 | 保存 |
| **Enter** | 单行输入框（比如添加模型时） | 提交 |
| **Esc** | 全屏类弹窗：提示词全屏、工具结果、用量详情 | 关闭 |
| **Esc** | 会话名行内编辑 | 取消编辑 |

### 栏位显隐与拖宽

顶栏右上 `◧` `▥` `◨` 三个按钮分别切换左栏（文件预览）/ 中栏（工作区）/ 右栏（聊天），显隐状态会记住。宽度拖栏与栏之间的分隔条即可，有最小宽度（预览 450px / 工作区 300px / 聊天 350px），窗口 ≤900px 算窄视口。主题切换 `☀`/`☾` 在同一排。详见 `workspace.md`。

### 隐藏入口速查

这些入口界面上不明显，但天天用：

| 入口 | 位置 |
|------|------|
| 会话详情抽屉 | 输入框工具栏**最左**的 `⋯` |
| 消息编辑 / 复制 / 置位 / 分叉 / 回滚 | 消息气泡右键，或气泡上的 `⋯` |
| 工作区三套右键菜单 | 树空白处 / 目录行 / 文件行 |
| 初始化 / 推送到项目工作区 | 工作区标题栏右侧 `⋯`（仅聊天工作区） |
| 子智能体会话 | 点 `task` 工具卡 |
| 技能详情 | 点 `skill` 工具卡 |
| 文件预览 | 点带 VFS 路径的工具卡，或消息里的路径链接 |
| 工具结果全文 | 点其它工具卡 |

## 七、FAQ

### 我怎么越狱？

先说清楚前提：**novel master 是客户端，它自身不内置内容过滤。** 你能生成什么，取决于你选的那个模型和你接的那个服务商的策略——限制通常在服务商那一侧，不在应用里。

想调整写作尺度，有两条正经路子：

1. **换服务商 / 模型**。在 设置 → AI · 服务商配置 里接入更宽松的服务商或模型。自建和中转端点也可以：用 openai 兼容协议，Base URL 填自建或中转地址；需要透传网关标识就填 Headers JSON；要覆盖生成参数默认值就用自定义参数 JSON。详见 `providers.md`。
2. **调智能体的提示词**。在 设置 → AI · 智能体配置 里，把写作风格与尺度写进系统区（系统提示词）和自定义附加信息，让模型按你要的尺度写。详见 `agents.md`。

这个指南不提供、也不会编写任何越狱提示词内容，上面这两条是软件设计上留给你的正当调节手段，剩下的就看你自己的选择了。

### 我怎么压缩上下文？

自动压缩：设置 → 工作区 · 常规，「隐藏起始深度」+「启用自动压缩」+「Token 比例」，改完防抖自动保存。
手动压缩：会话里点 `⋯` →「会话详情」抽屉 → 底部「压缩上下文」。
完整版见 `context.md`。

### 输入框打不了字，placeholder 写着「请先配置模型」？

去 设置 → AI · 服务商配置 配一个服务商和模型，见 `providers.md`。

### 为什么 Windows 上找不到应用菜单和「关于」？

菜单栏被隐藏了，这是设计。去 设置 → 应用 · 关于 看版本和更新。

### 更新怎么装？

没有应用内自动更新。弹窗点「前往下载」会用外部浏览器打开 GitHub 发行页，下载安装包自己装。

### 中栏的树怎么老是变？

它跟着右栏导航自动切 scope，右栏在项目列表就是文件浏览器、进项目是会话工作区、进会话是聊天工作区。见 `workspace.md`。

### 怎么导出整本书稿？

在目录行或空白处右键 →「导出」，导出成 ZIP 子树。想导单个文件就在文件行上右键。技能也是这么导 ZIP，见 `skills.md`。

### 换电脑怎么把数据带过去？

设置 → 数据 · 备份与恢复 →「导出」出 `.nmbackup`，在新机器上「导入」。本机的服务商配置和 API Key 会保留，不用重配。

### 点工具卡为什么跳到奇怪的地方？

工具卡点击有优先级：带 VFS 路径的跳文件预览，`task` 跳子智能体，`skill` 跳技能详情，其它打开结果全文。悬浮提示会写明这次会跳哪儿。

### 子会话里怎么编辑消息？

不能。子智能体面板是只读的，回父会话操作。
