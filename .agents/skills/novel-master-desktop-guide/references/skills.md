# 技能（Skill）管理

技能遵循 `SKILL.md` 标准，可以理解成「给 Agent 装的一个能力包」——写作风格检查、大纲模板、某类改写手法、社区现成的 skill 打包导入即用。

---

## 一、技能的两个域

| 域 | 生效范围 | 标签 |
|----|----------|------|
| **全局技能** | 所有项目 | tab 上标「被项目副本覆盖」表示某个项目里已经有同名副本了，这时这个全局版只对没有同名副本的项目生效 |
| **项目技能** | 仅所属项目，按项目分组展示 | — |

覆盖规则：**同名时项目副本覆盖全局版**。

---

## 二、技能管理列表

**入口有两条**：顶栏 ⚙ 设置 → 高级 · 技能管理；或者会话里 点 `⋯` →「会话详情」抽屉 →「技能」→「整理」。

1. 页内双 tab：「全局技能」/「项目技能」。
2. 点「新建」进新建技能弹窗（见第四节）。
3. 每行 `⋯` 菜单：编辑 / 编辑信息 / 导出 ZIP / 删除。
4. 行上可能挂两种标签：「被项目副本覆盖」和「无效 · 原因」（技能不可解析时）。**无效技能的「编辑信息」是被禁用的**——得先把 SKILL.md 修好。
5. 也能进批量模式多选删除。确认文案会区分影响范围：全局技能写「该技能影响所有项目，删除后全部会话不再注入」，项目技能写「该技能仅所属项目生效，删除后其他项目不受影响」。

---

## 三、技能详情（文件编辑器）

**入口有三条路**：
- 设置 → 高级 · 技能管理 → 点技能行。
- 会话技能面板 → 点技能行（开关区域外）。
- 聊天里点 `skill` 工具卡片（工具卡点击优先级里的第三条）。

页面结构：

1. **左侧文件列表**：`SKILL.md` 标着「入口文件」，**不可删**。下面是可以自己加的辅助文件。
2. **右侧编辑器**：查看 / 编辑双模态，CodeMirror。
3. 点「＋」新建辅助文件，**支持子目录**，比如 `references/写法示例.md`。
4. 辅助文件行尾的 `×` 删除该文件。
5. 底部「保存」「返回」，**Ctrl+S 也保存**。离开有未保存守卫。
6. 路径 chip 显示 `/meta/skills/{技能名}/{文件名}`，方便你核对文件放对没有。

## 四、新建技能（两条通道）

**入口：技能管理页「新建」，或会话技能面板「新建」**（后者默认项目域）。

弹窗里：

- **技能名**：如 `lore-style-guide`。规则是**不能含空格或斜杠，不能以「.」开头**，域内还要查重。
- **描述**：**必填**。它会进技能索引，模型靠它决定要不要用这个技能，所以别写「一些辅助工具」这种废话，写清楚什么时候该用。
- **存储域**：分段选「全局（所有项目）」/「项目」，选项目域时还要在「所属项目」下拉里挑一个。

然后二选一：

**通道 A：手填模板创建**
按模板填好就点「创建并编辑」，会在目标域写一个只含 `SKILL.md` 的新目录。

**通道 B：「从 ZIP 导入…」**
1. 点按钮选一个 ZIP。**ZIP 的根目录必须直接含 `SKILL.md`**，否则预检失败并报「根目录缺少 SKILL.md（导出格式：zip 根即技能目录）」。
2. 预检通过后，ZIP 里的文件数和 name/description 会预填进表单——**预填的名字和描述可以改**。
3. 点「创建并编辑」后，ZIP 内全部文件落入新技能目录。如果你在表单里改过 name 或 description，`SKILL.md` 的 front matter 会按表单最终值重写（没改就不重写）。
4. 想反悔，点「移除」退回手填模式。

技能名 `SKILL.md` 是保留名，不能拿来当技能名。

## 五、改名与改描述

**入口：技能管理行 `⋯` →「编辑信息」**

弹窗里改技能名 + 描述，内置技能名只读。输入的时候实时出校验原因（空格、斜杠、开头点、域内重名），改完保存提示「已保存技能信息」。

保存后如果技能详情页正看着同一个技能，页面会同步刷新，不会出现「技能改名把自己踢回列表」。

---

## 六、ZIP 导出与导入

**导出**：技能管理行 `⋯` →「导出 ZIP」，导出完 toast 提示「已导出「技能名.zip」」。

**格式约定（很重要）**：本产品导出的 ZIP，**根目录就是技能目录本身**，里面直接是 `SKILL.md` 和其它文件。导入时也按这个格式校验。所以别自己重新压一层目录，那样会报「根目录缺少 SKILL.md」。

一套走通：某台机器导出 → 传过去 → 另一台「新建」→ 「从 ZIP 导入…」→ 预检 → 创建并编辑。

## 七、会话技能面板（按项目开关技能）

**入口：会话里 点 `⋯` →「会话详情」抽屉 → 点「技能 查看与管理」**

这是「在会话里临时决定这个项目用哪些技能」的地方：

1. 面板是**当前项目的合并视图**：全局技能 ∪ 项目技能，同名时项目副本覆盖全局。
2. 每个技能带域徽标，被覆盖的标「被覆盖」，不可解析的标「无效」。
3. **每个技能一个启用开关**，开关写的是**当前项目的负清单**，只对这个项目生效。
4. 顶部有「‹返回」「整理」「新建」，还有「N/M 启用」的计数。
5. 点技能行（开关区域外）跳设置里的技能详情页，会过未保存守卫。
6. 「整理」跳 设置 · 技能管理，「新建」进新建技能弹窗并默认项目域、默认当前项目。
7. 面板空的时候提示「暂无技能。点击「新建」创建项目技能，或在设置·技能管理页维护全局技能。」

## 八、在对话里用技能

**入口：输入框工具栏的 `$` 按钮**，或者**直接在正文里打 `$`** 触发联想。

1. `$` 按钮打开引用技能选择器，平铺当前项目的技能合并视图，可以多选，显示域徽标、「已关闭」状态和描述。确认后插入 `$技能名`。
2. 直接打 `$` 会出联想气泡：按名称和描述模糊匹配，最多 5 条候选，上下键选完自动带前后空格插入。
3. 两个细节：
   - **无效技能不出现**在候选里（不可解析的等于没有）。
   - **已关闭（被负清单关掉）的技能仍然可以选**——显式 `$` 引用优先于负清单。所以「在面板里关掉它」不代表「不能显式点名用它」。
4. 技能真正生效要看智能体那边的「技能能力总开关」：关掉之后不注入索引、也不注册 `skill` 工具，但**手动 `$` 引用不受影响**（见 `agents.md`）。

## 九、如何把本指南装进 novel master

如果你想把这份桌面端使用指南当成一个技能，装进 novel master 自己用：

1. **打包成 ZIP**：把整个 `novel-master-desktop-guide` 目录压成 ZIP。注意 **ZIP 根目录要直接含 `SKILL.md`**——就是上面说的格式，不要多套一层 `novel-master-desktop-guide/` 目录，否则导入会报「根目录缺少 SKILL.md」。
   - 目录里有 `SKILL.md` 和 `references/`（含 quickstart / providers / context / workspace / agents / skills / misc 几个 `.md`）。如果压包工具默认把文件夹名当一层，得先进到目录里再压缩。
2. **导入**：设置 → 高级 · 技能管理 →「新建」→ 点「从 ZIP 导入…」→ 选那个 ZIP → 预检通过 → 检查预填的技能名和描述 → 点「创建并编辑」。
3. **改信息**（可选）：在技能管理里行 `⋯` →「编辑信息」，把描述改成能触发它的话，比如「novel master 桌面端操作指南，用户问怎么设置服务商、压缩上下文、批注、技能、备份、统计时使用」。
4. **启用**：回到会话，点 `⋯` →「会话详情」→「技能 查看与管理」，在面板里把它的开关打开（这是当前项目的负清单，开了才会注入）。
5. **对话里用**：输入框打 `$` 选中它，或者点 `$` 按钮多选后确认。

## 常见坑

1. **ZIP 导入报「根目录缺少 SKILL.md」。** 多套了一层目录。正确格式是 zip 根直接是 `SKILL.md`。重新压：进到技能目录里，压 `SKILL.md` 和 `references/`。
2. **描述写太随便，模型不用这个技能。** 描述是进技能索引的，写清「什么场景该用」，比写「辅助工具」有用得多。
3. **全局技能好像不生效。** 看看是不是被同名项目副本覆盖了——全局 tab 上会有「被项目副本覆盖」标签，这种情况只有没副本的项目用它。
4. **「编辑信息」点不动。** 技能是无效状态（SKILL.md 不可解析），先修好 SKILL.md 再改。
5. **SKILL.md 删不掉。** 它是入口文件，必须留着，只能删辅助文件。
6. **面板里关了技能，`$` 还能选它。** 这是设计：显式引用优先于负清单。要彻底不用，得去智能体那边把「技能能力总开关」关掉。
7. **删除技能的影响范围记不住。** 看确认弹窗的文案——全局技能影响所有项目，项目技能只影响所属项目。
8. **会话技能面板里的技能是哪儿来的。** 是当前项目的合并视图（全局 ∪ 项目），不是「会话私有的技能列表」。
