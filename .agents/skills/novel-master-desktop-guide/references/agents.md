# 智能体配置

一个智能体 = 系统提示词 + 可用工具名单 + 锁定模型 + 运行时步数上限。它是「换个角色干件事」的单位：只读分析的不给写工具，全权写作的全给，整理资料的换一个。

---

## 一、智能体列表

**入口：顶栏 ⚙ 设置 → AI · 智能体配置**

1. 页内双 tab：「主智能体」/「子智能体」。切 tab 会自动退出批量模式。
2. 点「新建 Agent」创建。
3. 每行 `⋯` 菜单：编辑、重命名、复制、删除。内置的 **general** 只有「查看」——它不可编辑也不可删，是保底的那个通用助手。
4. 点「管理」进批量模式多选删除，走的是独立的确认文案。
5. 行上可能挂「配置失效」标签——智能体被删了但会话还指着它。
6. **子智能体** tab 顶部会合成内置的 general（标注「通用助手 · 不可编辑」），它也在这个 tab 里。

## 二、智能体编辑页

**入口有三条**：列表点行 / 点 general 的「查看」/ 跨页跳转（别处点技能之类触发过来）。有未保存改动时离开会弹确认。

编辑页从上到下五个分区，**纵向顺序 = 模型组装提示词的顺序**，这个顺序很重要，别以为是随便排的。

### 1. 基本信息

名称、描述、作用域。作用域三选一：「默认（全部）」/「仅主智能体」/「仅子智能体」——决定它出现在主 tab、子 tab 还是两个 tab。

### 2. 模型

「专属模型」开关加模型选择器。不开就是「跟随」——跟随工作区默认模型与会话里的临时选择。开了就锁死这个智能体（会话里会显示 🔒「智能体锁定」，没法覆盖）。

模型从哪儿来见 `providers.md`。

### 3. 运行时

「最大步数」：限制单轮任务中模型与工具的往返次数。不填默认 20。改稿这种要连着读写十几个文件的活儿，得给够；纯问设定给太大反而容易让它绕。

### 4. 工具策略

先选模式，再选工具：

| 模式 | 含义 |
|------|------|
| **默认（全部工具）** | 不限制 |
| **白名单** | 只给勾选的 |
| **黑名单** | 除了勾选的都给 |

11 个内置工具，各自干什么：

| 工具 | 干什么 |
|------|--------|
| `read` | 读工作区单个文件的文本（只读，大文件可分段续读） |
| `write` | 写入或整文件覆盖（不存在的文件会创建） |
| `edit` | 文件内精确文本替换，适合小范围修改 |
| `fs` | 文件系统命令：列目录、删、移动、复制、建目录等 |
| `glob` | 按 glob 模式找文件路径（如 `**/*.md`） |
| `grep` | 在文件内容里搜关键词或正则，返回路径、行号与摘录 |
| `skill` | 装载与查看技能（读技能的 SKILL.md 开工） |
| `agent` | 在对话里管理智能体定义（列出 / 查看 / 新建 / 更新） |
| `curl` | 发 HTTP 请求，抓网页、接口文档、API 内容 |
| `search` | 联网搜索（走「搜索配置」里的引擎链；没配付费引擎也有内置 DuckDuckGo 兜底） |
| `task` | 派一个子代理去干子任务，跑完把结果带回来 |

典型配法：
- **只读分析员** → 白名单只勾 `read` / `fs` / `glob` / `grep`，不给 `write` `edit`，它就改不了你的稿。
- **全权写作** → 保持默认。
- **联网查资料** → 加 `curl` / `search`。

> `task` 始终注册、始终可用，不进白名单黑名单策略——它就是派子代理的口子。

### 5. 提示词模版

这是核心区，六个纵向区块，顺序固定：

```
系统 → 技能索引 → 常驻工作区 → 持久区 → 会话历史 → 动态区
```

| 区块 | 能不能编辑 | 作用 |
|------|------------|------|
| **系统区** | 可编辑（需「启用系统」） | 「系统内容」写这个角色的身份和总纲 |
| **技能索引区** | 只读 | 运行时注入当前生效的技能索引 |
| **常驻工作区** | 可编辑（开关 + 「助手确认语」） | 开启后把项目文件树注入上下文，助手确认语是必填的 |
| **持久区** | 可编辑（需「启用持久区」） | 每轮都带的固定文本 |
| **会话区**（会话历史） | 只读 | 运行时注入当前会话可见消息，固定位于持久区与动态区之间，不可编辑、不可关闭、始终发送 |
| **动态区** | 可编辑（需「启用动态区」） | 每轮临时拼进去的文本 |

几个要点：

- 关闭某个区不会删掉已填的内容，只是运行时不再发送；系统区关闭则不写入系统提示词。
- **持久区禁止使用宏**（会提示「持久区禁止使用宏。」）。
- **常驻工作区**开启后必须填助手确认语，空着会**直接阻断保存**并提示「请填写常驻工作区助手确认语」。
- 技能索引还可以单独关（技能能力总开关 + 索引前缀语）：关闭后不注入索引、也不注册 `skill` 工具，但**手动用 `$` 引用技能不受影响**。
- 另有「自定义附加信息」开关 + 文本：开启后每轮注入到最新一条用户消息上（开着但内容清空时静默省略，不阻断保存）。

### 工具栏：导入 / 导出 YAML

编辑页顶部有「导入 YAML」「导出 YAML」。同一个智能体要在多台机器上对齐，或者想进版本管理，就用这两个按钮倒来倒去。

## 三、切换会话的智能体

**入口：会话里点输入框工具栏最左的 `⋯` →「会话详情」抽屉 →「Agent」→ 点行**

弹选择器（PickerModal）挑一个，会话立刻绑过去。会话必须绑一个智能体，没法解绑。

卡片有三种状态，看徽标就知道：

| 状态 | 徽标 | 能不能点 |
|------|------|----------|
| 加载中 | 「加载中…」 | 锁住，防误点 |
| 加载失败 | 加载失败提示 | 锁住，提示「智能体信息加载中，请稍候再试。」这类固定文案 |
| 原智能体已被删除 | 「已删除 · 点击重选」 | **能点**，弹选择器重选一个，绑上之后悬空就解除了 |

> 选不上时可能是压根没配智能体，会提示「暂无 Agent，请先在设置中配置。」

模型行在同一抽屉里切换：来源不是会话覆盖时显示 🔒「智能体锁定」，点不了。可以选「清除会话覆盖（使用智能体锁定模型）」回退到智能体的锁定模型。列表空的话提示「暂无模型，请先在设置中配置 Provider。」

## 四、看子智能体的对话

**入口：聊天里点 `task` 工具卡片**（带子会话 id 的那种）

点进去是一个**只读面板**：

- 完整浏览子智能体的全部对话，没有输入框。
- 消息右键菜单被禁用——你不能在子会话里编辑、回滚、分叉，操作都得回父会话做。
- 运行中顶部显示「子智能体运行中…」和一个「停止」按钮，可以中断。
- 面板是 keep-alive 的：返回父会话再进来，流式内容不会丢。
- 左上角 `‹` 返回父会话。

## 常见坑

1. **general 点不开编辑。** 内置的通用助手全字段只读，就只能看。要改行为就复制一个再改（行 `⋯` →「复制」）。
2. **会话里模型换不了，图标是🔒。** 智能体锁定了模型，去智能体编辑页把「专属模型」关掉或者换个模型；或者给智能体换个没锁的。
3. **提示词改了没生效。** 看区的前面开关（启用系统 / 启用持久区 / 启用动态区）是不是忘了开——关着的区填了内容也不发送。
4. **保存被拦，提示「请填写常驻工作区助手确认语」。** 常驻工作区开关开着但确认语空了，把确认语填上。
5. **提示词里想用 `$filetree` 这类宏，写在持久区里报错。** 持久区禁止宏，挪到动态区。
6. **行上挂「配置失效」标签。** 这个智能体被删了，会话还指着它。去会话详情抽屉点智能体卡，徽标会显示「已删除 · 点击重选」，点一下重选即可。
7. **子会话里什么都改不了。** 面板本来就是只读的，回父会话操作。
8. **给了子智能体一堆工具还是不老实。** 工具策略要用白名单模式才真的生效，默认模式是全给。
