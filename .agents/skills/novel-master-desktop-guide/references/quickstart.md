# 快速上手：从零写出一章小说

跟着这一篇走一遍，你就能完整跑通「建项目 → 喂设定 → 让 Agent 写 → 定点改 → 收敛上下文」。

---

## 第 0 步：先把模型配好（不然后面全是灰的）

**入口：顶栏 ⚙ 设置 → AI · 服务商配置**

1. 点「新建服务商」，填协议（openai / anthropic / gemini）、Base URL、API Key，保存。
2. 在服务商详情里进「模型管理」页签，点「拉取模型」勾选要用的模型，或点「添加」手填厂商模型 ID。
3. 想让它默认就用这个模型：设置 → 工作区 · 常规 → 「默认选择」→「当前大模型」，点行选中即可。

没配模型之前聊天输入框是禁用的，placeholder 会变成「请先配置模型（设置 → Provider）」。详见 `providers.md`。

---

## 第 1 步：先认识这三栏

桌面端主界面就三根竖条，从左到右：

| 栏位 | 干什么 | 顶栏开关 |
|------|--------|----------|
| **左栏 · 文件预览** | 看和改文件内容，支持多标签页、预览/编辑切换 | `◧` |
| **中栏 · 工作区树** | 管文件树，Agent 真正读写的文件都在这里 | `▥` |
| **右栏 · 聊天** | 项目 → 会话 → 聊天三级下钻，跟 Agent 写稿的地方 | `◨` |

关键因果：**中栏显示哪一层，跟着右栏导航自动切**。右栏停在项目列表时，中栏是「文件浏览器」（只读的物理磁盘视图）；右栏进到某个项目的会话列表，中栏变「会话工作区」（项目模板母本）；右栏进到具体会话，中栏变「聊天工作区」（当前会话私有，Agent 主要在这儿读写）。

栏与栏之间的分隔条可以拖拽调宽（有最小宽度），嫌挤就先拖宽左栏看正文，或者用顶栏按钮把用不上的栏藏起来——显隐状态会被记住。详见 `workspace.md`。

---

## 第 2 步：新建项目

**入口：右栏顶部「项目」页（默认首屏）**

1. 点「新建」，填项目名，一部作品建一个项目。
2. 想先改个名或删掉，点项目行尾的 `⋯` → 重命名 / 删除。
3. 要一次清掉多个项目，点「管理」进批量模式勾选后删除（会连带删掉它下面所有会话，弹窗里会写明）。

---

## 第 3 步：在项目模板里铺设定

**入口：右栏点进项目（停在会话列表），此时中栏就是「会话工作区」**

这层是母本——以后每个新会话都从这里复制一份出去，所以大纲、人设、卷纲放这里最省事。

1. 中栏空白处右键 → 新建文件 / 新建文件夹，搭出目录，比如 `/设定/`、`/卷纲/`、`/章节/`。
2. 每个文件正文直接写：世界观、人物卡、卷纲、章节占位。有现成的设定资料，也可以空白处右键 → 导入，选 ZIP 包 / 角色卡 / 单文件三种形式之一。
3. 让 Agent 每次都能看到设定：给目录配「规则配置」。

**目录规则**：目录行右键 →「规则配置」，能设排序方式（文件名称 / 创建时间 / 更新时间 / 智能排序）、升序降序、头部数量、尾部数量，以及「其余文件填充」是显示文件名、头信息还是不展示。这套规则不改文件内容，只决定「哪些文件参与列表、怎么排、按什么档位进 Agent 上下文」。

4. 单个文件还想额外控制，就文件行右键 →「状态设置」，选三态之一：
   - **展示**：强制纳入 Agent 上下文，显示全内容。
   - **隐藏**：强制不纳入。
   - **跟随**：由父目录的纳入规则决定（默认）。

工作区根目录 `/` 的规则是强制启用的，没法关。

---

## 第 4 步：新建会话

**入口：右栏会话列表页 →「新建」**

1. 会话默认标题是自动编号，直接点进去就能用。
2. 进去之后中栏切成「聊天工作区」——一份从项目模板复制出来的私有副本。你在这儿怎么改都不会影响别的会话，也不会把项目模板弄脏。
3. 想改标题：进会话后点输入框工具栏最左的 `⋯` 打开「会话详情」抽屉，点会话名那行进入行内编辑，回车或点别处保存，Esc 取消。

---

## 第 5 步：把设定喂给 Agent

**入口：聊天输入框工具栏的 `@` 按钮（或直接在正文里打 `@`）**

1. 点 `@` 打开引用文件选择器，在工作区树里逐层浏览，可以多选文件和目录。
2. 勾选完点「确认」，选中的项会以 `@路径` 的形式插进正文，比如 `@/设定/人物卡.md`。
3. 也可以直接在输入框打 `@` 触发联想气泡，按名称模糊匹配，最多给 5 条候选，上下键选完自动带空格插入。

同一屏入口有两个：`@` 按钮和正文里的 `@` 触发，效果一样。

---

## 第 6 步：对话写稿

**入口：右栏聊天页签底部输入框**

1. 直接打字描述你要什么，比如「按卷纲写第一章，两千字左右，保持人物卡的说话习惯」。
2. 发送：点发送按钮，或者 **Ctrl/Cmd+Enter**（Enter 是换行，输入法组字期间不会误触发）。运行中按钮会变成 ■ 停止。
3. 输入框顶部那些不能删的小 chip 是状态标记，告诉你这一条带了什么（工作区、user_ops、批注）。草稿按会话自动保存，下次进来还在。
4. 顶部的「聊天 / 提示词」两个页签：点「提示词」能按轮看真实送进模型的提示词——轮卡可以展开收起，里面是叶子卡、工具组卡和常驻工作区文件卡，点任一张能进全屏看原文。底部会提示「在会话工作区调整纳入规则可改变预览内容」。

写完想看这次花了多少，点聊天页签顶部的流式指标条（耗时 / 输出 token / 实时速率），弹出的用量详情里有「最近请求」和「会话累计」两段。

---

## 第 7 步：左栏预览与工具卡

Agent 写完文件之后，左栏是看成果的地方。

- **打开文件预览有三条路**：中栏点文件行、点聊天里的工具卡、点聊天消息里的路径链接。
- **多标签页**：像 VS Code 那样开多个文件；删掉文件只会把 tab 标成「已删除」不会自动关掉；文件重命名时 tab 名会跟着变。
- **预览 / 编辑切换**：段落控件切换。Markdown 走渲染（支持 mermaid 图），其余文件走 `<pre>` 纯文本。
- **编辑**：切到「编辑」档就是 CodeMirror 编辑器，底部有行数和「未保存 / 已保存」状态，**Ctrl+S 保存**。物理文件浏览器面板只有只读的预览档，没有编辑档。
- 保存时如果内容被别人改过，会弹「保存失败：…」并保留 lastKnownContent 让你判断。

**工具卡的点击优先级**——工具调用卡（折叠组「工具调用 (N)」里的每张卡）点一下会去哪，取决于这张卡是什么：

| 卡是什么 | 点下去发生什么 |
|----------|----------------|
| 带 VFS 路径 | 在聊天工作区打开文件预览 |
| `task` 工具 | 跳到子智能体会话只读面板 |
| `skill` 工具 | 跳到设置里的技能详情页 |
| 其它 | 打开工具结果全文（全屏弹窗，Esc 或点遮罩关） |

悬浮提示会跟着变，写着「点击查看 · 子智能体会话 / 技能 / 结果 / 聊天工作区」。

## 第 8 步：用划词批注定点改稿

这是最省事的一种改稿方式：在左栏的文件预览里选中一段字，直接写批注发给 Agent，它就知道只改这一处。

**入口：左栏预览态，鼠标划词后出现的浮动条「添加批注」**

1. 前置条件有三个，缺一不出现：**必须在聊天工作区**（右栏停在具体会话）、**必须是预览态不是编辑态**、**文件必须是 Markdown**、并且当前会话有上下文。
2. 划词 → 点浮动条上的「添加批注」→ 弹窗里会显示你选中的原文，再填批注说明 → 保存。
3. 同一段文字上有多条批注时，会先经过一个「选择批注」弹窗让你挑。
4. 已入库的批注在预览里是高亮的，点高亮直接进「批注详情」弹窗改或删。
5. 发消息时批注会作为 `annotate` 附件注入，输入框顶部出现对应 chip。Agent 收到的就是「这段原文 + 这条批注」，定点改不乱动别的。

---

## 第 9 步：长对话收敛

聊了几十轮之后，上下文会越来越臃肿，这时候用四个词里的对应那个（详见 `context.md`）：

- **置位**：发消息后右键自己的那条消息 →「置位」，把它设成可见历史的起点，之前的旧消息折叠起来。
- **压缩**：上下文占用条看着太高了，就点输入框工具栏 `⋯` 打开「会话详情」抽屉 → 底部「压缩上下文」。也可以在 设置 → 工作区 · 常规 里开自动压缩、设 Token 比例阈值。
- **回滚**：改错了，右键某条消息 →「回滚」，退回到那条消息的状态，弹二次确认。
- **分叉**：想保留现在的走向另开一条，右键某条消息 →「分叉」，原分支原样留着。

其他消息操作：右键或点气泡上的 `⋯` →「编辑」可以改消息正文（回车换行，Ctrl+Enter 保存）、「复制」复制原文。隐藏的消息不显示回滚。运行中「置位」「分叉」会被拒掉并弹提示。

## 常见坑

1. **中栏怎么突然不是我刚才那棵树了？** 它跟着右栏导航变。回项目列表就是「文件浏览器」，进项目是「会话工作区」，进会话是「聊天工作区」。不是 bug。
2. **明明改了项目模板，会话里却没变？** 会话工作区是复制出去的独立副本。想让改动同步过去，用中栏标题右侧的 `⋯` →「初始化」（从项目工作区拉模板覆盖当前聊天工作区，本地修改会丢，会有确认弹窗）。反过来想把会话里的东西沉淀回模板，用同一个菜单里的「推送到项目工作区」。
3. **找不到会话操作的菜单在哪。** 输入框工具栏**最左边**的 `⋯` 才是，它打开的是「会话详情」抽屉，不是下拉菜单。
4. **划词批注不出来。** 检查三件事：在不在具体会话里、有没有切到「预览」档、是不是 Markdown 文件。编辑态和非 Markdown 都不触发。
5. **左栏说找不到编辑档。** 文件浏览器是只读物理树，本来就没有编辑档；要看可编辑的那棵，去聊天工作区里点文件。
6. **输入框打不了字。** 十有八九是没配模型，去 设置 → AI · 服务商配置看一眼。
